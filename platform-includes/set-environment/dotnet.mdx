```csharp
// Add this to the SDK initialization callback
options.Environment = "production";
```

```fsharp
// Add this to the SDK initialization callback
options.Environment <- "production"
```

If you don't set it, the SDK uses `SENTRY_ENVIRONMENT`, the .NET host environment or a default. The <PlatformLink to="/configuration/options/#Environment">Environment option</PlatformLink> describes the order.

To change the environment at runtime, set it on the scope:

```csharp
SentrySdk.ConfigureScope(scope => scope.Environment = "staging");
```

```fsharp
SentrySdk.ConfigureScope(fun scope -> scope.Environment <- "staging")
```

Everything captured with that scope uses this environment, including logs, metrics, sessions, check-ins and trace propagation. Sessions use the environment from when they start, so changes to `Scope.Environment` don't affect a session that's already running. 

<Alert title="Changed in Version 7.0.0">

In earlier versions, `Scope.Environment` applied only to events and transactions.

</Alert>
