## Prerequisites

You need:

- A Sentry [account](https://sentry.io/signup/) and [project](/product/projects/)
- Your application up and running
- Spring Framework `5.1.2`+
  - [Sentry WebFlux integration](/platforms/java/guides/spring-boot/webflux/) requires Spring Framework `5.2.4` or above

If you're on an older version, use [our legacy integration](/platforms/java/legacy/spring/).
