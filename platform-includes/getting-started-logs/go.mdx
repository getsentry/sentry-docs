
Use the `Sentry.Logger` API to send logs at different levels, such as `info`, `warn`, or `error`. You can pass any attributes you want and search or filter by them later.
See <PlatformLink to="/logs/">Set Up Logs</PlatformLink> for all available logging methods and the syntax for formatting messages.

```go
import (
    "context"

    "github.com/getsentry/sentry-go"
)

logger := sentry.NewLogger(context.Background())
logger.Info().Emit("User signed in")
logger.Warn().Emit("Slow operation detected")
```
