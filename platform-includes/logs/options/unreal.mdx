The following configuration options are available for Sentry Logs in Unreal Engine:

| Option | Description | Default |
|--------|-------------|------------|
| **VeryVerbose** | Forward VeryVerbose UE_LOG calls to Sentry as Trace level logs | `false` |
| **Verbose** | Forward Verbose UE_LOG calls to Sentry as Debug level logs | `false` |
| **Display/Log** | Forward Display and Log UE_LOG calls to Sentry as Info level logs | `false` |
| **Warning** | Forward Warning UE_LOG calls to Sentry as Warning level logs | `false` |
| **Error** | Forward Error UE_LOG calls to Sentry as Error level logs | `false` |
| **Fatal** | Forward Fatal UE_LOG calls to Sentry as Fatal level logs | `false` |
| **Send Logs As Breadcrumbs** | Send UE_LOG calls BOTH as Logs and as Breadcrumbs, instead of just Logs | `false` |
| **Log Category Filter** | Array of log categories to include (empty = all categories) | Empty |
| **Before Log Callback** | Handler to modify or filter log events before sending | None |
