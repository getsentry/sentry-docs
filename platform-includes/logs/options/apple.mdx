#### beforeSendLog

To filter logs, or update them before they are sent to Sentry, you can use the `beforeSendLog` option.

<Alert>

In SDK 9.27.0+, manual logging doesn't require an enable flag. To drop logs, return `nil` from `beforeSendLog`; setting `enableLogs` to `false` doesn't drop them. For older SDKs, also enable logging as described in [Setup](#setup).

</Alert>

```swift {tabTitle:Swift}
import Sentry

SentrySDK.start { options in
    options.dsn = "___PUBLIC_DSN___"

    options.beforeSendLog = { log in
        if log.level == .info {
            // Filter out all info logs
            return nil
        }
        return log
    }
}
```

```objc {tabTitle:Objective-C}
@import Sentry;

[SentrySDK startWithConfigureOptions:^(SentryOptions *options) {
    options.dsn = @"___PUBLIC_DSN___";

    options.beforeSendLog = ^SentryLog* (SentryLog *log) {
        if (log.level == SentryLogLevelInfo) {
            // Filter out all info logs
            return nil;
        }
        return log;
    };
}];
```

```objc {tabTitle:Objective-C (SentryObjC)}
#import <SentryObjC/SentryObjC.h>

[SentryObjCSDK startWithConfigureOptions:^(SentryObjCOptions *options) {
    options.dsn = @"___PUBLIC_DSN___";

    options.beforeSendLog = ^SentryObjCLog* (SentryObjCLog *log) {
        if (log.level == SentryObjCLogLevelInfo) {
            // Filter out all info logs
            return nil;
        }
        return log;
    };
}];
```

The `beforeSendLog` function receives a log object, and should return the log object if you want it to be sent to Sentry, or `nil` if you want to discard it.

The log object has the following properties:

- `level`: The log level (trace, debug, info, warn, error, fatal)
- `body`: The log message content
- `timestamp`: The timestamp of the log
- `attributes`: The attributes of the log
