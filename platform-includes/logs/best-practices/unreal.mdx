### Wide Events Over Scattered Logs

Instead of many thin logs that are hard to correlate, emit one comprehensive log per operation with all relevant context.

This makes debugging dramatically faster — one query returns everything about a specific order, user, or request.

```cpp
// ❌ Scattered thin logs
SentrySubsystem->LogInfo(TEXT("Starting checkout"));
SentrySubsystem->LogInfo(TEXT("Validating cart"));
SentrySubsystem->LogInfo(TEXT("Processing payment"));
SentrySubsystem->LogInfo(TEXT("Checkout complete"));

// ✅ One wide event with full context
// Use categories and descriptive messages
SentrySubsystem->LogInfo(
    FString::Printf(TEXT("Checkout completed - Order: %s, User: %s, Value: %.2f"),
        *OrderId, *UserId, CartValue),
    TEXT("Checkout")
);
```

### Include Business Context

Add attributes that help you prioritize and debug:

- **User context** — tier, account age, lifetime value
- **Transaction data** — order value, item count
- **Feature state** — active feature flags
- **Game metadata** — level, scene, player state

Use categories to organize logs and make them easier to search and filter.

```cpp
// Use categories for different systems
SentrySubsystem->LogInfo(
    FString::Printf(TEXT("Purchase completed - User: %s, Tier: %s, Value: %.2f"),
        *UserId, *UserTier, PurchaseValue),
    TEXT("IAP")
);

SentrySubsystem->LogInfo(
    FString::Printf(TEXT("Level loaded - Name: %s, LoadTime: %.2fs"),
        *LevelName, LoadTime),
    TEXT("GameFlow")
);
```

### Consistent Attribute Naming

Pick a naming convention and stick with it across your codebase. Inconsistent names make queries impossible.

**Recommended:** Use consistent category names and message formats.

```cpp
// ❌ Inconsistent categories
SentrySubsystem->LogInfo(TEXT("..."), TEXT("player"));
SentrySubsystem->LogInfo(TEXT("..."), TEXT("Player"));
SentrySubsystem->LogInfo(TEXT("..."), TEXT("PLAYER"));
SentrySubsystem->LogInfo(TEXT("..."), TEXT("PlayerSystem"));

// ✅ Consistent PascalCase categories
SentrySubsystem->LogInfo(TEXT("Player spawned"), TEXT("Player"));
SentrySubsystem->LogWarning(TEXT("Player died"), TEXT("Player"));
SentrySubsystem->LogDebug(TEXT("Player score updated"), TEXT("Player"));
```
