Logs are supported in Sentry Dart SDK version `9.0.0` and above, and are enabled by default in version `9.28.0` and above.

<Alert>

On SDK versions below `9.28.0`, logs are opt-in. Set `options.enableLogs = true` in `Sentry.init` to send them. In v9 releases from `9.28.0` onward, direct logger calls work without the flag, but automatic collection still uses `enableLogs`.

</Alert>

In SDK v10, the `enableLogs` option is removed. Use <PlatformLink to="/logs/#beforesendlog">`beforeSendLog`</PlatformLink> to filter logs.
