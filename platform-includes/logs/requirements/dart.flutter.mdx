Logs are supported in SDK version `9.0.0` and above. In SDK v10, logs are always enabled: initialize the SDK and call `Sentry.logger`.

<Alert>

On SDK versions below `9.28.0`, set `options.enableLogs = true` in `SentryFlutter.init` to send logs. In v9 releases from `9.28.0` onward, direct logger calls work without the flag, but automatic collection still uses `enableLogs`. The option is removed in v10; use <PlatformLink to="/logs/#beforesendlog">`beforeSendLog`</PlatformLink> to filter logs.

</Alert>
