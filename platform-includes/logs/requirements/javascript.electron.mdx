Logs for JavaScript are supported in Sentry Electron SDK version [`6.7.0`](https://github.com/getsentry/sentry-electron/releases/tag/6.7.0) and above, and are enabled by default in version `7.18.0` and above.

<Alert>
  On SDK versions below `7.18.0`, logs are opt-in. Set `enableLogs: true` in your `Sentry.init` to send them.
</Alert>
