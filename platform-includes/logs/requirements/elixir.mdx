Logs for Elixir are supported in Sentry Elixir SDK version `12.0.0` and above. The configuration on this page requires version `14.0.0` or later.

Add `sentry` to your `mix.exs` dependencies:

```elixir
defp deps do
  [
    {:sentry, "~> 14.0"}
  ]
end
```

If you're upgrading from version `13.x`, which turned on logs with `enable_logs: true`, see the [upgrade guide](https://hexdocs.pm/sentry/upgrade-14-x.html).
