Logs for Apple platforms are supported in Sentry Cocoa SDK version `8.55.0` and above. Starting with version `9.0.0`, structured logging is no longer experimental and is part of the stable API.

Manual logging is available on all supported Apple platforms, including watchOS. Starting with SDK `9.27.0`, calls to `SentrySDK.logger` don't require an enable flag. Earlier versions require the option described in [Setup](#setup).
