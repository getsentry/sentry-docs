Starting with SDK version `8.59.0`, direct `Sentry.logger()` calls work after initialization regardless of the `logs.enabled` setting. On earlier SDK versions, set `logs.enabled` to `true` to send logs through this API.

To collect logs automatically through the <PlatformLink to="/integrations/timber/">Timber</PlatformLink> or <PlatformLink to="/integrations/logcat/">Logcat</PlatformLink> integration, enable `logs.enabled` in the manifest or when you <PlatformLink to="/manual-setup/#configuration-via-sentryoptions">initialize the SDK in code</PlatformLink>:

```XML {filename:AndroidManifest.xml}
<meta-data android:name="io.sentry.logs.enabled" android:value="true" />
```

```java {tabTitle: Java} {10}
import io.sentry.SentryLevel;
import io.sentry.android.core.SentryAndroid;
import android.app.Application;

public class MyApplication extends Application {
  public void onCreate() {
    super.onCreate();
    SentryAndroid.init(this, options -> {
      options.setDsn("___PUBLIC_DSN___");
      options.getLogs().setEnabled(true);
    });
  }
}
```
