Enable Sentry Logs on the appender with `logsEnabled`. Use `minimumLevel` to configure which log messages are sent to Sentry.

```xml {tabTitle: log4j2.xml} {4,7}
<Sentry
        name="Sentry"
        dsn="___PUBLIC_DSN___"
        logsEnabled="true"
        minimumBreadcrumbLevel="DEBUG"
        minimumEventLevel="WARN"
        minimumLevel="DEBUG"
/>
```
