Logs are enabled by default. Initialize the SDK as usual, then use `Sentry.logger` to send logs.

```typescript {filename:src/instrument.server.ts}
import { defineCloudflareOptions } from "@sentry/cloudflare";

export default defineCloudflareOptions((env) => ({
  dsn: "___PUBLIC_DSN___",
}));
```

If you deploy with `wrangler` directly, pass the same options to `withSentry` as shown in the <PlatformLink to="/install/wrangler/">Wrangler setup</PlatformLink>.
