<PlatformSection supported={["dotnet.extensions-logging"]}>

Initialize the SDK with `SentrySdk.Init`, then add Sentry to your logging builder. Entries your app writes through `ILogger` are then sent as logs, without a logs-specific option.

```csharp
SentrySdk.Init(options =>
{
    options.Dsn = "___PUBLIC_DSN___";
});

builder.Logging.AddSentry();
```

Apps on the .NET Generic Host, such as worker services, use `UseSentry` from the `Sentry.Extensions.Hosting` package instead.

<Alert title="Changed in Version 7.0.0">

In earlier versions, `AddSentry` initialized the SDK itself and only sent logs when `EnableLogs` was `true`. On those versions, set the DSN and `EnableLogs` in `AddSentry(options => ...)` instead of calling `SentrySdk.Init`.

</Alert>

</PlatformSection>

SentrySdk.Init(options =>

Initialize the SDK, then add the Sentry target, in code or in your `NLog.config`. The target sends logs as soon as you add it.

SentrySdk.Init(options =>

var config = new LoggingConfiguration();
config.AddSentry();
LogManager.Configuration = config;
