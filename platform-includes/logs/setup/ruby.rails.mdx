Rails structured logging is disabled by default. To capture Rails framework events, enable it explicitly:

```ruby
Sentry.init do |config|
  config.dsn = "___PUBLIC_DSN___"
  config.rails.structured_logging.enabled = true
end
```

This enables automatic structured logging of Rails framework events, such as ActiveRecord queries and controller actions. You can also use the `Sentry.logger` API for explicit logging.

See the [Usage](#usage) section for examples and [Options](#options) to customize which events are captured.
