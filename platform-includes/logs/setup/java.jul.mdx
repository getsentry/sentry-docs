Enable Sentry Logs on the handler with `logsEnabled`. Use `minimumLevel` to configure which log messages are sent to Sentry.

```properties {tabTitle: logging.properties} {5,8}
# Configure the Sentry handler
handlers=io.sentry.jul.SentryHandler

# Enable Sentry Logs capture
io.sentry.jul.SentryHandler.logsEnabled=true

# Set the minimum level for the Sentry handler
io.sentry.jul.SentryHandler.minimumLevel=CONFIG
```
