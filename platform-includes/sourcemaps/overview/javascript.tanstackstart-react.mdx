## Uploading Source Maps in a TanStack Start Project Using sentryTanstackStart

<OrgAuthTokenNote />

**Make sure you add your auth token to your CI, if you are using one to deploy your application.**

Add your auth token to your environment:

```bash {filename:.env}
SENTRY_AUTH_TOKEN=___ORG_AUTH_TOKEN___
```

<Include name="vite-loadenv-hint.mdx" />

Configure `sentryTanstackStart` in your `vite.config.ts`:

```typescript {filename:vite.config.ts}
import { defineConfig } from "vite";
import { sentryTanstackStart } from "@sentry/tanstackstart-react/vite";
import { tanstackStart } from "@tanstack/react-start/plugin/vite";

export default defineConfig({
  plugins: [
    tanstackStart(),
    // other plugins - sentryTanstackStart should be last
    sentryTanstackStart({
      org: "___ORG_SLUG___",
      project: "___PROJECT_SLUG___",
      authToken: process.env.SENTRY_AUTH_TOKEN,
    }),
  ],
});
```

<Alert level="info">
  Source map upload **only** works when `org`, `project`, and `authToken` are
  all configured. Without these options, source maps will not be uploaded to
  Sentry.
</Alert>

### Source Map Options

When you don't set `build.sourcemap` in your Vite config, the plugin turns on hidden source maps for the client and server builds, uploads them to Sentry, and removes them from the build output. Source maps that you turn on yourself are uploaded and stay in the build output.

Configure source map behavior using the [plugin options](/platforms/javascript/sourcemaps/uploading/vite/), for example:

```typescript {filename:vite.config.ts}
import { defineConfig } from "vite";
import { sentryTanstackStart } from "@sentry/tanstackstart-react/vite";
import { tanstackStart } from "@tanstack/react-start/plugin/vite";

export default defineConfig({
  plugins: [
    tanstackStart(),
    sentryTanstackStart({
      org: "___ORG_SLUG___",
      project: "___PROJECT_SLUG___",
      authToken: process.env.SENTRY_AUTH_TOKEN,

      sourcemaps: {
        assets: ["./dist/**/*"],
        ignore: ["**/node_modules/**"],
      },
    }),
  ],
});
```

To remove all source maps from the build output, also the ones you turned on, set [`sourcemaps.delete`](/platforms/javascript/sourcemaps/uploading/bundler-plugin-options/#sourcemaps.delete) to `true`. To upload the source maps yourself later, for example with `sentry-cli sourcemaps upload`, set `sourcemaps: { upload: false, delete: false }`. The plugin then uploads nothing, but it still injects debug IDs and keeps the source maps in the build output.

<Alert level="warning">
  Generating source maps **may expose them to the public**, potentially causing
  your source code to be leaked. The `sentryTanstackStart` plugin removes the
  source maps it turned on, but keeps the ones you turned on. To remove these
  too, set
  [`sourcemaps.delete: true`](/platforms/javascript/sourcemaps/uploading/bundler-plugin-options/#sourcemaps.delete),
  or ensure your server denies access to `.js.map` files.
</Alert>
