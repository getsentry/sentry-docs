The Sentry Astro SDK will generate and upload source maps automatically during a production build, so that errors in Sentry contain readable stack traces.

It uses the Sentry Vite Plugin to upload source maps. See the <PlatformLink to="/manual-setup/#configure-source-maps-upload">Manual Configuration</PlatformLink> page and the Sentry [Vite plugin documentation](/platforms/javascript/sourcemaps/uploading/bundler-plugin-options/) for more details.
