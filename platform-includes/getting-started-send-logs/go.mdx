## Send Logs

Logs are enabled by default in Go SDK `0.33.0` and later; you don't need to set `EnableLogs` in `ClientOptions`. Use `sentry.NewLogger` to send structured logs:

```go
import (
    "context"

    "github.com/getsentry/sentry-go"
)

logger := sentry.NewLogger(context.Background())
logger.Info().Emit("User signed in")
logger.Warn().Emit("Slow operation detected")
```

For logging integrations documented by the Go SDK, see [slog](/platforms/go/logs/slog/), [Logrus](/platforms/go/logs/logrus/), [Zerolog](/platforms/go/logs/zerolog/), and [Zap](/platforms/go/logs/zap/). See [Set Up Logs in Go](/platforms/go/logs/) for more options.
