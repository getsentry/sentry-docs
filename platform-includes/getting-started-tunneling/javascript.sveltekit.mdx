To keep ad blockers from dropping Sentry events, send them through a tunnel on your own origin. The SDK serves the tunnel and forwards the events to Sentry.

Set `tunnel: true` in your client `Sentry.init`, and add `serveTunnelIntegration` to your server `Sentry.init`:

<PlatformContent includePath="configuration/tunnel-server-init" />

Learn more about the options in <PlatformLink to="/configuration/integrations/servetunnel/">`serveTunnelIntegration`</PlatformLink>. To set up your own tunnel endpoint instead, see the <PlatformLink to="/configuration/tunneling/#setting-up-the-tunnel-manually">Tunneling page</PlatformLink>.
