To keep ad blockers from dropping Sentry events, send them through a tunnel on your own origin. The SDK serves the tunnel and forwards the events to Sentry.

Set `tunnel: true` in your client `Sentry.init`, and add `serveTunnelIntegration` to your server `Sentry.init`:

```javascript {filename:sentry.client.config.ts} {3}
Sentry.init({
  dsn: "___PUBLIC_DSN___",
  tunnel: true,
});
```

```javascript {filename:sentry.server.config.ts} {3}
Sentry.init({
  dsn: "___PUBLIC_DSN___",
  integrations: [Sentry.serveTunnelIntegration()],
});
```

Learn more about the options in <PlatformLink to="/configuration/integrations/servetunnel/">`serveTunnelIntegration`</PlatformLink>. To set up your own tunnel endpoint instead, see our <PlatformLink to="/troubleshooting/#using-the-tunnel-option">Troubleshooting page</PlatformLink>.
