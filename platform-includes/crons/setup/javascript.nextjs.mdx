## Automatic Check-Ins (Vercel Only)

If you are hosting your Next.js application on Vercel and you are using [Vercel's Cron Jobs feature](https://vercel.com/docs/cron-jobs), you can configure the Next.js SDK to automatically create Check-Ins for you.
Instrumented cron jobs are decided at runtime by examining the `crons` field in your `vercel.json` file.

Set `_experimental.vercelCronsMonitoring` to `true` in your Sentry settings in `next.config.js`. See <PlatformLink to="/manual-setup/pages-router/#vercel-cron-jobs-optional">Manual Setup</PlatformLink> for more details.

<Alert level="warning">
  The older `webpack.automaticVercelMonitors` option only works with Webpack and
  the Pages Router. `_experimental.vercelCronsMonitoring` works with both
  bundlers and both routers.
</Alert>
