- From the next Sentry Java SDK release (after `8.59.0`), `@SentryCheckIn(value = "<monitor-slug>", upsertMonitorConfig = true)` sends a monitor configuration based on the method's `@Scheduled` annotation, and Sentry creates the monitor on the first check-in. Otherwise, or for schedules that can't be converted, [create the monitor in Sentry](https://sentry.io/issues/alerts/new/crons/) first, because Sentry drops check-ins for a slug that has no monitor.
</PlatformSection>
