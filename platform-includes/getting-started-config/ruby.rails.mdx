Initialize the SDK within your `config/initializers/sentry.rb`:

</SplitSectionText>
<SplitSectionCode>

```ruby {filename:config/initializers/sentry.rb}
Sentry.init do |config|
  config.dsn = '___PUBLIC_DSN___'

  # Get breadcrumbs from logs
  # Learn more at
  # https://docs.sentry.io/platforms/ruby/configuration/options/#breadcrumbs_logger
  config.breadcrumbs_logger = [:active_support_logger, :http_logger]
  # ___PRODUCT_OPTION_START___ performance

  # 100% of traces in development, 10% everywhere else
  # Learn more at
  # https://docs.sentry.io/platforms/ruby/configuration/options/#traces_sample_rate
  config.traces_sample_rate = Rails.env.development? ? 1.0 : 0.1
  # ___PRODUCT_OPTION_END___ performance
  # ___PRODUCT_OPTION_START___ profiling

  # Profile 100% of sampled traces. This is relative to traces_sample_rate.
  # Learn more at
  # https://docs.sentry.io/platforms/ruby/configuration/options/#profiles_sample_rate
  config.profiles_sample_rate = 1.0
  # ___PRODUCT_OPTION_END___ profiling
end
```
