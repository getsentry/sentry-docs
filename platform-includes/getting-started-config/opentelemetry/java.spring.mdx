The Spring integration initializes the SDK and the OpenTelemetry agent provides automatic instrumentation. Add `@EnableSentry` to a Spring configuration class and set the DSN:

```java {tabTitle: Spring 5}
import io.sentry.spring.EnableSentry;

@EnableSentry(dsn = "___PUBLIC_DSN___")
@Configuration
class SentryConfiguration {}
```

```java {tabTitle: Spring 6}
import io.sentry.spring.jakarta.EnableSentry;

@EnableSentry(dsn = "___PUBLIC_DSN___")
@Configuration
class SentryConfiguration {}
```

```java {tabTitle: Spring 7}
import io.sentry.spring7.EnableSentry;

@EnableSentry(dsn = "___PUBLIC_DSN___")
@Configuration
class SentryConfiguration {}
```

Configure Tracing, Profiling, and Logs in `sentry.properties`:

```properties {filename:sentry.properties}
traces-sample-rate=1.0
profile-session-sample-rate=1.0
profile-lifecycle=TRACE
logs.enabled=true
```
