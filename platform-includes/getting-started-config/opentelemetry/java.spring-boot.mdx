The Spring Boot integration initializes the SDK when the OpenTelemetry agent is installed. Set the DSN and feature options in `application.properties` or `application.yml`:

```properties {filename:application.properties}
sentry.dsn=___PUBLIC_DSN___
sentry.traces-sample-rate=1.0
sentry.profile-session-sample-rate=1.0
sentry.profile-lifecycle=TRACE
sentry.logs.enabled=true
```

```yaml {filename:application.yml}
sentry:
  dsn: ___PUBLIC_DSN___
  traces-sample-rate: 1.0
  profile-session-sample-rate: 1.0
  profile-lifecycle: TRACE
  logs:
    enabled: true
```
