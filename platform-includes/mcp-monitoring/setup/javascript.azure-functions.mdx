Create your MCP server as usual. No Sentry-specific code is needed:

```javascript {filename:mcp-server.js}
import { McpServer } from "@modelcontextprotocol/server";

const server = new McpServer({
  name: "my-mcp-server",
  version: "1.0.0",
});
```

On SDK versions earlier than `11.1.0`, or if automatic instrumentation isn't set up for your app, import Sentry from `@sentry/node` and wrap the MCP server instance before connecting it to a transport:

```javascript {filename:mcp-server.js}
import * as Sentry from "@sentry/node";
import { McpServer } from "@modelcontextprotocol/server";

const server = Sentry.wrapMcpServerWithSentry(
  new McpServer({
    name: "my-mcp-server",
    version: "1.0.0",
  })
);
```

The wrapper returns the same server instance. Wrapping a server the SDK already instrumented doesn't instrument it twice.
