```cpp
#include <sentry.h>

sentry_value_t event = sentry_value_new_message_event(
    SENTRY_LEVEL_INFO, "my-logger", "Hello user feedback!");
sentry_uuid_t event_id = sentry_capture_event(event);

sentry_value_t user_feedback = sentry_value_new_feedback(
    "Feedback message", "jane.doe@example.com", "Jane", &event_id);
sentry_capture_feedback(user_feedback);
```

Only the message is required. Pass `NULL` for the contact email or name when you don't collect them, and `NULL` for the event ID to send feedback that isn't tied to a specific event.

### What Gets Sent With Feedback

Since SDK version [0.16.0](https://github.com/getsentry/sentry-native/releases/tag/0.16.0), feedback carries the global scope's data: release, environment, tags, user, and contexts including the trace, along with any attachments set on the scope. Feedback from a session therefore lands on the same trace as that session's errors. The SDK deliberately leaves off breadcrumbs, modules, and stack traces.

Feedback does **not** go through `before_send`. To filter or enrich it, use <PlatformLink to="/configuration/options/#before_send_feedback">`before_send_feedback`</PlatformLink>.

### Attaching Files to Feedback

Use a hint to send files alongside a single feedback, such as a screenshot or a diagnostic log the user agreed to share:

```c
sentry_hint_t *hint = sentry_hint_new();
sentry_hint_attach_file(hint, "/var/log/last-session.log");

// Takes ownership of both the feedback and the hint.
sentry_capture_feedback_with_hint(user_feedback, hint);
```

### Capturing Feedback Against a Scope

Feedback usually arrives from a specific place in your UI, and tagging it on the global scope would mark every other event the same way. `sentry_scope_capture_feedback()` keeps that context local: it layers a scope's data on top of the global scope and returns the feedback's event ID.

```c
sentry_scope_t *scope = sentry_local_scope_new();
sentry_scope_set_tag(scope, "feedback.surface", "settings-dialog");

// Pass NULL for the hint when no extra attachments are needed.
sentry_uuid_t feedback_id
    = sentry_scope_capture_feedback(scope, user_feedback, NULL);
```

The scope follows the usual <PlatformLink to="/enriching-events/scopes/#who-frees-the-scope">ownership rules</PlatformLink>: a local scope is freed for you, a reusable one is not.

<Alert>

`sentry_value_new_user_feedback` and `sentry_capture_user_feedback` are deprecated. They produce the older User Report envelope item, which doesn't carry scope data or attachments. Use `sentry_value_new_feedback` and `sentry_capture_feedback` instead.

</Alert>
