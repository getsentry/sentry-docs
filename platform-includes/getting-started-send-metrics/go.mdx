## Send Application Metrics <FeatureBadge type="new" />

Application Metrics are supported in Go SDK `0.42.0` and later. They don't require an additional `ClientOptions` option. Create a meter and record counters, gauges, or distributions:

```go
import (
    "context"

    "github.com/getsentry/sentry-go"
)

meter := sentry.NewMeter(context.Background())
meter.Count("checkout.failed", 1)
meter.Gauge("queue.depth", 4.0)
meter.Distribution("api.latency", 187.0, sentry.WithUnit(sentry.UnitMillisecond))
```

See [Set Up Metrics for Go](/platforms/go/metrics/) for metric attributes, units, and trace linking.
