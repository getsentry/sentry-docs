### beforeSendMetric

Filter or modify metrics before sending. The callback receives a metric and a `Hint`; return `null` to drop the metric. On SDK v9, the callback takes only the metric parameter.

</SplitSectionText>
<SplitSectionCode>

```dart
import 'package:sentry_flutter/sentry_flutter.dart';

await SentryFlutter.init((options) {
  options.dsn = '___PUBLIC_DSN___';
  options.beforeSendMetric = (metric, hint) {
    // Drop specific metrics
    if (metric.attributes.containsKey('debug')) {
      return null;
    }

    // Return the metric to send it
    return metric;
  };
});
```

</SplitSectionCode>

### Disable Metrics

Metrics are captured when you call `Sentry.metrics.*`; there is no option to turn them on or off. To stop sending metrics without removing those calls, return `null` from `beforeSendMetric`.

<Alert>

On SDK v9, set `options.enableMetrics = false` in `SentryFlutter.init` to disable metrics instead.

</Alert>

</SplitSectionText>
<SplitSectionCode>

```dart
import 'package:sentry_flutter/sentry_flutter.dart';

await SentryFlutter.init((options) {
  options.dsn = '___PUBLIC_DSN___';
  options.beforeSendMetric = (metric, hint) => null;
});
```
