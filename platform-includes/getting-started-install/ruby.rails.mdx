Add the `sentry-ruby`, `sentry-rails`, and `stackprof` gems to your `Gemfile`. `stackprof` enables Profiling; keep it before `sentry-ruby` so it loads first:

</SplitSectionText>
<SplitSectionCode>

```ruby {filename:Gemfile}
gem "stackprof"
gem "sentry-ruby"
gem "sentry-rails"
```
