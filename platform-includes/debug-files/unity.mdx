The Unity SDK uploads debug files automatically during the build. To upload them yourself, use the `debug-files upload` command. It scans the given folder recursively and uploads the files it finds to Sentry. For IL2CPP builds, pass `--il2cpp-mapping` to also upload the line mapping for C# line numbers:

```bash
sentry-cli debug-files upload --il2cpp-mapping --org ___ORG_SLUG___ --project ___PROJECT_SLUG___ PATH_TO_BUILD_OUTPUT
```

For details on what the SDK uploads on each platform, see [Debug Symbols](/platforms/unity/native-support/#debug-symbols).
