The Sentry Native SDK is intended for C and C++. However, since it builds as a dynamic library and exposes C-bindings, it can be used by any language that supports interoperability with C, such as the Foreign Function Interface (FFI).

It also provides native crash reporting for other Sentry SDKs:

- [_Android (NDK)_](/platforms/android/configuration/using-ndk/)
- [_Flutter_](/platforms/dart/guides/flutter/)
- [_Godot_](/platforms/godot/)
- [_.NET_](/platforms/dotnet/)
- [_Unity_](/platforms/unity/)
- [_Unreal Engine_](/platforms/unreal/)

Sentry's console SDKs also build on the Native SDK. See the [Nintendo Switch](/platforms/nintendo-switch/), [PlayStation](/platforms/playstation/), and [Xbox](/platforms/xbox/) documentation to get access.

Sentry also offers higher-level SDKs for platforms with built-in support for native crashes:

- [_Android_](/platforms/android/)
- [_Apple (Cocoa)_](/platforms/apple/)
- [_Electron_](/platforms/javascript/guides/electron/)
