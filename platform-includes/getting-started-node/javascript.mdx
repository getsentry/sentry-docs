## Configure

**Error Monitoring** starts working as soon as you call `Sentry.init()`. **Logs** and **Application Metrics** need no extra configuration, and you'll learn how to send them in steps [#3](#send-logs) and [#4](#send-application-metrics-).
This guide also enables **Tracing** and **Profiling**.

<Include name="quick-start-features-expandable" />

### Initialize the Sentry SDK

To import and initialize Sentry, create a file named `instrument.(js|mjs)` in the root directory of your project and add the code shown below.

The snippet also turns on:
- Tracing: via <PlatformLink to="/configuration/options/#tracesSampleRate">`tracesSampleRate`</PlatformLink>
- Profiling: via <PlatformLink to="/configuration/options/#profileSessionSampleRate">`profileSessionSampleRate`</PlatformLink> and `nodeProfilingIntegration()`

<PlatformContent includePath="getting-started-config" />

Then, use the [--import](https://nodejs.org/api/cli.html#--importmodule) command line option and point it to your `instrument.(js|mjs)` file to load the module before the application starts:

```bash {tabTitle:CommonJS}
node --import ./instrument.js app.js
```

```bash {tabTitle:ESM}
node --import ./instrument.mjs app.mjs
```

If you are using a bundler like vite, you can also <PlatformLink to="/install/bundler/">follow the bundler setup docs</PlatformLink> instead.
