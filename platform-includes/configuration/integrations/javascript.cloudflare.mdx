When you build with the Sentry Cloudflare Vite plugin, the SDK also adds an integration for each supported package in your bundle, such as [OpenAI](./openai/), [Anthropic](./anthropic/), or [Postgres](./postgres/). To configure them, see <PlatformLink to="/install/vite-plugin/#configure-integrations">Configure Integrations</PlatformLink>.

[Mistral AI](./mistral/) is automatically instrumented when built with the Sentry Cloudflare Vite plugin. Without the plugin, use `instrumentMistralAiClient`.

The [`prismaIntegration`](./prisma/) needs the `nodejs_compat` compatibility flag on your Worker.
