The Cordova SDK tracks sessions by default using the native iOS and Android SDKs. A session starts when the app starts, and ends when the app has been in the background for longer than the <PlatformLink to="/configuration/options/#sessionTrackingIntervalMillis">`sessionTrackingIntervalMillis`</PlatformLink> option (30 seconds by default).

To disable the default sessions handling, set <PlatformLink to="/configuration/options/#enableAutoSessionTracking">`enableAutoSessionTracking`</PlatformLink> to `false`:

```javascript
Sentry.init({
  dsn: "___PUBLIC_DSN___",
  enableAutoSessionTracking: false,
});
```

Sessions are marked as:

- `crashed` if the app crashes on the native layer.
- `errored` if the SDK captures an event that contains an exception (this includes manually captured errors).

To receive data on user adoption, such as users crash free rate percentage, and the number of users that have adopted a specific release, set the user on the <PlatformLink to="/configuration/options/#initialScope">`initialScope`</PlatformLink> when initializing the SDK.
