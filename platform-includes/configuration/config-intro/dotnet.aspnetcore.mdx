Options can be set by passing a callback to the `UseSentry()` method which will
pass the option object along for modifications:

```csharp
var builder = WebApplication.CreateBuilder(args);

builder.WebHost.UseSentry(o => {
                o.Dsn = "___PUBLIC_DSN___";
                o.MaxBreadcrumbs = 50;
                o.Debug = true;
                o.SendDefaultPii = true;
            });
```

```fsharp
let builder = WebApplication.CreateBuilder(args)

builder.WebHost.UseSentry(fun o ->
                o.Dsn <- "___PUBLIC_DSN___"
                o.MaxBreadcrumbs <- 50
                o.Debug <- true
                o.SendDefaultPii <- true
            ) |> ignore
```

Additionally, you can set your options on `appsettings.json` when using `UseSentry()`:


```json {filename:appsettings.json}
  "Sentry": {
    "Dsn": "___PUBLIC_DSN___",
    "MaxBreadcrumbs": 50,
    "Debug": true,
    "SendDefaultPii": true
  }
```

<Alert title="Note">

You can configure the Sentry options inside of the `UseSentry` callback or through `appsettings.json`. The settings from `appsettings.json` will be applied before the callback is invoked.

</Alert>
