Pass the options to `UseSentry` in a callback:

```csharp {filename:Program.cs}
var builder = Host.CreateApplicationBuilder(args);
builder.UseSentry(options =>
{
    options.Dsn = "___PUBLIC_DSN___";
    options.MaxBreadcrumbs = 50;
    options.Debug = true;
    options.SendDefaultPii = true;
});
```

You can also set them in the `Sentry` section of `appsettings.json`:

```json {filename:appsettings.json}
{
  "Sentry": {
    "Dsn": "___PUBLIC_DSN___",
    "MaxBreadcrumbs": 50,
    "Debug": true,
    "SendDefaultPii": true
  }
}
```

`UseSentry` applies the configuration first and then runs the callback, so a value set in the callback wins.

<Alert>

After you have configured Sentry in your code, you can also configure the
[MSBuild setup](/platforms/dotnet/configuration/msbuild/) for your project. While this step is optional,
it can greatly improve your Sentry experience.

</Alert>
