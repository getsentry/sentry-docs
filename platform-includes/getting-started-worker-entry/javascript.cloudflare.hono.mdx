You don't need to change your Worker entry. The plugin wraps the Hono app that you export as default and instruments Hono. The SDK names each request after its route, for example `GET /users/:id`, creates a span for each middleware, and captures errors from your routes and middleware.

```typescript {filename:src/index.ts}
import { Hono } from "hono";

const app = new Hono();

app.get("/users/:id", (c) => {
  return c.json({ id: c.req.param("id") });
});

export default app;
```

Hono support needs `@sentry/cloudflare` version `11.2.0` or above.
