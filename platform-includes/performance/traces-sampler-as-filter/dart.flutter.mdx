```dart
await SentryFlutter.init((options) {
  options.tracesSampler = (samplingContext) {
    final spanContext = samplingContext.spanContext;
    if (spanContext.name == 'health-check') {
      return 0.0;
    }
    return 0.1;
  };
});
```

This example uses stream mode, the default in v10. Filter service spans using `spanContext.name` or `spanContext.attributes`. For transaction mode, explicitly set `options.traceLifecycle = SentryTraceLifecycle.static` and use `samplingContext.transactionContext` instead.
