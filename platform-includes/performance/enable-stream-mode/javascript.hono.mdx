<SplitSectionText>

Stream mode is the default. To set it explicitly, pass the `traceLifecycle` option when initializing the SDK:

</SplitSectionText>
<SplitSectionCode>

```javascript {tabTitle:Cloudflare Workers}
import { sentry } from "@sentry/hono/cloudflare";

app.use(
  sentry(app, {
    dsn: "___PUBLIC_DSN___",
    tracesSampleRate: 1.0,
    // stream mode is the default
    traceLifecycle: "stream",
  })
);
```

```javascript {tabTitle:Node.js} {filename: instrument.mjs}
import * as Sentry from "@sentry/hono/node";

Sentry.init({
  dsn: "___PUBLIC_DSN___",
  tracesSampleRate: 1.0,
  // stream mode is the default
  traceLifecycle: "stream",
});
```

```javascript {tabTitle:Bun}
import { sentry } from "@sentry/hono/bun";

app.use(
  sentry(app, {
    dsn: "___PUBLIC_DSN___",
    tracesSampleRate: 1.0,
    // stream mode is the default
    traceLifecycle: "stream",
  })
);
```

</SplitSectionCode>
</SplitSection>
</SplitLayout>

To use transaction mode instead, set `traceLifecycle` to `'static'`. Transaction mode exists for backwards compatibility and will be removed in a future major version.
