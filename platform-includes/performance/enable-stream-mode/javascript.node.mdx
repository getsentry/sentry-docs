<SplitSectionText>

Stream mode is the default. To set it explicitly, pass the `traceLifecycle` option when initializing the SDK:

</SplitSectionText>
<SplitSectionCode>

```javascript {tabTitle:CommonJS} {filename: instrument.js}
const Sentry = require("@sentry/node");

Sentry.init({
  dsn: "___PUBLIC_DSN___",
  tracesSampleRate: 1.0,
  // stream mode is the default
  traceLifecycle: "stream",
});
```

```javascript {tabTitle:ESM} {filename: instrument.mjs}
import * as Sentry from "@sentry/node";

Sentry.init({
  dsn: "___PUBLIC_DSN___",
  tracesSampleRate: 1.0,
  // stream mode is the default
  traceLifecycle: "stream",
});
```

</SplitSectionCode>
</SplitSection>
</SplitLayout>

To use transaction mode instead, set `traceLifecycle` to `'static'`. Transaction mode exists for backwards compatibility and will be removed in a future major version.
