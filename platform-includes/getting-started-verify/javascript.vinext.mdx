Let's test your setup and confirm that Sentry is working correctly and sending data to your Sentry project.

1. Add a route handler that throws an error:

   ```typescript {filename:app/api/sentry-example-api/route.ts}
   export const dynamic = "force-dynamic";

   export async function GET() {
     throw new Error("Sentry Test Error");
   }
   ```

2. Build your app and run it in the Workers runtime on your machine:

   ```bash
   npx vinext build && npx wrangler dev --config dist/server/wrangler.json
   ```

3. Open `/api/sentry-example-api` on the URL that the command prints.

### View Captured Data in Sentry

Now, head over to your project on [Sentry.io](https://sentry.io/) to view the collected data (it takes a couple of moments for the data to appear). The error and the trace of the request have the same trace ID.
