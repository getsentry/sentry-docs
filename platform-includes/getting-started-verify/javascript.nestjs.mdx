### Issues

First, let's verify that Sentry captures errors and creates issues in your Sentry project. Add the following route to your application, which will trigger an error that Sentry will capture.

```javascript
@Get("/debug-sentry")
  getError() {
    throw new Error("My first Sentry error!");
  }
```

### Tracing

To test your tracing configuration, update the previous code snippet to start a span around the error. The span is recorded as part of the request's trace.

```javascript {filename:app.controller.ts}
import { Controller, Get } from "@nestjs/common";
import * as Sentry from "@sentry/nestjs";

@Controller()
export class AppController {
  @Get("/debug-sentry")
  getError() {
    return Sentry.startSpan(
      {
        op: "test",
        name: "My First Test Span",
      },
      () => {
        throw new Error("My first Sentry error!");
      }
    );
  }
}
```
