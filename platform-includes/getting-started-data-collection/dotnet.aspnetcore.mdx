Starting with version 7.1.0, you can choose which categories of data the SDK collects by calling <PlatformLink to="/configuration/options/#ConfigureDataCollection">`ConfigureDataCollection`</PlatformLink> in the options you pass to `UseSentry`.

Calling `ConfigureDataCollection` applies the Data Collection defaults, which collect every category, including user identity such as the signed-in user and their IP address. The SDK always replaces sensitive values whose keys match a built-in deny list, such as `auth` or `password`, with `[Filtered]`. `SendDefaultPii` no longer controls these categories. Turn off the ones you don't need:

```csharp {4-7}
builder.WebHost.UseSentry(options =>
{
    options.Dsn = "___PUBLIC_DSN___";
    options.ConfigureDataCollection(dataCollection =>
    {
        dataCollection.UserInfo = false;
    });
});
```

`ConfigureDataCollection` is experimental, so calling it produces the `SENTRY0001` compiler diagnostic. Suppress it with `#pragma warning disable SENTRY0001`, or for the whole project with `<NoWarn>$(NoWarn);SENTRY0001</NoWarn>`.

You can also configure Data Collection in `appsettings.json`, under `Sentry:DataCollection`. The section opts you in just like calling `ConfigureDataCollection`:

```json {filename:appsettings.json}
{
  "Sentry": {
    "Dsn": "___PUBLIC_DSN___",
    "DataCollection": {
      "UserInfo": false
    }
  }
}
```

For the full list of categories and their defaults, <PlatformLink to="/configuration/options/#ConfigureDataCollection">see the `ConfigureDataCollection` option</PlatformLink>.
