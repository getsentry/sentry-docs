Starting with version 7.1.0, you can choose which categories of data the SDK collects with <PlatformLink to="/configuration/options/#ConfigureDataCollection">Data Collection</PlatformLink>. Add a `DataCollection` section to the `Sentry` section of `appsettings.json`.

The section applies the Data Collection defaults, which collect every category, including user identity such as the signed-in user and their IP address. The SDK always replaces sensitive values whose keys match a built-in deny list, such as `auth` or `password`, with `[Filtered]`. `SendDefaultPii` no longer controls these categories. Turn off the ones you don't need:

```json {filename:appsettings.json}
{
  "Sentry": {
    "Dsn": "___PUBLIC_DSN___",
    "DataCollection": {
      "UserInfo": false
    }
  }
}
```

For the full list of categories and their defaults, <PlatformLink to="/configuration/options/#ConfigureDataCollection">see the `ConfigureDataCollection` option</PlatformLink>.
