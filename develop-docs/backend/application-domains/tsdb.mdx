title: Time-series Storage

Sentry provides a service to store time-series data. Primarily this is used to display aggregate information for events and projects, as well as calculating (in real-time) the rates of events.

## The Snuba backend (recommended)

```python
SENTRY_TSDB = 'sentry.tsdb.snuba.SnubaTSDB'
```

This backend reads event ingestion related metrics from Snuba. Writes are no-ops, because Snuba already stores the data the time series are built from. Snuba needs to have its own outcomes consumer running, which is currently not part of devservices.

`sentry.tsdb.redis.RedisTSDB` was removed in Sentry 26.10.1, and `sentry.tsdb.redissnuba.RedisSnubaTSDB` in 26.11.0. The `RedisSnubaTSDB` path is still accepted: it resolves to `SnubaTSDB` and logs a deprecation warning.

## The Dummy Backend

As its name implies, _all_ TSDB data will be dropped on write and substituted with zeroes on read:

```python
SENTRY_TSDB = 'sentry.tsdb.dummy.DummyTSDB'
```
