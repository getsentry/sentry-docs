title: AI Agents Module
---

The AI Agents module is agnostic to the library used. The SDK will instrument existing AI agents in certain frameworks or libraries (at the time of writing those are `openai-agents` in Python and `Vercel AI` in Javascript). You may need to manually annotate spans for other libraries.

## Spans Conventions

For your AI agents data to show up in the Sentry [Agents Dashboard](https://sentry.io/orgredirect/organizations/:orgslug/dashboards/), at least one of the AI spans needs to be created and have well-defined names and data attributes. If the required data (marked with MUST or required) is missing, the data will not show up in the Agents dashbboard.

We try to follow [v1.36.0](https://github.com/open-telemetry/semantic-conventions/blob/v1.36.0/docs/gen-ai/README.md) of the [OpenTelemetry Semantic Conventions](https://opentelemetry.io/docs/specs/semconv/gen-ai/) for Generative AI as close as possible. Being 100% compatible is not yet possible, because OpenTelemetry has "Span Events" which Sentry does not support. The input from/output to an AI model is stored in span events in OpenTelemetry. Since this is not possible in Sentry, we add this data onto span attributes as a list.

<Alert level="success" title="Hint">
The [Sentry Conventions](https://github.com/getsentry/sentry-conventions/) have all the detailed specifications for `"gen_ai.*"` span attributes.

Sentry Conventions is the single source of truth.

</Alert>

## Invoke Agent Span

Describes AI agent invocation.
Agent invocations represent operations that can include multiple model calls, or some auxiliary work that goes beyond transforming the model input and output.

- Span `op` **SHOULD** be `"gen_ai.invoke_agent"`.
- Span `name` **SHOULD** be `"invoke_agent {gen_ai.agent.name}"`. (e.g. `"invoke_agent Weather Agent"`) **[4]**
- Attribute `gen_ai.operation.name` **MUST** be `"invoke_agent"`.
- Attribute `gen_ai.agent.name` **SHOULD** be set to the agent's name. (e.g. `"Weather Agent"`). As a fallback to `gen_ai.agent.name`, the product also interprets `gen_ai.function_id` as an agent name for libraries that let users set a tracing identifier on a per-invocation basis.
- If relevant, the `gen_ai.pipeline.name` attribute **SHOULD** be set to the name of the AI workflow, pipeline or chain within which the agent operates. (e.g. `"weather-pipeline"`)
- As a fallback to missing inputs and outputs on child chat spans, the Invoke Agent Span can carry `gen_ai.input.messages` and `gen_ai.system_instructions` based on the input of the first model call, and `gen_ai.output.messages` based on the output of the final model call under the agent execution.

## AI Client Span

This span represents a request to an AI model or service that generates a response or requests a tool call based on the input prompt.

- Span `op` **SHOULD** be `"gen_ai.{gen_ai.operation.name}"`. (e.g. `"gen_ai.chat"`)
- Span `name` **SHOULD** be `"{gen_ai.operation.name} {gen_ai.request.model}"`. (e.g. `"chat o3-mini"`)
- Attribute `gen_ai.operation.name` **MUST** be `"chat"`, `"embeddings"`, `"generate_content"` or `"text_completion"`.
- Attribute `gen_ai.provider.name` **MUST** be the Generative AI product as identified by the client or server instrumentation. (e.g. `"openai"`)
- Attribute `gen_ai.request.model` **MUST** be the requested model. (e.g. `"gpt-4o"`)
- Attribute `gen_ai.response.model` **MUST** be the concrete response model. (e.g. `"gpt-4o-2024-08-06"`)
- If the request originates from an agent, the `gen_ai.agent.name` attribute **SHOULD** be set to the name of the agent. (e.g. `"Weather Agent"`). As a fallback to `gen_ai.agent.name`, the product also interprets `gen_ai.function_id` as an agent name for libraries that let users set a tracing identifier on a per-invocation basis.
- If relevant, the `gen_ai.pipeline.name` attribute **SHOULD** be set to the name of the AI workflow, pipeline or chain within which the agent operates. (e.g. `"weather-pipeline"`)

## Execute Tool Span

Describes a tool execution.

- Span `op` **SHOULD** be `"gen_ai.execute_tool"`.
- Span `name` **SHOULD** be `"execute_tool {gen_ai.tool.name}"`. (e.g. `"execute_tool query_database"`)
- Attribute `gen_ai.operation.name` **MUST** be `"execute_tool"`.
- Attribute `gen_ai.agent.name` **SHOULD** be set to the name of the agent that invoked the tool. (e.g. `"Weather Agent"`). As a fallback to `gen_ai.agent.name`, the product also interprets `gen_ai.function_id` as an agent name for libraries that let users set a tracing identifier on a per-invocation basis.
- If relevant, the `gen_ai.pipeline.name` attribute **SHOULD** be set to the name of the AI workflow, pipeline or chain within which the agent operates. (e.g. `"weather-pipeline"`)

Additional attributes on the span:

| Attribute                    | Type   | Description                                                                                                    | Example                                    |
| :--------------------------- | :----- | :------------------------------------------------------------------------------------------------------------- | :----------------------------------------- |
| `gen_ai.tool.name`           | string | Name of the tool executed.                                                                                     | `"random_number"`                          |
| `gen_ai.tool.description`    | string | Description of the tool executed.                                                                              | `"Tool returning a random number"`         |
| `gen_ai.tool.call.arguments` | string | Arguments of the tool call (stringified).                                                                      | `'{"max":10}'`                             |
| `gen_ai.tool.call.result`    | string | Result of the tool call (stringified).                                                                         | `"7"`                                      |

## Decision Span

Describes a decision on generated content against a set of questions, such as grading a model's reply for accuracy or classifying a support message, for example from TypeSafe Jev. Sentry shows decisions as their own rows in the conversation transcript and timeline, with dedicated **Input** and **Output** views.

- Span `op`: `"gen_ai.decide"`
- Span `name`: `"decide {gen_ai.request.model}"` (e.g. `"decide typesafe/jev-1.13"`)
- `gen_ai.operation.name`: `"decide"`. Decisions share the `ai_client` operation type with model calls, so this attribute is what tells them apart.

| Attribute                    | Type   | Description                                                                                                                                                                                                         | Example                                                                                                    |
| :--------------------------- | :----- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :--------------------------------------------------------------------------------------------------------- |
| `gen_ai.request.model`       | string | The evaluation model the SDK asked for. Drives model breakdowns, cost, and the span title. Without a model, Relay doesn't classify the span as `ai_client`.                                                         | `"typesafe/jev-1.13"`                                                                                      |
| `gen_ai.response.model`      | string | The concrete model that responded. Omit it when the provider doesn't report one.                                                                                                                                    | `"typesafe/jev-1.13-20260917"`                                                                             |
| `gen_ai.usage.input_tokens`  | int    | Input tokens used by the evaluation. Drives token widgets and cost.                                                                                                                                                 | `154`                                                                                                      |
| `gen_ai.usage.output_tokens` | int    | Output tokens used by the evaluation. Drives token widgets and cost.                                                                                                                                                | `28`                                                                                                       |
| `gen_ai.agent.name`          | string | The agent the decision ran under. Omit it when the decision runs outside an agent.                                                                                                                                  | `"Support Agent"`                                                                                          |
| `gen_ai.input.messages`      | string | The content being evaluated and the questions asked about it, as a one-element array holding one object. Shown in the decision **Input** view. See [Decision Input Messages](#decision-input-messages).             | `'[{"state": "...", "questions": {"accuracy": {"type": "score", "criteria": ["incorrect", "correct"]}}}]'` |
| `gen_ai.output.messages`     | string | The answers, as a one-element array holding one object. Shown in the decision **Output** view and as the one-line result in the transcript and timeline. See [Decision Output Messages](#decision-output-messages). | `'[{"answers": {"accuracy": {"type": "score", "score": 1}}}]'`                                             |

### Decision Input Messages

`gen_ai.input.messages` holds a one-element array: `[{"state", "questions"}]`. Copy `state` and the questions as the caller passed them. If the provider uses a different layout, convert it to this layout. `<name>` is the question key.

| Field                           | Type                   | Required                 | Description                                                                                                                                                             | Example                                                 |
| :------------------------------ | :--------------------- | :----------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------ |
| `state`                         | any                    | Yes                      | The content being evaluated: a string, an object, or a message array, as the caller passed it. Replace binary data, including `data:` URLs, with `"[Blob substitute]"`. | `"I was charged twice and want a refund."`              |
| `questions`                     | object                 | Yes                      | The questions, keyed by question name.                                                                                                                                  | `{"urgency": {...}}`                                    |
| `questions.<name>.type`         | string                 | Yes                      | `"boolean"`, `"predicate"`, `"noul"`, `"choice"`, or `"score"`. Copy other values as they are.                                                                          | `"choice"`                                              |
| `questions.<name>.instructions` | string                 | Yes                      | The question text.                                                                                                                                                      | `"Which team should handle this?"`                      |
| `questions.<name>.criteria`     | object or string array | For `choice` and `score` | For `choice`, an object that maps each option to its description. For `score`, an ordered array of labels. The index is the score.                                      | `{"billing": "Charges and refunds"}`, `["low", "high"]` |
| `questions.<name>.descriptions` | object                 | No                       | Only for `score`. Maps a score index (as a string) to the description of that level. Omit the levels that have no description.                                          | `{"1": "Blocks the customer"}`                          |

### Decision Output Messages

`gen_ai.output.messages` holds a one-element array: `[{"answers"}]`. `answers` uses the same keys as `questions`, and each answer has a `type` that matches its question.

| Field                          | Type   | Required                      | Description                                                                                           | Example                                |
| :----------------------------- | :----- | :---------------------------- | :---------------------------------------------------------------------------------------------------- | :------------------------------------- |
| `answers`                      | object | Yes                           | The answers, keyed by question name.                                                                  | `{"urgency": {...}}`                   |
| `answers.<name>.type`          | string | Yes                           | The type of the question.                                                                             | `"score"`                              |
| `answers.<name>.probability`   | number | For `boolean` and `predicate` | The probability that the answer is yes. Shown as Yes when it's 0.5 or higher.                         | `0.97`                                 |
| `answers.<name>.noul`          | number | For `noul`                    | The probability that the answer is yes. Jev's variant of `boolean`.                                   | `0.98`                                 |
| `answers.<name>.choice`        | string | For `choice`                  | The selected option.                                                                                  | `"billing"`                            |
| `answers.<name>.score`         | number | For `score`                   | The score. It can be a fraction between two levels.                                                   | `1.58`                                 |
| `answers.<name>.probabilities` | object | No                            | Only for `choice` and `score`. Maps each option, or each score index as a string, to its probability. | `{"billing": 0.64, "technical": 0.36}` |
| `answers.<name>.legend`        | object | No                            | Only for `score`. Maps each score index (as a string) to its label.                                   | `{"0": "low", "1": "high"}`            |
| `answers.<name>.confidence`    | number | No                            | Only for `choice` and `score`. The confidence of the answer.                                          | `0.28`                                 |

Omit optional fields when the provider doesn't report them. A field with the wrong type makes that question or answer unreadable, and Sentry shows it raw.

## Extraction Span

Describes an extraction of typed fields from an input, such as the total and due date of an invoice, for example from Cloudflare Clairic. The model can extract values that are in the input, compute values from them, and estimate or forecast values that the input doesn't determine.

- Span `op`: `"gen_ai.extract"`
- Span `name`: `"extract {gen_ai.request.model}"` (e.g. `"extract @cf/cloudflare/clairic"`)
- `gen_ai.operation.name`: `"extract"`

| Attribute                    | Type   | Description                                                                                                                                  | Example                                                                                         |
| :--------------------------- | :----- | :------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------- |
| `gen_ai.request.model`       | string | The extraction model the SDK asked for. Drives model breakdowns, cost, and the span title.                                                   | `"@cf/cloudflare/clairic"`                                                                      |
| `gen_ai.response.model`      | string | The concrete model that responded. Omit it when the provider doesn't report one.                                                             | `"clairic"`                                                                                     |
| `gen_ai.usage.input_tokens`  | int    | Input tokens used by the extraction, including all passes. Drives token widgets and cost.                                                    | `655`                                                                                           |
| `gen_ai.usage.output_tokens` | int    | Output tokens used by the extraction. Drives token widgets and cost.                                                                         | `0`                                                                                             |
| `gen_ai.agent.name`          | string | The agent the extraction ran under. Omit it when the extraction runs outside an agent.                                                       | `"Billing Agent"`                                                                               |
| `gen_ai.input.messages`      | string | The input and the field specs, as a one-element array holding the request body. See [Extraction Input Messages](#extraction-input-messages). | `'[{"state": "Invoice INV-2291 ...", "fields": {"total": {"type": "number", "unit": "USD"}}}]'` |
| `gen_ai.output.messages`     | string | The answers, as a one-element array holding the response body. See [Extraction Output Messages](#extraction-output-messages).                | `'[{"answers": {"total": {"type": "number", "value": 1080}}, "truncated": false}]'`             |

Don't send the other usage counts that the provider reports (such as Clairic's `state_tokens`, `image_tokens`, `schema_tokens`, and `passes`). `gen_ai.usage.input_tokens` already includes them.

**[0]:**

Span attributes only allow primitive data types (like `int`, `float`, `boolean`, `string`). This means you need to use a stringified version of a list of dictionaries. Do NOT set the object/array `[{"foo": "bar"}]` but rather the string `'[{"foo": "bar"}]'` (must be parsable JSON).

**[1]:**

Messages use the format `{role, parts}` where `parts` is an array of typed objects: `[{"role": "user", "parts": [{"type": "text", "content": "..."}]}]`. The `role` must be `"user"`, `"assistant"`, `"tool"`, or `"system"`. Each part has a `type`; common types include `"text"` (user-visible content), `"reasoning"` (internal thinking/chain-of-thought), `"tool_call"`, and `"tool_call_response"`. Use `{"type": "reasoning", "content": "..."}` for the model's thinking output — Sentry surfaces it separately and does not render it as a user-visible message in Conversations, so do not represent thinking content as a `"text"` part. For backwards compatibility, the legacy format `{role, content}` is also accepted.

**[2]:**

Cached tokens are a subset of input tokens; `gen_ai.usage.input_tokens` includes `gen_ai.usage.cache_read.input_tokens`.

**[3]:**

Reasoning tokens are a subset of output tokens; `gen_ai.usage.output_tokens` includes `gen_ai.usage.reasoning.output_tokens`.

**[4]**

In some agent libraries, the agent name is optional, and some do not provide the user an option to name their agents.
In these cases, the span name **SHOULD** be `"invoke_agent {call_id}"`, where `call_id` is some user-provided identifier for the agent invocation. For example, `functionId` in Vercel AI.
