The **Sentry Cookbook** is a collection of recipes: concrete, timed walkthroughs for a specific job you want to get done with Sentry. Docs explain how a feature works. Recipes show you how to wire a full workflow end-to-end.

Use cookbook when you want to:

- Go one step further after setup (monitor an agent, triage overnight errors, ship a fix from Slack)
- Deep-dive a particular subject with a partnered tool (Claude Code, Cursor, Linear, Supabase)
- Copy a proven pattern instead of inventing the wiring yourself

Recipes live on the marketing site and stay the source of truth. This page is the docs front door — a short explainer plus the highest-traffic starting points.
