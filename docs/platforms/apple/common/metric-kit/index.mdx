[MetricKit](https://developer.apple.com/documentation/metrickit) is an Apple service that runs in the operating system and provides diagnostic and metric reports about your app on your users' devices. The MetricKit integration converts two kinds of MetricKit data:

- **Diagnostic reports**, such as app hangs, CPU and disk write exceptions, or slow app launches, become Sentry error events. Learn more in <PlatformLink to="/metric-kit/diagnostic-reports/">App Hangs and Other Diagnostic Reports</PlatformLink>.
- **Metric reports**, such as CPU time, network transfer, memory and app exit counts, become <PlatformLink to="/metrics/">Application Metrics</PlatformLink>. Learn more in <PlatformLink to="/metric-kit/metric-reports/">Metric Reports</PlatformLink>.

The integration is disabled by default, and you enable diagnostic reports and metric reports separately.

## Prerequisites

- SDK version 8.14.0 or later for hang, CPU exception and disk write exception diagnostic reports.
- SDK version 9.32.0 or later for app launch, crash and memory exception diagnostic reports, and for metric reports. Some of these diagnostic reports are only available on newer OS versions, which are listed in <PlatformLink to="/metric-kit/diagnostic-reports/#choose-diagnostic-reports">Choose Diagnostic Reports</PlatformLink>.
- iOS 15 and later, macOS 12 and later, or visionOS. MetricKit isn't available on tvOS and watchOS.

## Delayed Data

MetricKit reports data after it was recorded. It can deliver a diagnostic report while the app that recorded it is still running, or on a later launch, and it delivers metric payloads at most once a day. The SDK sends this data with the app and OS versions it was recorded with, instead of the versions running when MetricKit delivered it. Learn more in Apple's description of the [MetricKit reporting model](https://developer.apple.com/documentation/metrickit/monitoring-app-performance-with-metrickit#Understand-the-reporting-model).
