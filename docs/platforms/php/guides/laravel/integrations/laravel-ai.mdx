<Alert>

This feature is currently in Beta. Beta features are still in progress and may have bugs. We recognize the irony.

</Alert>

The Laravel AI integration connects Sentry with the [Laravel AI](https://laravel.com/docs/13.x/ai-sdk) package. It's enabled by default once `laravel/ai` is installed and <PlatformLink to="/tracing/">tracing</PlatformLink> is active, and it powers Agent Tracing for Laravel applications: agent invocations, LLM requests, tool executions, embeddings, token usage, and conversation IDs.

For requirements, configuration, supported providers, privacy controls, and verification, see <PlatformLink to="/agent-tracing/">Set Up Agent Tracing</PlatformLink>.
