On Lambda, the integration adds what the Sentry SDK can't trace on its own: transactions for event handlers, cold starts, and AWS SDK calls.

It only sends them when tracing is enabled. To enable it, set the `traces_sample_rate` option of the Sentry SDK to a value greater than `0.0`:

```php {filename:index.php}
\Sentry\init([
    'dsn' => '___PUBLIC_DSN___',
    'traces_sample_rate' => 1.0,
]);
```

With Laravel or Symfony, set this option in the configuration of their Sentry SDK (see [Laravel](/platforms/php/guides/laravel/#tracing) or [Symfony](/platforms/php/guides/symfony/tracing/)).
