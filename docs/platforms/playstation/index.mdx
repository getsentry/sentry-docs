## Feature Highlights

PlayStation 5 support was originally introduced in Native SDK `0.8.5`.

- **Device Context**<br />
  Automatic console model, family, and manufacturer context, including PS5 Pro detection.<br /><small>Available since `0.10.1+20250903` (expanded console context since `0.15.3-20260707`).</small>

- **Crash Attachments**<br />
  Log files and other custom files attached to PlayStation crash reports.<br /><small>Available since `0.11.3+20251020`.</small>

- [**Non-Fatal Stack Traces**](/platforms/unreal/configuration/debug-symbols/)<br />
  Symbolicated stack traces for messages and ensures in Unreal Development/Test builds.<br /><small>Available since `0.16.0-20260729`.</small>

- [**Crash-Free Session Tracking**](/product/releases/health/)<br />
  Track crashed sessions through PlayStation crash reports without requiring a subsequent game launch.<br /><small>Available since `0.17.5-20261029`.</small>
