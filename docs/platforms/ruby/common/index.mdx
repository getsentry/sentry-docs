## Configure

**Error Monitoring** starts working as soon as you call `Sentry.init`. **Logs** and **Application Metrics** need no extra configuration, and you'll learn how to send them in steps [#3](#send-logs) and [#4](#send-application-metrics-).
This guide also enables **Tracing** and **Profiling**.

### Control the Data You Send to Sentry

<SplitLayout>
<SplitSection>
<SplitSectionText>

By default, the SDK does **not** send user identity data (IP address, ID, and similar) or other data like HTTP bodies and URL query parameters.

To opt in and get richer debugging context, turn on individual categories using the `data_collection` option. For the full list of categories and their defaults, <PlatformLink to="/configuration/options/#data_collection">see the `data_collection` options</PlatformLink>.

</SplitSectionText>
<SplitSectionCode>

```ruby
require 'sentry-ruby'

Sentry.init do |config|
  config.dsn = '___PUBLIC_DSN___'

  config.data_collection.user_info = true
  config.data_collection.http_bodies = [:incoming_request, :outgoing_request]
  # other categories
end
```

</SplitSectionCode>
</SplitSection>
</SplitLayout>

## Send Logs

<SplitLayout>
<SplitSection>
<SplitSectionText>

Use `Sentry.logger` to send logs at different levels, such as `info`, `warn`, or `error`. Add attributes to make logs easier to search and filter.

If you use Ruby's standard-library `Logger`, enable the `:logger` patch to send its logs to Sentry automatically. See the <PlatformLink to="/integrations/logging/">Ruby Logger integration</PlatformLink> for setup instructions.

See <PlatformLink to="/logs/">Set Up Logs</PlatformLink> for all available logging methods and message formatting.

</SplitSectionText>
<SplitSectionCode>

```ruby
Sentry.logger.info("User logged in", user_id: 42)
Sentry.logger.warn("Slow operation detected", operation: "data_fetch")
Sentry.logger.error("Payment failed", order_id: "or_2342")
```

</SplitSectionCode>
</SplitSection>
</SplitLayout>

## Send Application Metrics <FeatureBadge type="new" />

<SplitLayout>
<SplitSection>
<SplitSectionText>

Use `Sentry.metrics` to send counters, gauges, and distributions from your app. Add attributes to search and filter metrics later.

See <PlatformLink to="/metrics/">Set Up Metrics</PlatformLink> for all available metric types and configuration options.

</SplitSectionText>
<SplitSectionCode>

```ruby
Sentry.metrics.count("checkout.failed", value: 1)

Sentry.metrics.gauge(
  "queue.depth",
  42,
  attributes: { queue: "payments" }
)

Sentry.metrics.distribution(
  "api_latency",
  187,
  unit: "millisecond",
  attributes: { endpoint: "/api/orders" }
)
```

</SplitSectionCode>
</SplitSection>
</SplitLayout>
