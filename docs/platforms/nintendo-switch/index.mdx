## Feature Highlights

Nintendo Switch support was originally introduced in Native SDK `0.8.2`. Switch 2 support followed in `0.12.5+20260203` for native and Unreal, and `0.16.5-20260901` for Unity.

- **Screenshots**<br />
  Screenshot attachments through Nintendo crash-report forwarding.

- **Device Context**<br />
  Automatic console model, family, and manufacturer context.<br /><small>Available since `0.11.3+20251020` (expanded console context since `0.15.3-20260707`).</small>

- **Unity Network Checks**<br />
  Detect offline status without triggering system connection dialogs.<br /><small>Available since `0.16.5-20260907`.</small>

- **Default user IDs*<br />
  Default user IDs set based on a unique device identifier, scoped to the Sentry project, and preserved when local storage is cleared.<br /><small>Available since `0.17.3-20261013`.</small>

- [**Crash-Free Session Tracking**](/platforms/native/configuration/releases/#release-health)<br />
  Track crashed sessions through Nintendo crash reports without requiring persistent storage or a subsequent game launch.<br /><small>Available since `0.17.5-20261029`.</small>
