## Install

Add the Sentry Dart SDK to your `pubspec.yaml`:

```yml {filename:pubspec.yaml}
dependencies:
  sentry: ^{{@inject packages.version('sentry.dart') }}
```

## Configure

**Error Monitoring** starts working as soon as you call `Sentry.init()`. **Logs** and **Application Metrics** need no extra configuration in the current SDK, and you'll learn how to send them in steps [#3](#send-logs) and [#4](#send-application-metrics-).
This guide also enables **Tracing**.

### Initialize the Sentry SDK

Configuration should happen as **early as possible** in your application's lifecycle.

Import and initialize the SDK in your app's entry point:

The snippet also turns on:

- Tracing: via <PlatformLink to="/configuration/options/#tracesSampleRate">`tracesSampleRate`</PlatformLink>
- Additional user and request data: via <PlatformLink to="/configuration/options/#sendDefaultPii">`sendDefaultPii`</PlatformLink>

Don't need a feature? Remove its integration and options from the snippet.

```dart
import 'package:sentry/sentry.dart';

Future<void> main() async {
  await Sentry.init((options) {
    options.dsn = '___PUBLIC_DSN___';

    // Adds request headers and IP to events.
    options.sendDefaultPii = true;

    // Enables Tracing.
    // Set to 1.0 to capture 100% of spans for tracing.
    // We recommend reducing this value in production.
    options.tracesSampleRate = 1.0;
  });

  // You can also configure SENTRY_DSN, SENTRY_RELEASE, SENTRY_DIST, and
  // SENTRY_ENVIRONMENT via Dart environment variables (--dart-define).
}
```

## Send Logs

Use `Sentry.logger` to send structured logs at different levels. You can add attributes to make logs easier to search and filter.

If you use the Dart `logging` package, add the <PlatformLink to="/integrations/logging/">`sentry_logging` integration</PlatformLink> to send its records to Sentry.

See <PlatformLink to="/logs/">Set Up Logs</PlatformLink> for all available logging methods and message formatting.

```dart
Sentry.logger.info('Order completed', attributes: {
  'order_id': SentryAttribute.string('12345'),
  'total': SentryAttribute.double(99.99),
});

Sentry.logger.warn('Slow operation detected');
Sentry.logger.error('Validation failed');
```

## Send Application Metrics <FeatureBadge type="new" />

Use `Sentry.metrics` to send counters, gauges, and distributions from your app. Add attributes to filter and group metrics in Sentry.

See <PlatformLink to="/metrics/">Set Up Metrics</PlatformLink> for metric types, attributes, and configuration options.

```dart
Sentry.metrics.count('checkout.failed', 1);
Sentry.metrics.gauge('queue.depth', 42);
Sentry.metrics.distribution('api_latency', 187);
```

## Verify Your Setup

Let's test your setup and confirm that data reaches your Sentry project.

Add this to your async entry point after `Sentry.init()` to trigger and capture a test error:

```dart
try {
  throw StateError('Sentry Test Error');
} catch (exception, stackTrace) {
  await Sentry.captureException(
    exception,
    stackTrace: stackTrace,
  );
}
```
