Version 10 raises the minimum supported platform versions, removes deprecated APIs, and changes several telemetry defaults. The changes below include the core Dart SDK changes that affect Flutter applications.

This checklist covers the Flutter v10 migration. Some steps only apply to specific target platforms, integrations, or configuration options. Check off a step after completing it or confirming that it doesn't apply to your app. Your progress is saved in this browser.

For the full write-up of every change, see the [migration guide](../).

<Alert level="warning">

The Dart analyzer won't catch every behavior change. Read through the steps before upgrading, including changes to telemetry defaults, error grouping, and release health.

</Alert>
