The [Quantum](https://github.com/quantum-elixir/quantum-core) integration supports cron monitoring for Quantum jobs.

This integration is built into the Sentry SDK.

## Configure

You can configure the Quantum integration in your Sentry configuration, under the `:integrations` key:

```elixir {filename:config/config.exs} {diff}
config :sentry,
  # ...,
  integrations: [
+    quantum: [
+      cron: [enabled: true]
+    ]
  ]
```

## Monitor Defaults

<AvailableSince version="14.1.0" />

To apply the same check-in margin or maximum runtime to Quantum monitors, set `monitor_config_defaults` under `integrations`:

```elixir {filename:config/config.exs}
config :sentry,
  integrations: [
    monitor_config_defaults: [checkin_margin: 5, max_runtime: 30],
    quantum: [cron: [enabled: true]]
  ]
```

These defaults also apply to other cron integrations. Quantum supplies each job's schedule and timezone, overriding those two defaults.
