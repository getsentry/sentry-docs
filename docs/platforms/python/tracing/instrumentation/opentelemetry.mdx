This page describes version `3.x` of the Python SDK. For `2.x`, switch to `2.x` in the version selector.

To send OpenTelemetry traces to Sentry, use the <PlatformLink to="/integrations/otlp/">`OTLPIntegration`</PlatformLink>, which sends them directly to Sentry over OTLP. If you're upgrading from SDK `2.x`, see the <PlatformLink to="/migration/2.x-to-3.x/#opentelemetry">migration guide</PlatformLink>.
