## Configure

**Error Monitoring** starts working as soon as you call `sentry_sdk.init()`. **Logs** and **Application Metrics** need no extra configuration when using `sentry_sdk.logger` and `sentry_sdk.metrics`, and you'll learn how to send them in steps [#3](#send-logs) and [#4](#send-application-metrics-). Standard-library `logging` and Loguru records require configuring their logging integrations.
This guide also enables **Tracing** and **Profiling**.

<Include name="quick-start-features-expandable" />

### Initialize the Sentry SDK

Configuration should happen as **early as possible** in your application's lifecycle.

<SplitLayout>
<SplitSection>
<SplitSectionText>

Import and initialize the SDK in your app's entry point:

The snippet also turns on:

- Tracing: via <PlatformLink to="/configuration/options/#traces_sample_rate">`traces_sample_rate`</PlatformLink>
- Profiling: via <PlatformLink to="/configuration/options/#profile_session_sample_rate">`profile_session_sample_rate`</PlatformLink> and <PlatformLink to="/configuration/options/#profile_lifecycle">`profile_lifecycle`</PlatformLink>

Don't need a feature? Remove its options from the snippet.

</SplitSectionText>
<SplitSectionCode>

```python
import sentry_sdk
sentry_sdk.init(
    dsn="___PUBLIC_DSN___",

    # Send request headers and user IP address.
    send_default_pii=True,

    # Enables Tracing.
    # Set to 1.0 to capture 100% of spans for tracing.
    # We recommend reducing this value in production.
    traces_sample_rate=1.0,

    # Enables Profiling.
    # Set to 1.0 to profile 100% of sessions.
    profile_session_sample_rate=1.0,
    # Profiles are collected while at least one span is active.
    profile_lifecycle="trace",
)
```

</SplitSectionCode>
</SplitSection>
</SplitLayout>

<SplitLayout>
<SplitSection>
<SplitSectionText>

In async programs, we recommend to initialize the Sentry SDK inside an `async` function to ensure async code is instrumented properly. If possible, call `sentry_sdk.init()` at the beginning of the first `async` function you call:

</SplitSectionText>
<SplitSectionCode>

```python
import asyncio
import sentry_sdk
async def main():
    sentry_sdk.init(
        ...  # same as above
    )

asyncio.run(main())
```

</SplitSectionCode>
</SplitSection>
</SplitLayout>

### Instrumenting Your App

The Sentry SDK automatically enables integrations for <PlatformLink to="/tracing/instrumentation/automatic-instrumentation/">many popular libraries</PlatformLink>, so operations like HTTP requests or database queries made with supported libraries will be captured as spans automatically.

<SplitLayout>
<SplitSection>
<SplitSectionText>

However, spans are only created within an existing transaction. If you're not using a supported framework that creates transactions automatically, you'll need to create them manually using `sentry_sdk.start_transaction()`.

See <PlatformLink to="/tracing/instrumentation/custom-instrumentation/">Custom Instrumentation</PlatformLink> for more info.

</SplitSectionText>
<SplitSectionCode>

```python
import sentry_sdk

def some_function():
    with sentry_sdk.start_transaction(op="task", name="Test Transaction"):
        ...
```

</SplitSectionCode>
</SplitSection>
</SplitLayout>

## Send Logs

<SplitLayout>
<SplitSection>
<SplitSectionText>

Use `sentry_sdk.logger` to send structured logs at different levels. You can include searchable attributes with each message.

To capture records from Python's standard-library `logging` module or Loguru, configure `capture_sentry_logs=True` on the corresponding integration. See the <PlatformLink to="/integrations/logging/">standard logging</PlatformLink> and <PlatformLink to="/integrations/loguru/">Loguru</PlatformLink> integration guides.

See <PlatformLink to="/logs/">Set Up Logs</PlatformLink> for all available logging methods and formatting options.

</SplitSectionText>
<SplitSectionCode>

```python
import sentry_sdk

sentry_sdk.logger.info("Order processed {order_id}", order_id="order-123")
sentry_sdk.logger.warning("Rate limit reached", attributes={"endpoint": "/api/orders"})
```

</SplitSectionCode>
</SplitSection>
</SplitLayout>

## Send Application Metrics <FeatureBadge type="new" />

<SplitLayout>
<SplitSection>
<SplitSectionText>

Use `sentry_sdk.metrics` to send counters, gauges, and distributions from your app. Metrics are enabled by default after you initialize the SDK.

See <PlatformLink to="/metrics/">Set Up Metrics</PlatformLink> for all available metric types and configuration options.

</SplitSectionText>
<SplitSectionCode>

```python
import sentry_sdk

sentry_sdk.metrics.count("checkout.failed", 1)
sentry_sdk.metrics.gauge("active_connections", 42)
sentry_sdk.metrics.distribution("api_latency", 187, unit="millisecond")
```

</SplitSectionCode>
</SplitSection>
</SplitLayout>
