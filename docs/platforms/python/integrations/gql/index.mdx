The [GQL](https://gql.readthedocs.io/en/stable/) integration allows you to monitor all GraphQL requests that your Python application makes using the `gql` library. Specifically, this integration reports every [`TransportQueryError`](https://gql.readthedocs.io/en/latest/modules/transport_exceptions.html#gql.transport.exceptions.TransportQueryError) to Sentry and provides additional context including:

- The URL the request was made to
- The GraphQL query which caused the error
- The `errors` information that the GraphQL server returns

## Install

Make sure you have the latest version of the Sentry SDK installed:

```bash {tabTitle:pip}
pip install "sentry-sdk"
```
```bash {tabTitle:uv}
uv add "sentry-sdk"
```

## Configure

If you have the `gql` package in your dependencies, the GQL integration will be enabled automatically when you initialize the Sentry SDK.

## Data Privacy and the GQL Integration

By default, the SDK records the GraphQL queries and the `errors` information that the GraphQL server returns. To control this, use the `graphql` key of the <PlatformLink to="/configuration/options/#data_collection">`data_collection`</PlatformLink> option in your SDK init. The `document` key controls the queries and the `errors` information, and the `variables` key controls the query variables:

```python
sentry_sdk.init(
    # ...
    data_collection={
        "graphql": {"document": True, "variables": True},
    },
)
```

These are the defaults. See <PlatformLink to="/data-management/data-collected/">Data Collected</PlatformLink> for all available keys.

In SDK versions prior to `3.0`, this data isn't sent by default. To send it, pass a `data_collection` dictionary as shown above, or set the `send_default_pii` option to `True`. Since `send_default_pii` is a global SDK option, setting it to `True` affects all integrations, so make sure to [scrub sensitive data](/platforms/python/data-management/sensitive-data/) from events first.
