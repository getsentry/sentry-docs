This page lists the minimum version of each library that version `2.x` of the Python SDK instruments. Version `3.x` raises many of these minimums. To see them, switch to `latest` in the version selector.

## Python

The SDK requires Python 3.6 or later. Some integrations require a newer Python version. Check the integration's page for details.

## Integrations

If an installed library is older than the minimum version listed here, the SDK doesn't enable the integration for it.
