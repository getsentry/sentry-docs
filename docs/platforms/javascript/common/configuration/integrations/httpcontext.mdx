_Import name: `Sentry.httpContextIntegration`_

This integration is enabled by default. If you'd like to modify your default integrations, read [this](./../#modifying-default-integrations).

This integration attaches the current page URL and the `User-Agent` and `Referer` headers to events and spans.
Sentry uses the `User-Agent` header to tag events with browser, OS, and device information.

```JavaScript
Sentry.init({
  integrations: [Sentry.httpContextIntegration()],
});
```

## Data Collection

This integration respects the <PlatformLink to="/configuration/options/#dataCollection">`dataCollection`</PlatformLink> option in your root `Sentry.init` config:

- `dataCollection.httpHeaders.request` controls the `User-Agent` and `Referer` headers.
- `dataCollection.urlQueryParams` controls the query parameters in the page URL and the referrer.

If you set `httpHeaders: { request: false }`, the SDK doesn't send the `User-Agent` header, so your events won't have browser, OS, or device information.
To keep that information while limiting which other request header values are sent, add `user-agent` to an allowlist:

```JavaScript
Sentry.init({
  dataCollection: {
    httpHeaders: {
      request: { allow: ["user-agent"] },
    },
  },
});
```
