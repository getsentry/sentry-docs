<Alert>

This integration only works in the Node.js runtime and requires SDK version `11.11.0` or higher.

</Alert>

_Import name: `Sentry.awsLambdaWebIntegration`_

This integration is enabled by default. If you'd like to modify your default integrations, read [this](./../#modifying-default-integrations).

The `awsLambdaWebIntegration` adds AWS Lambda metadata, such as the request ID, endpoint name, and cold start, to errors and spans when your app runs as an [AWS Lambda Web Function](https://docs.aws.amazon.com/lambda/latest/dg/web-functions.html). Outside of a Web Function, it does nothing.

For Lambda Event Functions, use the [AWS Lambda SDK](/platforms/javascript/guides/aws-lambda/) instead.

```JavaScript
Sentry.init({
  integrations: [Sentry.awsLambdaWebIntegration()],
});
```
