_Import name: `Sentry.googleGenAIIntegration`_

This integration is enabled by default when tracing is enabled. If you'd like to modify your default integrations, read [this](./../#modifying-default-integrations).

The `googleGenAIIntegration` adds instrumentation for the [`@google/genai`](https://www.npmjs.com/package/@google/genai) SDK to capture <PlatformLink to="/agent-tracing/">agent tracing</PlatformLink> `gen_ai` spans, recording model, token usage, latency, and (when enabled) inputs and outputs.

```javascript
Sentry.init({
  dsn: "___PUBLIC_DSN___",
  // Tracing must be enabled for agent tracing to work.
  // `googleGenAIIntegration` is then on by default; add it to `integrations` only to change its options.
  tracesSampleRate: 1.0,
});
```

To group multi-turn chats in [Conversations](/product/agents/conversations/) and show who started them, set a conversation ID and user in every request that makes AI calls. See <PlatformLink to="/agent-tracing/#tracking-conversations">Tracking Conversations</PlatformLink>.

## Supported Operations

By default, tracing support is added to the following Google Gen AI SDK calls:

- `models.generateContent()` - Generate content with a given model
- `models.generateContentStream()` - Stream content generation with a given model
- `models.embedContent()` - Generate embeddings with a given model
- `chats.create()` - Create chat sessions
- `sendMessage()` - Send messages in chat sessions
- `sendMessageStream()` - Stream messages in chat sessions
- `decisions.create()` - Evaluate questions with the [Gemini Decisions API](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/)

Streaming and non-streaming requests are automatically detected and handled appropriately.

### Trace Decisions

With Sentry SDK `11.14.0` or higher and `@google/genai` `3.2.0` or higher, each `decisions.create()` call creates a `gen_ai.decide` span named `decide <model>`, with model, latency, and token usage. When recording is enabled, Sentry captures `input` and `questions` as input messages and `answers` as output messages.

The Decisions API requires API version `v1beta`. Set it on the client:

```javascript
import { GoogleGenAI } from "@google/genai";

const ai = new GoogleGenAI({
  apiKey: process.env.GEMINI_API_KEY,
  httpOptions: { apiVersion: "v1beta" },
});

const decision = await ai.decisions.create({
  model: "models/gemini-decision-1",
  input: "I was charged twice this month and want a refund.",
  questions: {
    wants_refund: { type: "noul", instructions: "Is a refund requested?" },
  },
});
```

## Supported Versions

- `@google/genai`: `>=0.10.0 <4`

## Options

### `recordInputs`

_Type: `boolean` (optional)_

Records inputs to Google Gen AI SDK calls (such as prompts and messages).

Defaults to `true` if `dataCollection.genAI.inputs` is `true`, which is the default.

### `recordOutputs`

_Type: `boolean` (optional)_

Records outputs from Google Gen AI SDK calls (such as generated text and responses).

Defaults to `true` if `dataCollection.genAI.outputs` is `true`, which is the default.

```javascript
Sentry.init({
  dsn: "___PUBLIC_DSN___",
  tracesSampleRate: 1.0,
  integrations: [
    Sentry.googleGenAIIntegration({
      recordInputs: false,
      recordOutputs: false,
    }),
  ],
});
```
