<Alert>

This integration only works inside a browser environment. It requires JavaScript SDK version 11.14.0 or later.

</Alert>

_Import name: `Sentry.longTasksIntegration`_

The LongTasks integration captures long animation frames as spans on the active span. In browsers that do not support long animation frames, it captures long tasks (main thread blocking for more than 50ms) instead.

The <PlatformLink to="/configuration/integrations/browsertracing/">BrowserTracing</PlatformLink> integration adds this integration automatically, so you don't need to add it yourself. Configure it through BrowserTracing's `enableLongTask` and `enableLongAnimationFrame` options. Set both to `false` to turn it off.

```javascript
Sentry.init({
  integrations: [
    Sentry.browserTracingIntegration({
      enableLongAnimationFrame: false,
    }),
  ],
});
```

To set its options directly, add the integration yourself. An explicitly added LongTasks integration takes precedence over BrowserTracing's settings.

<PlatformSection supported={["javascript"]}>

## Use With BrowserTracingCore

To ship less code, replace `browserTracingIntegration` with <PlatformLink to="/configuration/integrations/browsertracing/#reduce-bundle-size">`browserTracingCoreIntegration`</PlatformLink>, which doesn't add this integration, and add it only if you need it:

```javascript
Sentry.init({
  integrations: [
    Sentry.browserTracingCoreIntegration(),
    Sentry.longTasksIntegration(),
  ],
});
```

</PlatformSection>

## Configuration Options

<SdkOption name="enableLongAnimationFrame" type="boolean" defaultValue="true">

Capture long animation frames as spans in browsers that support them.

</SdkOption>

<SdkOption name="enableLongTask" type="boolean" defaultValue="true">

Capture long tasks as spans when long animation frames are disabled or not supported.

</SdkOption>
