For more information on setting up Sentry Express support, see the [Express Sentry documentation](/platforms/javascript/guides/express/).

_Import name: `Sentry.expressIntegration`_

This integration is enabled by default. If you'd like to modify your default integrations, read [this](./../#modifying-default-integrations).

The `expressIntegration` captures errors thrown in your Express route handlers and middleware, and creates spans for your Express middleware, routers, and request handlers. It also names your transactions after the matched route, such as `GET /users/:id`.

Errors are captured when they are thrown, before any of your own error-handling middleware runs, so you don't need to call `setupExpressErrorHandler` anymore.

For the integration to work, Sentry has to instrument Express before your app loads it. Run your app with the `--import` flag or use one of the other <PlatformLink to="/install/">installation methods</PlatformLink>.

```JavaScript
Sentry.init({
  integrations: [Sentry.expressIntegration()],
});
```

## Options

### `shouldHandleError`

_Type: `((error: Error) => boolean) | false`_

Decides whether an error thrown from a route handler or middleware is sent to Sentry.

By default, errors with a 5xx status code and errors without a status code are sent. Errors with a 3xx or 4xx status code are not. The status code is read from the error's `status`, `statusCode`, `status_code`, or `output.statusCode` property.

For example, to also capture 4xx errors:

```javascript
Sentry.init({
  integrations: [
    Sentry.expressIntegration({
      shouldHandleError(error) {
        return Number(error.statusCode ?? 500) >= 400;
      },
    }),
  ],
});
```

Set this option to `false` to turn off automatic error capturing. You can then capture errors yourself with `Sentry.captureException` in your own error-handling middleware.

### `ignoreLayers`

_Type: `Array<string | RegExp | ((name: string) => boolean)>`_

An array of patterns matched against the span name of an Express layer. Matching layers don't create spans. Strings must match the name exactly.

```javascript
Sentry.init({
  integrations: [
    Sentry.expressIntegration({
      ignoreLayers: ["jsonParser", /^cors/],
    }),
  ],
});
```

### `ignoreLayersType`

_Type: `Array<'middleware' | 'router' | 'request_handler'>`_

An array of Express layer types to ignore when creating spans. Use this to filter out all middleware, router, or request handler spans.

```javascript
Sentry.init({
  integrations: [
    Sentry.expressIntegration({
      ignoreLayersType: ["middleware"],
    }),
  ],
});
```

## Supported Versions

- `express`: `^4.0.0 || ^5.0.0`
