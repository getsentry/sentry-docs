<Alert>

This integration only works inside a browser environment.

</Alert>

_Import name: `Sentry.browserTracingIntegration`_

With [tracing](/concepts/key-terms/tracing/), Sentry follows requests, background jobs, and [AI agent runs](/product/agents/) across services so you can see where they fail or slow down. Spans record each service and the operations inside it.

The BrowserTracing integration sets up automatic tracing for your frontend applications. It captures transactions and spans from the browser and sends them to Sentry.

Read more about [setting up BrowserTracing](./../../../tracing/).

```JavaScript
Sentry.init({
  integrations: [Sentry.browserTracingIntegration()],
});
```

See <PlatformLink to="/tracing/instrumentation/automatic-instrumentation/#configuration-options">Configuration Options</PlatformLink> for a full list of available options for `browserTracingIntegration`
