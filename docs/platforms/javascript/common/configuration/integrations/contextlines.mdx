_Import name: `Sentry.contextLinesIntegration`_

<PlatformCategorySection supported={['server-only']}>

This integration is enabled by default. If you'd like to modify your default integrations, read [this](./../#modifying-default-integrations).

This integration adds source code to your stack frames. It ensures that you can see the code that caused the error directly in the Sentry UI.

</PlatformCategorySection>

<PlatformCategorySection notSupported={['server-only']}>

This integration adds source code from inline JavaScript of the current page's HTML (e.g. JS in `<script>` tags) to stack traces of captured errors.
It _can't_ collect source code from assets referenced by your HTML (e.g. `<script src="..." />`).

The `ContextLines` integration is useful when you have inline JS code in HTML pages that can't be accessed by Sentry's backend, for example, due to a login-protected page.

</PlatformCategorySection>

<PlatformContent includePath="configuration/contextlines" />

## Options

### `frameContextLines`

_Type: `number`_

The number of lines to collect around each stack frame's line number. Defaults to 7.
