_Import name: `Sentry.anthropicAIIntegration`_

This integration is enabled by default when tracing is enabled. If you'd like to modify your default integrations, read [this](./../#modifying-default-integrations).

The `anthropicAIIntegration` adds instrumentation for the [`@anthropic-ai/sdk`](https://www.npmjs.com/package/@anthropic-ai/sdk) SDK to capture <PlatformLink to="/agent-tracing/">agent tracing</PlatformLink> `gen_ai` spans, recording model, token usage, latency, and (when enabled) inputs and outputs.

```javascript
Sentry.init({
  dsn: "___PUBLIC_DSN___",
  // Tracing must be enabled for agent tracing to work.
  // `anthropicAIIntegration` is then on by default; add it to `integrations` only to change its options.
  tracesSampleRate: 1.0,
});
```

The integration sets a conversation ID for [Conversations](/product/agents/conversations/) only for session tool runners. See [Conversation IDs](#conversation-ids) for when you need to call `Sentry.setConversationId()` yourself. To show who started each chat, also call `Sentry.setUser()` in every request that makes AI calls.

## Supported Operations

By default, tracing support is added to the following Anthropic SDK calls:

- `messages.create()` - Create messages with Claude models
- `messages.stream()` - Stream messages with Claude models
- `completions.create()` - Create completions (legacy)
- `beta.messages.create()` - Beta messages API

Streaming and non-streaming requests are automatically detected and handled appropriately.

## Conversation IDs

The integration sets `gen_ai.conversation.id` automatically only for session tool runners created with `client.beta.sessions.events.toolRunner()`. It uses the runner's session ID. This requires SDK version `11.12.0` or higher.

For all other calls, such as `messages.create()`, `messages.stream()`, and `beta.messages.toolRunner()`, call `Sentry.setConversationId()` with your app's chat ID before the first AI call of each request. An ID you set with `Sentry.setConversationId()` replaces the session ID. See <PlatformLink to="/agent-tracing/#set-the-conversation-id-yourself">Set the Conversation ID Yourself</PlatformLink>.

## Supported Versions

- `@anthropic-ai/sdk`: `>=0.19.2 <1.0.0`

## Options

### `recordInputs`

_Type: `boolean` (optional)_

Records inputs to Anthropic SDK calls (such as prompts and messages).

Defaults to `true` if `dataCollection.genAI.inputs` is `true`, which is the default.

### `recordOutputs`

_Type: `boolean` (optional)_

Records outputs from Anthropic SDK calls (such as generated text and responses).

Defaults to `true` if `dataCollection.genAI.outputs` is `true`, which is the default.

```javascript
Sentry.init({
  dsn: "___PUBLIC_DSN___",
  tracesSampleRate: 1.0,
  integrations: [
    Sentry.anthropicAIIntegration({
      recordInputs: false,
      recordOutputs: false,
    }),
  ],
});
```
