[Flue](https://flueframework.com/) is an open TypeScript framework for building AI agents, made by the Astro team. This guide uses the Sentry CLI to set up the Sentry SDK in a Flue app so agent turns, model calls, tool executions, and errors flow into [Sentry Agent Tracing](/product/agents/).
