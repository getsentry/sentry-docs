[vinext](https://github.com/cloudflare/vinext) builds a Next.js application with Vite. This guide sets up Sentry for the server side of a vinext app that runs on Cloudflare Workers.

<Alert level="info">
  If you build your app with the OpenNext Cloudflare adapter, follow the
  [Next.js on
  Cloudflare](/platforms/javascript/guides/nextjs/manual-setup/cloudflare/)
  guide instead.
</Alert>

## Prerequisites

You need:

- A Sentry [account](https://sentry.io/signup/) and [project](/product/projects/)
- A vinext application that runs on Cloudflare Workers with the [Cloudflare Vite plugin](https://developers.cloudflare.com/workers/vite-plugin/)
