To set up Sentry yourself, you install the Sentry packages, add the Sentry Vite plugin, set your Sentry options, and capture the server errors that vinext handles itself. The steps depend on the runtime your vinext app runs on:

- [Cloudflare](/platforms/javascript/guides/vinext/manual-setup/cloudflare/): for a vinext app on Cloudflare Workers, built with the Cloudflare Vite plugin
