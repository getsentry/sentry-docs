## Configure

**Error Monitoring** starts working as soon as you call `Sentry.init()`. **Logs** and **Application Metrics** need no extra configuration, and you'll learn how to send them in steps [#3](#send-logs) and [#4](#send-application-metrics-).
This guide also enables **Tracing** and **Profiling**.

<Include name="quick-start-features-expandable" />

Make sure to initialize Sentry at the top of your function code and wrap each function with the appropriate helper.

The snippet also turns on:

- Tracing: via <PlatformLink to="/configuration/options/#tracesSampleRate">`tracesSampleRate`</PlatformLink>
- Profiling: via <PlatformLink to="/configuration/options/#profileSessionSampleRate">`profileSessionSampleRate`</PlatformLink>, <PlatformLink to="/configuration/options/#profileLifecycle">`profileLifecycle`</PlatformLink>, and the profiling integration

Don't need a feature? Remove its integration and options from the snippet.

Select the tab that matches the kind of function you're using (HTTP, Background, or CloudEvent):

```javascript {tabTitle:Http functions} {mdExpandTabs}
const Sentry = require("@sentry/google-cloud-serverless");
const { nodeProfilingIntegration } = require("@sentry/profiling-node");

Sentry.init({
  dsn: "___PUBLIC_DSN___",
  integrations: [
    // enables Profiling
    nodeProfilingIntegration(),
  ],
  // Enables Tracing.
  // Set to 1.0 to capture 100% of spans for tracing.
  // We recommend reducing this value in production.
  tracesSampleRate: 1.0,
  // Enables Profiling for every session.
  profileSessionSampleRate: 1.0,
  profileLifecycle: "trace",
});

exports.helloHttp = Sentry.wrapHttpFunction((req, res) => {
  throw new Error("oh, hello there!");
});
```

```javascript {tabTitle:Background functions}
const Sentry = require("@sentry/google-cloud-serverless");
const { nodeProfilingIntegration } = require("@sentry/profiling-node");

Sentry.init({

exports.helloEvents = Sentry.wrapEventFunction((data, context, callback) => {

```

## Verify Your Setup

Let's test your setup and confirm that Sentry is working correctly and sending data to your Sentry project.

Add an intentional error to a wrapped function, then invoke it to verify that Sentry captures the error:

```javascript
exports.helloHttp = Sentry.wrapHttpFunction((req, res) => {
  throw new Error("Sentry Test Error");
});
```
