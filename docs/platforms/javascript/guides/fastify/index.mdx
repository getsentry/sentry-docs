[Fastify](https://fastify.dev/) is a fast, low-overhead web framework for Node.js. You don't need a Fastify-specific Sentry SDK: set up Sentry for the runtime your app runs on, and your Fastify app is instrumented automatically.

## Automatic Instrumentation

When you follow the quick start for any of these runtimes, Sentry automatically instruments Fastify. Errors from your routes are captured and, with tracing enabled, incoming requests are traced without any Fastify-specific setup.

To customize how Fastify is instrumented, see the [`fastifyIntegration`](/platforms/javascript/guides/node/configuration/integrations/fastify/) options.
