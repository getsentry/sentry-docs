[Express](https://expressjs.com/) is a minimal and flexible web framework for Node.js. You don't need an Express-specific Sentry SDK: set up Sentry for the runtime your app runs on, and your Express app is instrumented automatically.

## Automatic Instrumentation

When you follow the quick start for any of these runtimes, Sentry automatically instruments Express. Errors from your routes are captured and, with tracing enabled, incoming requests are traced without any Express-specific setup.
