[Hapi](https://hapi.dev/) is a configuration-centric web framework for Node.js. You don't need a Hapi-specific Sentry SDK: set up Sentry for the runtime your app runs on, and your Hapi app is instrumented automatically.

## Automatic Instrumentation

When you follow the quick start for any of these runtimes, Sentry automatically instruments Hapi. Errors from your routes are captured and, with tracing enabled, incoming requests are traced without any Hapi-specific setup.

To customize how Hapi is instrumented, see the [`hapiIntegration`](/platforms/javascript/guides/node/configuration/integrations/hapi/) options.
