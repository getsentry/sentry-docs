<AvailableSince version="10.67.0" />

Sentry automatically instruments the [Cloudflare Workers AI binding](https://developers.cloudflare.com/workers-ai/get-started/workers-wrangler/) (`env.AI`). Calls to `env.AI.run(...)` create `gen_ai` spans that follow Sentry's <PlatformLink to="/agent-tracing/">Agent Tracing</PlatformLink> conventions, capturing the model, request parameters, and token usage.

No extra setup is required beyond the <PlatformLink to="/">quick start</PlatformLink>. The `AI` binding on the `env` that your handler receives is instrumented for you:

```typescript
export default {
  async fetch(request, env) {
    // env.AI is automatically instrumented
    const result = await env.AI.run("@cf/meta/llama-3.1-8b-instruct", {
      messages: [{ role: "user", content: "What is the capital of France?" }],
    });

    return new Response(JSON.stringify(result));
  },
} satisfies ExportedHandler<Env>;
```

That is enough for spans. The SDK records prompt and response content by default. To turn that off, set `genAI: { inputs: false, outputs: false }` in the <PlatformLink to="/configuration/options/#dataCollection">`dataCollection` option</PlatformLink>.

Only `env.AI.run` is instrumented. Streaming spans end when the stream is fully read or cancelled. With `returnRawResponse` or `websocket`, response body fields are not recorded.

You can browse the full list of available models in the [Cloudflare Workers AI models directory](https://developers.cloudflare.com/ai/models/).

## Trace Jev Evaluations

<AvailableSince version="11.3.0" />

Calls to TypeSafe's [Jev model](https://developers.cloudflare.com/ai/models/typesafe/jev/) (`typesafe/jev`) through `env.AI.run()` are traced automatically. No additional integration or setup is needed:

```typescript
const result = await env.AI.run("typesafe/jev", {
  state: "I was charged twice. Please refund the extra charge.",
  questions: {
    department: {
      type: "choice",
      instructions: "Which team should handle this?",
      criteria: {
        billing: "Charges and refunds",
        technical: "Bugs and outages",
      },
    },
  },
});
```

Sentry treats any `env.AI.run()` call whose input has both `state` and `questions` as an evaluation. Each call creates a `gen_ai.evaluate` span named `evaluate <model>`, with the response model (for example, `jev-1.13.0`), latency, and token usage. When recording is enabled, Sentry captures `state` and `questions` as input messages and `answers` as output messages, including probabilities and confidence values returned by Jev. These spans have the same attributes as spans from the [TypeSafe integration](/platforms/javascript/guides/node/configuration/integrations/typesafe/) on other runtimes.

Evaluation state and answers can contain sensitive data. To stop recording them, set `genAI: { inputs: false, outputs: false }` in the <PlatformLink to="/configuration/options/#dataCollection">`dataCollection` option</PlatformLink>.
