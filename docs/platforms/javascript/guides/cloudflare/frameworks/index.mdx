title: Frameworks on Cloudflare
description: "Learn how to set up the Cloudflare SDK with popular frameworks like Astro, SvelteKit, and Remix."
---

You can use the Sentry Cloudflare SDK in combination with Sentry meta-framework SDKs like SvelteKit or Remix to instrument your Cloudflare Pages applications that use these frameworks.

For these frameworks, follow the Cloudflare quick start in the framework guide:

- [Astro on Cloudflare](/platforms/javascript/guides/astro/cloudflare/)
- [Hono on Cloudflare](/platforms/javascript/guides/hono/cloudflare/)
- [Next.js on Cloudflare](/platforms/javascript/guides/nextjs/cloudflare/)
- [Nuxt on Cloudflare](/platforms/javascript/guides/nuxt/cloudflare/)
- [Remix on Cloudflare](/platforms/javascript/guides/remix/cloudflare/)
- [SvelteKit on Cloudflare](/platforms/javascript/guides/sveltekit/cloudflare/)
- [TanStack Start React on Cloudflare](/platforms/javascript/guides/tanstackstart-react/cloudflare/)

For Shopify Hydrogen on Oxygen, follow the [Hydrogen quick start](/platforms/javascript/guides/react-router/hydrogen/) in the React Router guide.
