<Alert title="Using a Web Framework?">

Express, Fastify, Hapi, Hono, and Koa don't need any extra setup. Follow this guide, and the SDK instruments them automatically.

Frameworks like Next.js have their own Sentry SDK. Follow the guide for your framework instead: [Astro](/platforms/javascript/guides/astro/), [NestJS](/platforms/javascript/guides/nestjs/), [Next.js](/platforms/javascript/guides/nextjs/), [Nitro](/platforms/javascript/guides/nitro/), [Nuxt](/platforms/javascript/guides/nuxt/), [React Router](/platforms/javascript/guides/react-router/), [Remix](/platforms/javascript/guides/remix/), [SolidStart](/platforms/javascript/guides/solidstart/), [SvelteKit](/platforms/javascript/guides/sveltekit/), [TanStack Start](/platforms/javascript/guides/tanstackstart-react/).

</Alert>
