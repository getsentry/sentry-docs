[Mastra](https://mastra.ai/) is a TypeScript framework for building AI applications and agents. This guide uses the Sentry CLI to set up the Sentry SDK in a Mastra app so agent runs, model generations, tool calls, workflows, and errors flow into [Sentry Agent Tracing](/product/agents/).
