[Koa](https://koajs.com/) is a lightweight, middleware-based web framework for Node.js. You don't need a Koa-specific Sentry SDK: set up Sentry for the runtime your app runs on, and your Koa app is instrumented automatically.

## Automatic Instrumentation

When you follow the quick start for any of these runtimes, Sentry automatically instruments Koa. Errors from your routes are captured and, with tracing enabled, incoming requests are traced without any Koa-specific setup.

To customize how Koa is instrumented, see the [`koaIntegration`](/platforms/javascript/guides/node/configuration/integrations/koa/) options.
