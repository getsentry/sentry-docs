Sentry takes data privacy very seriously and has default settings in place that prioritize data safety, especially when it comes to personally identifiable information (PII) data. When you add the Sentry SDK to your application, you allow it to collect data and send it to Sentry during the runtime and build time of your application.

The category types and amount of data collected vary, depending on the integrations you've enabled in the Sentry SDK. This page lists data categories that the Sentry Cordova SDK collects.

You can always scrub any data before it's sent to Sentry. See <PlatformLink to="/data-management/sensitive-data/">Scrubbing Sensitive Data</PlatformLink> for more information.

## HTTP Headers

By default, the <PlatformLink to="/configuration/integrations/httpcontext/">HttpContext integration</PlatformLink> sends the `User-Agent` and `Referer` headers of the current page to Sentry.

## Information About Logged-in User

By default, the Sentry SDK doesn't send any information about the logged-in user, such as email address, user ID, or username. User information is only sent if you set it with <PlatformLink to="/apis/#setUser">`Sentry.setUser()`</PlatformLink>.

## Users' IP Address

If you set the `ip_address` of the user to `"{{ auto }}"` with <PlatformLink to="/apis/#setUser">`Sentry.setUser()`</PlatformLink>, Sentry will infer the IP address from the connection between your app and Sentry's server.

To ensure your users' IP addresses are never stored in your event data, you can go to your project settings, click on ["Security & Privacy"](https://sentry.io/orgredirect/organizations/:orgslug/settings/projects/:projectId/security-and-privacy/), and enable "Prevent Storing of IP Addresses" or use Sentry's [server-side data scrubbing](/security-legal-pii/scrubbing/) to remove `$user.ip_address`.

## Request URL

By default, the HttpContext integration sends the URL of the current page to Sentry. Breadcrumbs for outgoing `fetch` and XHR requests include the full request URL, including the query string.

## Request and Response Bodies

The Sentry SDK doesn't send request or response bodies.

## Source Context

By default, SDKs set up by the Sentry CLI Wizard (`@sentry/wizard`) will enable uploading source maps to Sentry.

To disable source map upload, see <PlatformLink to="/sourcemaps/">the Source Maps documentation</PlatformLink>.

## Local Variables In Stack Trace

The Sentry SDK doesn't send local variables in JavaScript stack traces.

## Device, OS and Runtime Information

By default, the Sentry SDK sends information about the device, operating system, and runtime to Sentry. When the native SDK is enabled, this information is collected by the native iOS or Android SDK. Otherwise, it's obtained from the User Agent string.

## Console Logs

By default, the Sentry SDK sends console logs to Sentry as breadcrumbs, which may contain PII data.

To disable sending console messages, set the `console` option of the <PlatformLink to="/configuration/integrations/breadcrumbs/">Breadcrumbs integration</PlatformLink> to `false`.
