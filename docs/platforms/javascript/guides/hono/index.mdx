[Hono](https://hono.dev/) doesn't need its own Sentry setup. Set up Sentry for the runtime your app runs on, and the SDK instruments Hono automatically: `honoIntegration` captures errors from Hono's `onError` handler, and creates spans for incoming requests when tracing is enabled.

## Customize Error Capturing

Errors with a 3xx or 4xx status code are skipped. To change which errors are captured, pass a `shouldHandleError` callback to `honoIntegration()`:

```javascript
Sentry.init({
  dsn: "___PUBLIC_DSN___",
  integrations: [
    Sentry.honoIntegration({
      shouldHandleError(error) {
        const status = error?.status;
        // Capture 401/403 in addition to the default 5xx errors
        return (
          status === 401 ||
          status === 403 ||
          typeof status !== "number" ||
          status >= 500
        );
      },
    }),
  ],
});
```
