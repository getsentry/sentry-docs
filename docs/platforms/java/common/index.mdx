## Configure

**Error Monitoring** starts once Sentry is configured. **Application Metrics** need no extra configuration, and you'll learn how to send them in step [#4](#send-application-metrics-). This guide also configures **Tracing**, **Logs**, and **Profiling**.

<Include name="quick-start-features-expandable" />

Don't need a feature? Remove its configuration from the SDK initialization. To disable Profiling, also remove the `sentry-async-profiler` dependency.
