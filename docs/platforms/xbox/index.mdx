## Feature Highlights

Xbox Series X|S support was originally introduced in Native SDK `0.7.18`.

- **Device Context**<br />
  Automatic console model, family, and manufacturer context.<br /><small>Available since `0.13.5+20260409` (expanded console context since `0.15.3-20260707`).</small>

- **WinGDK Support**<br />
  Native and Unreal integrations for Windows GDK builds.<br /><small>Available since `0.13.7-20260417`.</small>

- [**Native Crash Backend**](/platforms/native/configuration/backends/native/)<br />
  Opt-in out-of-process crash handling with Windows Error Reporting (WER) support for fast-fail crashes.<br /><small>Available since `0.14.0-20260504` (stable since `0.16.0-20260729`, WER support since `0.17.5-20261029`).</small>

- [**Screenshots**](/platforms/unreal/enriching-events/screenshots/)<br />
  Screenshot attachments via the Unreal renderer (native backend required) or GDK system service (devkits only).<br /><small>Available since `0.14.0-20260504` (system-service screenshots since `0.14.2-20260518`).</small>

- [**Session Replay**](/platforms/unreal/session-replay/#xbox)<br />
  Experimental pre-crash video with a breadcrumb timeline. Requires Unreal on Xbox Series X|S and the software encoder.<br /><small>Available since `0.14.2-20260518` (software-encoded replay since `0.17.3-20261013`).</small>

- [**App-Hang Detection**](/platforms/native/app-hangs/)<br />
  Experimental, opt-in hang reports with stack traces.<br /><small>Available since `0.15.2-20260626` (pause control for expected inactivity since `0.16.1-20260803`).</small>

- [**WER Integration**](/platforms/native/advanced-usage/windows-error-reporting/)<br />
  Sync tags and attachments to WER, and WER report IDs back to Sentry's **Windows Error Reporting** context (native backend required).<br /><small>Available since `0.16.0-20260729` (WER report IDs since `0.17.5-20261029`).</small>

- **GPU Crash Reporting**<br />
  GPU crash capture for Unreal and custom engines on Xbox Series X|S. Includes GDK hang reports, `.hix` dumps, and failed commands when RHI breadcrumbs are available.<br /><small>Available since `0.16.5-20260901` (Shipping-build capture, hang-report and `.hix` attachments, and custom-engine support since `0.17.5-20261029`).</small>

- **App-Specific Device ID**<br />
  Default user IDs derived from the app-specific device ID, scoped to the Sentry project, and preserved across reinstalls and cleared local storage.<br /><small>Available since `0.17.3-20261013`.</small>
