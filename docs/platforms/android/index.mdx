On this page, we get you up and running with Sentry's Android SDK, automatically reporting errors and exceptions in your application.

<Alert>

If you don't already have an account and Sentry project established, head over to [sentry.io](https://sentry.io/signup/), then return to this page.

## Install

Sentry captures data by using an SDK within your application's runtime. These are platform-specific and allow Sentry to have a deep understanding of how your application works.

We recommend installing the SDK through our [Sentry Wizard](https://github.com/getsentry/sentry-wizard) by running one of the following commands inside your project directory:

```bash {tabTitle:brew} {mdExpandTabs}
brew install getsentry/tools/sentry-wizard && sentry-wizard -i android
```

```bash {tabTitle:npx}
npx @sentry/wizard@latest -i android
```

```bash {tabTitle:macOS (Intel/x64)}
downloadUrl="https://github.com/getsentry/sentry-wizard/releases/download/v5.1.0/sentry-wizard-darwin-x64"
curl -L $downloadUrl -o sentry-wizard
chmod +x sentry-wizard
./sentry-wizard -i android
```

```bash {tabTitle:macOS (Apple Silicon/arm64)}
downloadUrl="https://github.com/getsentry/sentry-wizard/releases/download/v5.1.0/sentry-wizard-darwin-arm64"
curl -L $downloadUrl -o sentry-wizard
chmod +x sentry-wizard
./sentry-wizard -i android
```

```bash {tabTitle:Linux (x64)}
downloadUrl="https://github.com/getsentry/sentry-wizard/releases/download/v5.1.0/sentry-wizard-linux-x64"
curl -L $downloadUrl -o sentry-wizard
chmod +x sentry-wizard
./sentry-wizard -i android
```

```bash {tabTitle:Linux (arm64)}
downloadUrl="https://github.com/getsentry/sentry-wizard/releases/download/v5.1.0/sentry-wizard-linux-arm64"
curl -L $downloadUrl -o sentry-wizard
chmod +x sentry-wizard
./sentry-wizard -i android
```

```powershell {tabTitle:Windows}
$downloadUrl = "https://github.com/getsentry/sentry-wizard/releases/download/v5.1.0/sentry-wizard-win-x64.exe"
Invoke-WebRequest $downloadUrl -OutFile sentry-wizard.exe
./sentry-wizard.exe -i android
```

This will patch your project and configure the SDK. You only need to patch the project once, then you can add the patched files to your version control system.
If you prefer, you can also <PlatformLink to="/manual-setup/">set up the SDK manually</PlatformLink> or follow the instructions below to adapt the [configuration](#configure).

<Expandable title="The following tasks will be performed by the Sentry Wizard">

The wizard will prompt you to log in to Sentry. It'll then automatically do the following steps for you:

- Update your app's `build.gradle` file with the Sentry Gradle plugin and configure it
- Update your `AndroidManifest.xml` with the default Sentry configuration
- Create `sentry.properties` with an auth token to upload proguard mappings (this file is automatically added to `.gitignore`)
- Add an example error to your app's Main Activity to verify your Sentry setup

</Expandable>

## Configure

**Error Monitoring** starts working as soon as you initialize the SDK. **Logs** need `io.sentry.logs.enabled` set to `true`; **Application Metrics** are available after initialization and need no extra configuration. You'll learn how to send them in [Send Logs](#send-logs) and [Send Application Metrics](#send-application-metrics-).

This guide also enables **Tracing**, **Profiling**, and **Session Replay**. The Android SDK also supports **User Feedback**; see <PlatformLink to="/user-feedback/">Set Up User Feedback</PlatformLink> to add a feedback form to your app.

Initialize the SDK through your application's `AndroidManifest.xml`. If you initialize the SDK in code instead, enable Logs with `options.logs.enabled = true` in Kotlin or `options.getLogs().setEnabled(true)` in Java.

The snippet also turns on:

- Tracing: via <PlatformLink to="/configuration/options/#tracesSampleRate">`tracesSampleRate`</PlatformLink>
- Profiling: via <PlatformLink to="/configuration/options/#profileSessionSampleRate">`profileSessionSampleRate`</PlatformLink> and <PlatformLink to="/configuration/options/#profileLifecycle">`profileLifecycle`</PlatformLink>
- Session Replay: via `sessionSampleRate` and `onErrorSampleRate` in the <PlatformLink to="/session-replay/configuration/#general-configuration">Session Replay configuration</PlatformLink>
- Logs: via `io.sentry.logs.enabled`, described in the <PlatformLink to="/logs/#setup">Logs setup</PlatformLink>

Don't need a feature? Remove its options from the snippet.

```xml {filename:AndroidManifest.xml}
<application>
  <!-- Required: set your sentry.io project identifier (DSN) -->
  <meta-data android:name="io.sentry.dsn" android:value="___PUBLIC_DSN___" />
  <!-- Use Data Collection defaults but don't collect automatic user information. -->
  <meta-data android:name="io.sentry.data-collection.user-info" android:value="false" />

  <!-- Enables Tracing. -->
  <!-- Set to 1.0 to capture 100% of spans for tracing. -->
  <!-- We recommend reducing this value in production. -->
  <meta-data android:name="io.sentry.traces.sample-rate" android:value="1.0" />

  <!-- Enables Profiling. -->
  <meta-data android:name="io.sentry.traces.profiling.session-sample-rate" android:value="1.0" />
  <meta-data android:name="io.sentry.traces.profiling.lifecycle" android:value="trace" />

  <!-- Captures replays for 10% of sessions and 100% of sessions with errors. -->
  <meta-data android:name="io.sentry.session-replay.on-error-sample-rate" android:value="1.0" />
  <meta-data android:name="io.sentry.session-replay.session-sample-rate" android:value="0.1" />

  <!-- Enables Logs. -->
  <meta-data android:name="io.sentry.logs.enabled" android:value="true" />
</application>
```

### Configure the Sentry Android Gradle Plugin

The Sentry Wizard configures the Gradle plugin, which supports automatic tracing instrumentation and uploads ProGuard/R8 mappings and source context. For manual setup, see the <PlatformLink to="/configuration/gradle/">Gradle plugin</PlatformLink>, <PlatformLink to="/enhance-errors/proguard/">ProGuard/R8</PlatformLink>, and <PlatformLink to="/enhance-errors/source-context/">source context</PlatformLink> guides.

<Alert level="info">

On Android 15 (API level 35) and higher, profiling uses the Android <Link to="https://developer.android.com/reference/android/os/ProfilingManager">ProfilingManager</Link> to capture <Link to="https://perfetto.dev/">Perfetto</Link> traces. On older devices, the SDK automatically falls back to the <PlatformLink to="/profiling/legacy/">legacy profiler</PlatformLink>.

</Alert>

## Send Logs

Once Logs are enabled in the manifest above, use `Sentry.logger()` to send log messages at different levels.

```java {tabTitle: Java}
import io.sentry.Sentry;

Sentry.logger().info("Order processed");
Sentry.logger().error("Payment failed");
```

```kotlin {tabTitle: Kotlin}
import io.sentry.Sentry

Sentry.logger().info("Order processed")
Sentry.logger().error("Payment failed")
```

If you already log with Timber or Logcat, the <PlatformLink to="/integrations/timber/">Timber</PlatformLink> and <PlatformLink to="/integrations/logcat/">Logcat</PlatformLink> integrations can send those logs to Sentry too.

See <PlatformLink to="/logs/">Set Up Logs</PlatformLink> for all available logging methods and configuration options.

## Send Application Metrics <FeatureBadge type="new" />

The Android SDK provides counters, gauges, and distributions through `Sentry.metrics()`. Metrics need no separate enable option and are supported in Android SDK version 8.34.0 and later.

```java {tabTitle: Java}
import io.sentry.Sentry;

Sentry.metrics().count("button_click", 1.0);
Sentry.metrics().gauge("queue_depth", 42.0);
Sentry.metrics().distribution("response_time", 187.5);
```

```kotlin {tabTitle: Kotlin}
import io.sentry.Sentry

Sentry.metrics().count("button_click", 1.0)
Sentry.metrics().gauge("queue_depth", 42.0)
Sentry.metrics().distribution("response_time", 187.5)
```

See <PlatformLink to="/metrics/">Set Up Metrics</PlatformLink> for all available metric types and configuration options.

## Verify Your Setup

Add an intentional error to your application to confirm that Sentry captures it:

```java {tabTitle: Java}
import io.sentry.Sentry;

Sentry.captureException(new Exception("This is a test."));
```

```kotlin {tabTitle: Kotlin}
import io.sentry.Sentry

Sentry.captureException(Exception("This is a test."))
```
