A game can log the same error every frame. Throttling drops the repeats, so they don't use up your quota.

Throttling is off by default.

## Configure Throttling in the Editor

Open **Tools > Sentry > Logging** and turn on **Enable Error Event Throttling**. **Dedupe Window [ms]** sets how long the SDK waits before it captures the same error again. The default is `1000` milliseconds.

The built-in throttler handles errors from `Debug.LogError`, `Debug.LogAssertion`, and `Debug.LogException`. It treats two errors as the same when their message and stack trace match, and remembers the last 100 distinct errors. It doesn't throttle breadcrumbs or structured logs.

## Configure Throttling in Code

To throttle in code, implement `IThrottler` and set it as the [`Throttler`](/platforms/unity/configuration/options/#Throttler) option. A custom throttler can also throttle breadcrumbs and structured logs. If you set a throttler in code, the SDK uses it instead of the editor settings.

This example drops any error, breadcrumb, or log that repeats within five seconds:

```csharp
using System;
using System.Collections.Generic;
using Sentry.Unity;
using UnityEngine;

public class RepeatThrottler : IThrottler
{
    private static readonly TimeSpan Window = TimeSpan.FromSeconds(5);
    private readonly Dictionary<string, DateTime> _lastSeen = new Dictionary<string, DateTime>();

    public bool ShouldCaptureEvent(string message, string stackTrace, LogType logType) =>
        ShouldCapture("event:" + message + stackTrace);

    public bool ShouldCaptureException(Exception exception) =>
        ShouldCapture("exception:" + exception.GetType().Name + exception.Message);

    public bool ShouldCaptureBreadcrumb(string message, LogType logType) =>
        ShouldCapture("breadcrumb:" + message);

    public bool ShouldCaptureStructuredLog(string message, LogType logType) =>
        ShouldCapture("log:" + message);

    private bool ShouldCapture(string key)
    {
        lock (_lastSeen)
        {
            var now = DateTime.UtcNow;
            if (_lastSeen.TryGetValue(key, out var last) && now - last < Window)
            {
                return false;
            }

            if (_lastSeen.Count >= 100)
            {
                _lastSeen.Clear();
            }

            _lastSeen[key] = now;
            return true;
        }
    }
}
```

Set it in your [options configuration script](/platforms/unity/configuration/options/programmatic-configuration/):

```csharp
public override void Configure(SentryUnityOptions options)
{
    options.Throttler = new RepeatThrottler();
}
```

`EnableLogDebouncing` and the `DebounceTime*` options are deprecated. Use `Throttler` instead.
