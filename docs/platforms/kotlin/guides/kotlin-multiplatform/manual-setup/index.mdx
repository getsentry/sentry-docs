If you can't (or prefer not to) use the [gradle plugin](/platforms/kotlin/guides/kotlin-multiplatform/#install), you can follow the instructions below to configure your application manually.

## Install

Sentry captures data by using an SDK within your application's runtime.

<Include name="kmp-cocoapods-deprecation.mdx" />

The manual setup below uses the Kotlin CocoaPods plugin to supply Sentry Cocoa. If you're starting a new project, use the [Gradle plugin with Swift Package Manager](/platforms/kotlin/guides/kotlin-multiplatform/#install) instead.

To install the Kotlin Multiplatform SDK, you need to add the following to your `build.gradle.kts` file in your shared module:

```kotlin {filename:shared/build.gradle.kts}
plugins {
    kotlin("multiplatform")
    kotlin("native.cocoapods")
    // .. your other plugins
}

kotlin {
  android()
  iosX64()
  iosArm64()
  iosSimulatorArm64()

  sourceSets {
    val commonMain by getting {
      dependencies {
        implementation("io.sentry:sentry-kotlin-multiplatform:{{@inject packages.version('sentry.kotlin.kmp', '0.0.1-alpha.2') }}")
      }
    }

    // Android target
    val androidMain by getting {
      dependsOn(commonMain)
    }

    // Apple targets:
    val iosMain by getting {
      dependsOn(commonMain)
    }
  }

  cocoapods {
    // rest of configuration
    summary = "Some description for the Shared Module"
    homepage = "Link to the Shared Module homepage"
    ios.deploymentTarget = "14.1"
    podfile = project.file("../iosApp/Podfile")
    // Make sure you use the proper version according to our Cocoa SDK Version Compatibility Table.
    // TODO: link to table in sentry-kotlin-multiplatform gh repo
    pod("Sentry") {
      // Check the version compatibility table for the correct version
      version = "8.36.0"
      linkOnly = true
      extraOpts += listOf("-compiler-option", "-fmodules")
    }
  }
}
```

## Apple Installation Methods

### Swift Package Manager (SPM)

Swift Package Manager (SPM) is a powerful tool for managing dependencies in Swift that allows developers to enjoy a more native integration experience with Xcode.
If you already use SPM or prefer it over other package managers on Apple platforms, this guide will show you how to install the Kotlin Multiplatform SDK while using Swift Package Manager.

#### Install

To use Swift Package Manager without the Kotlin CocoaPods plugin, use the [Sentry Gradle plugin](/platforms/kotlin/guides/kotlin-multiplatform/#install). Add the Sentry Cocoa SDK to your Xcode project with [Swift Package Manager](/platforms/apple/install/swift-package-manager/), then apply the Gradle plugin, which links the Kotlin/Native framework against it. Setting up this linking by hand isn't covered in this guide.

Make sure the Sentry Cocoa version you install is compatible with your Sentry Kotlin Multiplatform SDK version. You can find the compatible versions in the [Cocoa SDK version compatibility table](https://github.com/getsentry/sentry-kotlin-multiplatform?tab=readme-ov-file#cocoa-sdk-version-compatibility-table).

### Migrating From CocoaPods

If your shared module currently gets Sentry Cocoa through the Kotlin CocoaPods plugin:

1. Remove the `pod("Sentry")` declaration from the `cocoapods {}` block in your shared module's `build.gradle.kts`.
2. If the Kotlin CocoaPods plugin is only there to supply Sentry, remove `kotlin("native.cocoapods")` and the `cocoapods {}` block, and have your iOS app consume the shared framework through [direct integration](https://kotlinlang.org/docs/multiplatform/multiplatform-direct-integration.html) instead.
3. Add the Sentry Cocoa SDK to your Xcode project with [Swift Package Manager](/platforms/apple/install/swift-package-manager/), using the version from the compatibility table.
4. Apply the [Sentry Gradle plugin](/platforms/kotlin/guides/kotlin-multiplatform/configuration/gradle/) so it can link the framework.

<Alert>

The Gradle plugin only sets up Swift Package Manager linking when the Kotlin CocoaPods plugin is **not** applied to the module. If your shared module is itself published as a pod (for example, your iOS app consumes it through CocoaPods), the plugin skips linking entirely. Learn more in [how auto-install and linking interact](/platforms/kotlin/guides/kotlin-multiplatform/configuration/gradle/#how-auto-install-and-linking-interact).

</Alert>
