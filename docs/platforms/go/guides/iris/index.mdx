### Options

`sentryiris` accepts a struct of `Options` that allows you to configure how the handler will behave.

```go
// Whether Sentry should repanic after recovery, in most cases it should be set to true,
// as iris.Default includes its own Recovery middleware that handles http responses.
Repanic bool
// Whether you want to block the request before moving forward with the response.
// Because Iris's default `Recovery` handler doesn't restart the application,
// it's safe to either skip this option or set it to `false`.
WaitForDelivery bool
// Timeout for the event delivery requests.
Timeout time.Duration
```

<Break />

```go
app := iris.Default()
app.Use(sentryiris.New(sentryiris.Options{
    // modify your own config options
    Repanic:         true,
    WaitForDelivery: false,
    Timeout:         5 * time.Second,
}))
```

## Verify

```go
// Create your app
app := iris.Default()

// Once it's done, you can attach the handler as one of your middleware
app.Use(sentryiris.New(sentryiris.Options{
	// specify options here...
}))

// Set up routes
app.Get("/", func(ctx iris.Context) {
	// capturing an error intentionally to simulate usage
	sentry.CaptureMessage(sentryiris.GetContext(ctx), "It works!")

	ctx.Writef("Hello world!")
})

// And run it
app.Run(iris.Addr(":3000"))
```

## Usage

`sentryiris` forks a scope for each request. Use `sentryiris.GetContext(ctx)` to get the request's Go context.

<Include name="go/request-scope-usage" />

```go
app := iris.Default()

app.Use(sentryiris.New(sentryiris.Options{
	Repanic: true,
}))

app.Use(func(ctx iris.Context) {
	if scope := sentry.ScopeFromContext(sentryiris.GetContext(ctx)); scope != nil {
		scope.SetTag("someRandomTag", "maybeYouNeedIt")
	}
	ctx.Next()
})

app.Get("/", func(ctx iris.Context) {
	captureCtx, scope := sentry.WithScope(sentryiris.GetContext(ctx))
	scope.SetContext("query", sentry.Context{"unwanted": "someQueryDataMaybe"})
	sentry.CaptureMessage(captureCtx, "User provided unwanted query string, but we recovered just fine")
})

app.Get("/foo", func(ctx iris.Context) {
	// sentryiris handler will catch it just fine. Also, because we attached "someRandomTag"
	// in the middleware before, it will be sent through as well
	panic("y tho")
})

app.Run(iris.Addr(":3000"))
```
