## Requirements

Slog structured logging is supported in Sentry Go SDK version `0.34.0` and above.

## Install

```bash
go get github.com/getsentry/sentry-go
go get github.com/getsentry/sentry-go/slog
```

### Options

`sentryslog` accepts a `sentryslog.Option` struct to control which records are sent to Sentry and how they're enriched before sending.

| Field             | Type                                  | Description                                 | Default                                                                                                 |
| ----------------- | ------------------------------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `LogLevel`        | `[]slog.Level`                        | Log levels to capture as Sentry log entries | `[]slog.Level{slog.LevelDebug, slog.LevelInfo, slog.LevelWarn, slog.LevelError, sentryslog.LevelFatal}` |
| `AttrFromContext` | `[]func(context.Context) []slog.Attr` | Add attributes from the current context     | None                                                                                                    |
| `AddSource`       | `bool`                                | Include source information in Sentry output | `false`                                                                                                 |
| `ReplaceAttr`     | `func([]string, slog.Attr) slog.Attr` | Rewrite or filter attributes before sending | None                                                                                                    |

## Verify

This example sends `INFO`, `WARN`, and `ERROR` records as structured logs. Capture an error event separately with `sentry.CaptureException(ctx, err)` when needed.

```go
package main

import (
	"context"
	"log/slog"
	"time"

	"github.com/getsentry/sentry-go"
	sentryslog "github.com/getsentry/sentry-go/slog"
)

func main() {
	if err := sentry.Init(sentry.ClientOptions{Dsn: "___PUBLIC_DSN___"}); err != nil {
		panic(err)
	}
	defer sentry.Flush(2 * time.Second)
	ctx, _ := sentry.WithScope(context.Background())
	handler := sentryslog.Option{
		LogLevel:  []slog.Level{slog.LevelInfo, slog.LevelWarn, slog.LevelError},
		AddSource: true,
	}.NewSentryHandler(ctx)

	logger := slog.New(handler)

	logger.InfoContext(ctx, "Application started", "service", "image-processor")
	logger.WarnContext(ctx, "Cache miss", "key", "thumbnail:123")
	logger.ErrorContext(ctx, "Image processing failed", "image_id", "img_123")
}
```

## Send Logs to Sentry and Another Handler

If you also want to keep writing logs somewhere else, Go 1.26+ includes `slog.NewMultiHandler`.

```go
package main

import (
	"context"
	"log/slog"
	"os"
	"time"

	"github.com/getsentry/sentry-go"
	sentryslog "github.com/getsentry/sentry-go/slog"
)

func main() {
	if err := sentry.Init(sentry.ClientOptions{Dsn: "___PUBLIC_DSN___"}); err != nil {
		panic(err)
	}
	defer sentry.Flush(2 * time.Second)
	ctx, _ := sentry.WithScope(context.Background())

	sentryHandler := sentryslog.Option{
		LogLevel: []slog.Level{slog.LevelInfo, slog.LevelWarn, slog.LevelError},
	}.NewSentryHandler(ctx)

	textHandler := slog.NewTextHandler(os.Stdout, nil)

	logger := slog.New(slog.NewMultiHandler(sentryHandler, textHandler))
	logger.InfoContext(ctx, "Application started", "service", "image-processor")
}
```

<Include name="logs/go-ctx-usage-alert.mdx" />

`AttrFromContext` functions receive the context supplied to the log call. Use `InfoContext`, `ErrorContext`, or another context-aware method when extractors need request values; ordinary `Info` and `Error` calls do not inherit those values from the handler's construction context.
