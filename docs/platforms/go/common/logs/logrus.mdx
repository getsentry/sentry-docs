The Logrus integration sends structured logs to Sentry. Use `sentry.CaptureException(ctx, err)` separately when you also want an error event.

## Install

```bash
go get github.com/getsentry/sentry-go
go get github.com/getsentry/sentry-go/logrus
```

## Configure

Initialize Sentry before configuring the hook:

<PlatformContent includePath="getting-started-include-logs-config" />

Create a hook with the operation context, choose which levels to send, and flush before shutdown:

```go
ctx, _ := sentry.WithScope(context.Background())
client := sentry.ClientFromContext(ctx)
hook := sentrylogrus.NewLogHook(ctx,
	[]logrus.Level{logrus.InfoLevel, logrus.WarnLevel, logrus.ErrorLevel},
)
logger := logrus.New()
logger.AddHook(hook)
defer client.Flush(2 * time.Second)

logger.WithContext(ctx).WithField("job", "checkout").Info("Job started")
```

`NewLogHook(ctx, levels)` returns a hook without creating a client. To use a custom client, create it with `sentry.NewClient`, handle the initialization error, and pass `sentry.ContextWithClient(ctx, client)` to the hook. If you enable fatal logs, register a Logrus exit handler to flush before `os.Exit`.

## Per-Operation Context

Use `logger.WithContext(ctx)` to select the scope and active trace for a log entry.
