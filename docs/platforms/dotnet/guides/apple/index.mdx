Sentry supports [.NET for iOS, macOS, and Mac Catalyst](https://learn.microsoft.com/dotnet/ios/) directly from the [Sentry NuGet package](https://www.nuget.org/packages/Sentry).

## Install

Add the Sentry dependency to your .NET for iOS, macOS, and/or Mac Catalyst application:

```shell {tabTitle:.NET Core CLI}
dotnet add package Sentry -v {{@inject packages.version('sentry.dotnet') }}
```

```powershell {tabTitle:Package Manager}
Install-Package Sentry -Version {{@inject packages.version('sentry.dotnet') }}
```

## Configure

**Error Monitoring** starts working as soon as you call `SentrySdk.Init()`. **Logs** sent through `SentrySdk.Logger` and **Application Metrics** need no extra configuration. You'll learn how to send them in [Send Logs](#send-logs) and [Send Application Metrics](#send-application-metrics-).

This guide also enables **Tracing**, **Profiling**, and **Session Replay** (experimental).

On .NET for iOS, macOS, and Mac Catalyst, you also get:

- All the features of our main [.NET SDK](/platforms/dotnet/), for your managed code
- Native crash reporting for Apple platforms, leveraging our [Cocoa SDK](/platforms/apple/) including:
    - Automatically [attach screenshots to Native exceptions](/platforms/apple/guides/ios/configuration/options/#attachScreenshot)
    - Detect [App Hangs](/platforms/apple/configuration/app-hangs/)
    - [Automatic performance tracing](/platforms/apple/tracing/)
    - [Automatic breadcrumbs](/platforms/apple/enriching-events/breadcrumbs/#automatic-breadcrumbs)
    - [Swizzling](/platforms/apple/configuration/swizzling/)
- Automatic session tracking and [release health](/product/releases/)

In your `AppDelegate.cs` file, call `SentrySdk.Init` in the `FinishedLaunching` event and include any options you would like to set. The `Dsn` is the only required parameter.

The snippet also turns on:

- Tracing: via <PlatformLink to="/configuration/options/#TracesSampleRate">`TracesSampleRate`</PlatformLink>
- Profiling: via <PlatformLink to="/profiling/">`ProfilesSampleRate`</PlatformLink>. On iOS and Mac Catalyst, the SDK adds the native profiling integration automatically, so you don't need the `Sentry.Profiling` package.
- Session Replay: via <PlatformLink to="/configuration/native-options/#session-replay">`Native.ExperimentalOptions.SessionReplay`</PlatformLink>

Don't need a feature? Remove its options from the snippet.

```csharp
[Register("AppDelegate")]
public class AppDelegate : UIApplicationDelegate
{
    public override bool FinishedLaunching(UIApplication application, NSDictionary launchOptions)
    {
        // Init the Sentry SDK
        SentrySdk.Init(options =>
        {
            options.Dsn = "___PUBLIC_DSN___";
            options.SendDefaultPii = true; // adds the user's IP address automatically
            // Enables Tracing.
            // Set to 1.0 to capture 100% of spans for tracing.
            // We recommend reducing this value in production.
            options.TracesSampleRate = 1.0;
            // Enables Profiling.
            // Set to 1.0 to profile 100% of captured transactions.
            options.ProfilesSampleRate = 1.0;
#if DEBUG
            // Log debug information about the Sentry SDK
            options.Debug = true;
#endif

            // Native Apple SDK options are available via options.Native
            options.Native.EnableAppHangTracking = true;

            // If your app doesn't have sensitive data, you can get screenshots on error events automatically
            // https://docs.sentry.io/platforms/apple/guides/ios/configuration/options/#attachScreenshot
            options.Native.AttachScreenshot = true;

            // Session Replay is currently available via the ExperimentalOptions
            options.Native.ExperimentalOptions.SessionReplay.OnErrorSampleRate = 1.0;
            options.Native.ExperimentalOptions.SessionReplay.SessionSampleRate = 1.0;

            options.SetBeforeSend(evt =>
            {
                if (evt.Exception?.Message.Contains("Something you don't care want logged?") ?? false)
                {
                    return null; // return null to filter out event
                }
                // or add additional data
                evt.SetTag("dotnet-iOS-Native-Before", "Hello World");
                return evt;
            });

            options.OnCrashedLastRun = e =>
            {
                Console.WriteLine(e);
            };
        });

        return true;
    }
}
```

For a full list of native options, see <PlatformLink to="/configuration/native-options/">Apple Native Options</PlatformLink>.

### Options

The .NET for iOS, macOS, and Mac Catalyst integration is part of [Sentry](/platforms/dotnet/). Please refer to the documentation for that package for information about platform agnostic options.

For configuration of the embedded Sentry Cocoa SDK, see <PlatformLink to="/configuration/native-options/">Apple Native Options</PlatformLink>.

## Send Logs

Use `SentrySdk.Logger` to send logs at different levels. These logs are sent without an additional option.

See <PlatformLink to="/logs/">Set Up Logs</PlatformLink> for all available logging methods and formatting options.

```csharp
SentrySdk.Logger.LogInfo("Order processed");
SentrySdk.Logger.LogWarning("Rate limit reached for /api/orders");
```

## Send Application Metrics <FeatureBadge type="new" />

Metrics are enabled by default in Sentry .NET SDK 6.1.0 and later. Use `SentrySdk.Metrics` to send counters, gauges, and distributions from your app.

See <PlatformLink to="/metrics/">Set Up Metrics</PlatformLink> for all available metric types and configuration options.

```csharp
SentrySdk.Metrics.EmitCounter("button_click", 5,
    new Dictionary<string, object> { ["browser"] = "Firefox" });
SentrySdk.Metrics.EmitGauge("page_load", 15.0, MeasurementUnit.Duration.Millisecond,
    new Dictionary<string, object> { ["page"] = "/home" });
SentrySdk.Metrics.EmitDistribution("api_latency", 187, MeasurementUnit.Duration.Millisecond,
    new Dictionary<string, object> { ["endpoint"] = "/api/orders" });
```
