Sentry provides an integration with Azure Functions through the [Sentry.Extensions.Logging](https://www.nuget.org/packages/Sentry.Extensions.Logging) and [Sentry.OpenTelemetry.Exporter](https://www.nuget.org/packages/Sentry.OpenTelemetry.Exporter) NuGet packages.

## Features

In addition to capturing errors, you can monitor interactions between multiple services or applications by <PlatformLink to="/tracing/instrumentation/opentelemetry-otlp/">enabling tracing</PlatformLink>.

Select which Sentry features you'd like to install in addition to Error Monitoring to get the corresponding installation and configuration instructions below.

## Install

<OnboardingOptionButtons options={['error-monitoring', 'performance']}/>

Add the Sentry dependencies to your Azure Functions application:

```shell {tabTitle:.NET Core CLI}
dotnet add package Sentry.Extensions.Logging -v {{@inject packages.version('sentry.dotnet.extensions.logging') }}
// ___PRODUCT_OPTION_START___ performance
dotnet add package Sentry.OpenTelemetry.Exporter -v {{@inject packages.version('sentry.dotnet') }}
dotnet add package OpenTelemetry.Extensions.Hosting
dotnet add package OpenTelemetry.Instrumentation.Http

// ___PRODUCT_OPTION_END___
```

```powershell {tabTitle:Package Manager}
Install-Package Sentry.Extensions.Logging -Version {{@inject packages.version('sentry.dotnet.extensions.logging') }}
// ___PRODUCT_OPTION_START___ performance
Install-Package Sentry.OpenTelemetry.Exporter -Version {{@inject packages.version('sentry.dotnet') }}
Install-Package OpenTelemetry.Extensions.Hosting
Install-Package OpenTelemetry.Instrumentation.Http
// ___PRODUCT_OPTION_END___
```

The [Sentry.Extensions.Logging](/platforms/dotnet/guides/extensions-logging/) package also provides access to the `ILogger<T>` integration and the other core features available in the [Sentry](/platforms/dotnet/) SDK.

## Configure

The core features of Sentry are enabled by calling `AddSentry` when configuring logging.

<OnboardingOption optionId="performance">
To enable tracing, add Sentry's OTLP exporter to the OpenTelemetry `TracerProviderBuilder` and call `UseOtlp()` on the Sentry options. See <PlatformLink to="/tracing/instrumentation/opentelemetry-otlp/">OpenTelemetry (OTLP)</PlatformLink> for sampling and trace propagation.
</OnboardingOption>

For example:

```csharp
using Microsoft.Extensions.Hosting;
using Microsoft.Extensions.Logging;
// ___PRODUCT_OPTION_START___ performance
using Microsoft.Extensions.DependencyInjection;
using OpenTelemetry.Trace;
// ___PRODUCT_OPTION_END___

var host = new HostBuilder()
    .ConfigureFunctionsWorkerDefaults()
// ___PRODUCT_OPTION_START___ performance
    .ConfigureServices(services =>
    {
        services.AddOpenTelemetry().WithTracing(builder =>
        {
            builder
                .AddSentryOtlpExporter("___PUBLIC_DSN___") // <-- Send traces to Sentry over OTLP
                .AddHttpClientInstrumentation(); // From OpenTelemetry.Instrumentation.Http, instruments outgoing HTTP requests
        });
    })
// ___PRODUCT_OPTION_END___
    .ConfigureLogging(logging =>
    {
        logging.AddSentry(options =>
        {
            options.Dsn = "___PUBLIC_DSN___";
            // ___PRODUCT_OPTION_START___ performance
            options.UseOtlp(); // <-- Configure Sentry to use OpenTelemetry for tracing
            // ___PRODUCT_OPTION_END___
            options.Debug = true;
        });
    })
    .Build();

await host.RunAsync();
```
