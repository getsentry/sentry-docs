title: Native Options
description: "Configure the embedded native Sentry SDKs when targeting Android, iOS, or Mac Catalyst with .NET MAUI."
sidebar_order: 5
---

When your .NET MAUI app targets Android, iOS, or Mac Catalyst, Sentry embeds the native [Android SDK](/platforms/android/) or [Cocoa SDK](/platforms/apple/). The `options.Native` property exposes configuration for these embedded SDKs. It isn't available when targeting Windows or Tizen, so wrap native options in a conditional compilation directive:

```csharp
builder.UseSentry(options =>
{
    options.Dsn = "___PUBLIC_DSN___";

#if __ANDROID__
    options.Native.AnrEnabled = true;
#elif __IOS__ || __MACCATALYST__
    options.Native.EnableAppHangTracking = true;
#endif
});
```

The available options are listed in the platform-specific references:

- [Android Native Options](/platforms/dotnet/guides/android/configuration/native-options/) for the Android target
- [Apple Native Options](/platforms/dotnet/guides/apple/configuration/native-options/) for the iOS and Mac Catalyst targets
