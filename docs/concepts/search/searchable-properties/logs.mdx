Search logs in [Explore → Logs](/product/logs/). The keys below are common properties set by Sentry or the SDKs. Any custom attribute you attach on the log is searchable too, using the same attribute name you set in the SDK.

Raw text search matches `message` only. It does not search the rest of the log. Search is case sensitive by default. Use the **Ignore case** toggle in the search bar to match regardless of case. A regular expression uses `message://pattern//`. See [regular expressions](/concepts/search/#regular-expressions-logs-only).

## Searchable Properties

These keys can be used in a log search:

<DefinitionList>

### `message`

The log message body.

- **Type:** string

### `message.template`

The parameterized template, when the SDK recorded one. For example, `Adding item {item} for user {user}`.

- **Type:** string

### `message.parameter.<name>`

One parameter from a parameterized message. `<name>` is the parameter name or the positional index, such as `message.parameter.item` or `message.parameter.0`.

- **Type:** string or number, depending on the value the SDK sent

### `severity`

The severity text. One of `trace`, `debug`, `info`, `warn`, `error`, or `fatal`.

- **Type:** string

### `severity_number`

The numeric severity. Higher numbers are more severe. SDKs set the low end of each range: `trace` is 1, `debug` is 5, `info` is 9, `warn` is 13, `error` is 17, and `fatal` is 21.

- **Type:** number

### `timestamp`

When the log was recorded.

- **Type:** datetime

### `trace`

The trace ID for the active trace when the log was recorded.

- **Type:** string

### `span_id`

The span the log was emitted from. Empty when no span was active. Older SDKs send the same value as `trace.parent_span_id`.

- **Type:** string

### `id`

The log's unique ID.

- **Type:** string

### `project`

The project the log belongs to. You can also scope projects with the page filter.

- **Type:** string

### `environment`

The environment set in the SDK, such as `development`, `staging`, or `production`. [Learn more](/concepts/key-terms/environments/).

- **Type:** string

### `release`

The release set in the SDK. `release:latest` selects the most recent release. [Learn more](/product/releases/usage/sorting-filtering/#latest-release).

- **Type:** string

### `logger.name`

The name of the logger that emitted the log, when the SDK or logging integration set one.

- **Type:** string

### `origin`

Set when an SDK integration captured the log. For example, `auto.log.serilog` or `auto.db.prisma`. Direct calls to the Sentry logger API do not set this.

- **Type:** string

### `sdk.name`

Name of the Sentry SDK that sent the log.

- **Type:** string

### `sdk.version`

Version of the Sentry SDK that sent the log.

- **Type:** string

### `payload_size`

Size of the log payload, in bytes.

- **Type:** number

### `replay.id`

The ID of the active replay when the log was recorded.

- **Type:** string

### `browser.name`

Display name of the browser. Relay parses this from the user agent when the SDK does not set it.

- **Type:** string

### `browser.version`

Version of the browser.

- **Type:** string

### `user.id`

Application-specific identifier for the user. Sent when [send default PII](/platform-redirect/?next=/data-management/data-collected/) is enabled, or when you set it yourself.

- **Type:** string

### `user.email`

Email address of the user.

- **Type:** string

### `user.name`

Username of the user.

- **Type:** string

### `server.address`

Server address. Backend SDKs attach this.

- **Type:** string

### `os.name`

Operating system name. Mobile, desktop, and native SDKs attach this.

- **Type:** string

### `os.version`

Operating system version.

- **Type:** string

### `device.brand`

Device brand.

- **Type:** string

### `device.model`

Device model.

- **Type:** string

### `device.family`

Device family.

- **Type:** string

### `code.file.path`

File path captured with the log, when the SDK recorded a code location.

- **Type:** string

### `code.function.name`

Function name captured with the log.

- **Type:** string

### `code.line.number`

Line number captured with the log.

- **Type:** number

</DefinitionList>
