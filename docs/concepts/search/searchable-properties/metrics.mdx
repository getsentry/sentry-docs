Search application metrics in [Explore → Metrics](/product/metrics/). Pick the metric in the metric selector, then filter with the keys below. Any custom attribute you attach on the metric is searchable too, using the same attribute name you set in the SDK.

The metric selector sets `metric.name`, `metric.type`, and `metric.unit` for you, so the search bar doesn't suggest those keys.

## Searchable Properties

These keys can be used in a metric search:

<DefinitionList>

### `metric.name`

The metric identifier, such as `checkout.failed` or `queue.depth`.

- **Type:** string

### `metric.type`

The metric type. One of `counter`, `gauge`, or `distribution`.

- **Type:** string

### `metric.unit`

Unit of measurement, such as `millisecond`, `byte`, or `ratio`. SDKs can also send custom units. Empty or `none` when the SDK did not set one.

- **Type:** string

### `value`

The numeric value. For a counter, this is the amount added. For a gauge, this is the current value. For a distribution, this is one measured value.

- **Type:** number

### `timestamp`

When the metric was recorded.

- **Type:** datetime

### `trace`

The trace ID for the active trace when the metric was recorded. Every metric has a trace ID, but metrics are often sampled at 100% while traces are sampled at a lower rate, so the trace itself may not have been stored.

- **Type:** string

### `sentry.span_id`

The span the metric was recorded on. Empty when no span was active.

- **Type:** string

### `trace.parent_span_id`

The parent span ID sent by some SDKs for the same association as `sentry.span_id`.

- **Type:** string

### `transaction`

The name of the transaction or segment that was active when the metric was recorded, when the SDK set one.

- **Type:** string

### `id`

The metric event's unique ID.

- **Type:** string

### `project`

The project the metric belongs to. You can also scope projects with the page filter.

- **Type:** string

### `environment`

The environment set in the SDK, such as `development`, `staging`, or `production`. [Learn more](/concepts/key-terms/environments/).

- **Type:** string

### `release`

The release set in the SDK. [Learn more](/product/releases/).

- **Type:** string

### `sdk.name`

Name of the Sentry SDK that sent the metric.

- **Type:** string

### `sdk.version`

Version of the Sentry SDK that sent the metric.

- **Type:** string

### `replay.id`

The ID of the active replay when the metric was recorded.

- **Type:** string

### `browser.name`

Display name of the browser. Relay parses this from the user agent when the SDK does not set it.

- **Type:** string

### `browser.version`

Version of the browser.

- **Type:** string

### `user.id`

Application-specific identifier for the user. Sent when [send default PII](/platform-redirect/?next=/data-management/data-collected/) is enabled, or when you set it yourself.

- **Type:** string

### `user.email`

Email address of the user.

- **Type:** string

### `user.name`

Username of the user.

- **Type:** string

### `server.address`

Server address. Backend SDKs attach this.

- **Type:** string

</DefinitionList>
