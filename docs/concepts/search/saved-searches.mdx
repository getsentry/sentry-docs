<Alert>
  Saved searches have been replaced by [Issue
  Views](/product/issues/issue-views/).
</Alert>

To keep an issue search you use often, save it as an [Issue View](/product/issues/issue-views/). A view saves the search query, sort order, and filters, and you can open it later from the **Issues** sidebar. To learn how to create, edit, and share views, see [Issue Views](/product/issues/issue-views/).
