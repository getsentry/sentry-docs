The Logicstar integration enables automatic fixes for your Sentry issues with Logicstar AI.

<Alert title="Created by LogicStar AI">

Built and supported by LogicStar AI. For help installing or using this integration, contact LogicStar AI directly.

- **Support:** [support@logicstar.ai](mailto:support@logicstar.ai)
- **Documentation:** [LogicStar Sentry integration docs](https://logicstar.ai/documentation/sentry-integration)
- **In Sentry:** [Settings > Integrations > LogicStar](https://sentry.io/orgredirect/organizations/:orgslug/settings/sentry-apps/logicstar/)

</Alert>

## Install and Configure

<Alert>

Sentry owner, manager, or admin permissions are required to install this integration.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Logicstar**

2. Follow the full [Logicstar installation instructions](https://logicstar.ai/documentation/sentry-integration).
