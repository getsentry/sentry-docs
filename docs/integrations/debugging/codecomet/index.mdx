CodeComet developed an LLM-powered debugging agent that looks at error details and inspects corresponding code repositories to generate bug fixes. The end result is an explanation along with actual code for a developer to review.
<Alert title="Created by CodeComet">

Built and supported by CodeComet, not Sentry. For help installing or using this integration, contact CodeComet directly.

- **Support:** [support@codecomet.io](mailto:support@codecomet.io)
- **Documentation:** [CodeComet Sentry integration docs](https://www.codecomet.io/docs/integrations#section4)
- **In Sentry:** [Settings > Integrations > CodeComet](https://sentry.io/orgredirect/organizations/:orgslug/settings/sentry-apps/codecomet/)

</Alert>

## Install and Configure

<Alert>

Sentry Owner, Manager, or Admin permissions are required to install this integration.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **CodeComet**

2. Follow the full [CodeComet installation instructions](https://www.codecomet.io/docs/integrations#section4).
