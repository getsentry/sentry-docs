Apigene helps you effortlessly track and resolve application errors while enhancing performance with real-time insights.


<Alert title="Created by Apigene">

Built and supported by Apigene, not Sentry. For help installing or using this integration, contact Apigene directly.

- **Website:** [www.apigene.ai](https://www.apigene.ai)
- **In Sentry:** [Settings > Integrations > Apigene](https://sentry.io/orgredirect/organizations/:orgslug/settings/sentry-apps/apigene/)

</Alert>

## Install and Configure

<Alert>

Sentry owner, manager, or admin permissions are required to install this integration.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Apigene**

2. Follow the full [Apigene installation instructions](https://www.apigene.ai).
