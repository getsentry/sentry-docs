Tembo is a cloud coding agents platform that offers unified access to claude code, codex, ampcode, cursor cli, and other agentic applications! It autonomously identifies database performance bottlenecks, prioritizes sentry issues, writes optimized code fixes, and submits ready-to-deploy PRs directly to your repos.

<Alert title="Created by Tembo">

Built and supported by Tembo, not Sentry. For help installing or using this integration, contact Tembo directly.

- **Support:** [support@tembo.io](mailto:support@tembo.io)
- **Documentation:** [Tembo Sentry integration docs](https://docs.tembo.io/integrations/sentry)
- **In Sentry:** [Settings > Integrations > Tembo](https://sentry.io/orgredirect/organizations/:orgslug/settings/sentry-apps/dbaai/)

</Alert>

## Install and Configure

<Alert>

Sentry Owner, Manager, or Admin permissions are required to install this integration.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Tembo**

2. Follow the full [Tembo installation instructions](https://docs.tembo.io/integrations/sentry).
