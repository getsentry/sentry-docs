The Datadog for Seer integration gives [Seer Agent](/product/ai-in-sentry/seer/#seer-agent) access to Datadog data like metrics, spans, traces, logs, notebooks, monitors, dashboards, and more. Seer can then use Datadog data to enhance or supplement Sentry telemetry in issue analysis or investigations.

## Install the Datadog for Seer integration

<Alert>

Sentry Owner, Manager, or Admin permissions are required to install this integration.

</Alert>

1. Navigate to [Seer Connector Settings](https://sentry.io/orgredirect/organizations/:orgslug/settings/seer/connectors/)
2. Select the Datadog for Seer integration and  click **Add Organization**
3. You will need to complete the following fields:
    - **Datadog Site**: This is the region your Datadog organization is hosted in. You can find the site as a part of the URL after logging into your Datadog account. For more info on finding your site, see https://docs.datadoghq.com/getting_started/site/.
    - **Datadog API Key**: Find your API keys on Datadog under **Organization Settings > API Keys**. 
    - **Datadog Application Key**: Find your Application keys on Datadog under **Organization Settings > Application Keys**. 
    **Note**: If creating a new key, you must give Seer read permissions to your organization’s telemetry data. To do so, click `Edit` next to `Scope`, then **Select Read All**, then `Save`. **If you do not assign scope to the application key, Seer will not have permission to read your data.**
4. Click **Continue** to complete the setup.

## Configure 

You can always update your connector settings by clicking the **Configurations** tab on the Datadog for Seer settings page, then clicking `Configure` for the connector you wish to update.
