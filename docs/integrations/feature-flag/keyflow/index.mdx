The Keyflow integration connects Sentry with KeyFlow to automate project and issue management workflows. Developers can list projects, view issues, edit and create issues, and manage teams directly from KeyFlow, enabling faster triaging of errors and improved monitoring of application health. 

<Alert title="Created by Keyflow">

Built and supported by Keyflow. For help installing or using this integration, contact Keyflow directly.

- **Support:** [founders@keyflow.space](mailto:founders@keyflow.space)
- **Documentation:** [Keyflow Sentry integration docs](https://docs.keyflow.space/introduction)
- **In Sentry:** [Settings > Integrations > Keyflow](https://sentry.io/orgredirect/organizations/:orgslug/settings/sentry-apps/keyflow/)

</Alert>

## Install and Configure

<Alert>

Sentry owner, manager, or admin permissions are required to install this integration.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Keyflow**

2. Follow the full [Keyflow installation instructions](https://docs.keyflow.space/introduction).
