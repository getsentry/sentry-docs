The Glue.ai integration allows users to get notified about metrics alerts via Glue so that they can discuss and triage efficiently.

<Alert title="Created by GlueGroups, Inc.">

Built and supported by GlueGroups, Inc. For help installing or using this integration, contact GlueGroups, Inc. directly.

- **Support:** [Help and support](https://docs.glue.ai/get-started/help-and-support), [support@glue.ai](mailto:support@glue.ai)
- **Documentation:** [Glue Sentry integration docs](https://docs.glue.ai/integrations/sentry)
- **In Sentry:** [Settings > Integrations > Glue](https://sentry.io/orgredirect/organizations/:orgslug/settings/sentry-apps/glue/)

</Alert>

## Install and Configure

<Alert>

Sentry Owner, Manager, or Admin permissions are required to install this integration.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Glue.ai**

2. Follow the full [Glue.ai installation instructions](https://docs.glue.ai/integrations/sentry).
