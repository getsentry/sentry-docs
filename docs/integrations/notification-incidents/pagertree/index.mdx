## Install and Configure

<Alert>

Sentry owner, manager, or admin permissions are required to install this integration.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **PagerTree**

2. Follow the full [PagerTree installation instructions](https://pagertree.com/docs/integration-guides/sentry).
