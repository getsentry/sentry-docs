## Install and Configure

<Alert>

Sentry owner, manager, or admin permissions are required to install this integration.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Telegram Alerts Bot**

2. Follow the full [Telegram installation instructions](https://telegra.ph/Telegram-Alerts-Bot-FAQ-01-27).
