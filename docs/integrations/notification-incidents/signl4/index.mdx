SIGNL4 is a mobile alerting, and incident response service.

<Alert title="Created by SIGNL4">

Built and supported by SIGNL4, not Sentry. For help installing or using this integration, contact SIGNL4 directly.

- **Documentation:** [SIGNL4 Sentry integration docs](https://www.signl4.com/blog/portfolio_item/sentry/)
- **In Sentry:** [Settings > Integrations > SIGNL4](https://sentry.io/orgredirect/organizations/:orgslug/settings/document-integrations/signl4/)

</Alert>

## Install and Configure

<Alert>

Sentry owner, manager, or admin permissions are required to install this integration.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **SIGNL4**

2. Follow the full [SIGNL4 installation instructions](https://www.signl4.com/blog/portfolio_item/sentry/).
