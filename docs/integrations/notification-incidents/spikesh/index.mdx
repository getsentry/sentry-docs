Built and supported by Spike.sh. For help installing or using this integration, contact Spike.sh directly.

## Install and Configure

<Alert>

Sentry owner, manager, or admin permissions are required to install this integration.

Spike.sh **won't** work with self-hosted Sentry.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Spike.sh**

2. Follow the full [Spike.sh installation instructions](https://docs.spike.sh/integrations-guideline/integrate-spike-with-sentry).
