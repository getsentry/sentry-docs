Rootly is a Slack-native incident management app and platform that automates tedious manual work during incidents.

<Alert title="Created by Rootly Inc.">

Built and supported by Rootly Inc., not Sentry. For help installing or using this integration, contact Rootly Inc. directly.

- **Support:** [support@rootly.com](mailto:support@rootly.com)
- **Documentation:** [Rootly Sentry integration docs](https://docs.rootly.com/integrations/sentry)
- **In Sentry:** [Settings > Integrations > Rootly](https://sentry.io/orgredirect/organizations/:orgslug/settings/sentry-apps/rootly/)

</Alert>

## Install and Configure

<Alert>

Sentry owner, manager, or admin permissions are required to install this integration.

Rootly **won't** work with self-hosted Sentry.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Rootly**

2. Follow the full [Rootly installation instructions](https://docs.rootly.com/integrations/sentry).
