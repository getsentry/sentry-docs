CloudEagle.ai directly integrates with your Sentry REST API v2 to provide comprehensive application usage insights and security posture analysis within minutes.

<Alert title="Created by Cloudeagle">

Built and supported by Cloudeagle. For help installing or using this integration, contact Cloudeagle directly.

- **Support:** [shrejal@cloudeagle.ai](mailto:shrejal@cloudeagle.ai)
- **Documentation:** [CloudEagle.ai Sentry integration docs](https://www.cloudeagle.ai/app-integrations/sentry)
- **In Sentry:** [Settings > Integrations > CloudEagle.ai](https://sentry.io/orgredirect/organizations/:orgslug/settings/sentry-apps/cloudeagleai/)

</Alert>

## Install and Configure

<Alert>

Sentry owner, manager, or admin permissions are required to install this integration.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Cloudeagle**

2. Follow the full [Cloudeagle installation instructions](https://www.cloudeagle.ai/app-integrations/sentry).
