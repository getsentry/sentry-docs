BetterBugs + Sentry integration connects your Sentry infrastructure to your BetterBugs account. You get Sentry event logs (both frontend and backend) auto-attached to every bug report.
<Alert title="Created by BetterBugs">

Built and supported by BetterBugs, not Sentry. For help installing or using this integration, contact BetterBugs directly.

- **Documentation:** [BetterBugs Sentry integration docs](https://docs.betterbugs.io/product-features/integrations/sentry)
- **In Sentry:** [Settings > Integrations > BetterBugs](https://sentry.io/orgredirect/organizations/:orgslug/settings/sentry-apps/betterbugs/)

</Alert>

## Install and Configure

<Alert>

Sentry owner or manager permissions are required to install this integration.

</Alert>

1. Navigate to [Settings > Integrations](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > BetterBugs

2. Follow the full BetterBugs [installation instructions here](https://docs.betterbugs.io/product-features/integrations/sentry).
