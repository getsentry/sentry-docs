The Bug Sniff integration streamlines error management by automatically creating Trello cards for errors. It synchronizes error statuses and resolutions between Sentry and Trello, removing the need for manual handoffs.

<Alert title="Created by Bug Sniff">

Built and supported by Bug Sniff. For help installing or using this integration, contact Bug Sniff directly.

- **Support:** [hello@bugsniff.com](mailto:hello@bugsniff.com)
- **Documentation:** [Bug Sniff Sentry integration docs](https://bugsniff.com/docs.html)
- **In Sentry:** [Settings > Integrations > Bug Sniff](https://sentry.io/orgredirect/organizations/:orgslug/settings/sentry-apps/bug-sniff/)

</Alert>

## Install and Configure

<Alert>

Sentry owner, manager, or admin permissions are required to install this integration.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Bug Sniff**

2. Follow the full [Bug Sniff installation instructions](https://bugsniff.com/docs.html).
