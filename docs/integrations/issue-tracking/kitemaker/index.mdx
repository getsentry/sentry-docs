This integration is maintained and supported by the company that created it. For more details, or questions, please feel free to reach out to hi@kitemaker.co!
## Install and Configure

<Alert>

Sentry owner, manager, or admin permissions are required to install this integration.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Kitemaker**

2. Follow the installation instructions in Sentry.
