<Alert>

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Goast**

2. Follow the full [Goast installation instructions](https://support.goast.ai/integrations/sentry).
