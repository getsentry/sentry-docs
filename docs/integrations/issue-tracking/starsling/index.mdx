StarSling's Sentry integration allows you to see all your Sentry issues prioritized (via LLM) with one-click Autofix actions powered by 
Sentry AI (Seer). Sentry customers will be able to use Sentry AI/Seer alongside their other DevOps tools, in one unified interface.

<Alert title="Created by StarSling">

Built and supported by StarSling, not Sentry. For help installing or using this integration, contact StarSling directly.

- **Support:** [founders@starsling.dev](mailto:founders@starsling.dev)
- **Website:** [www.starsling.dev](https://www.starsling.dev/)
- **In Sentry:** [Settings > Integrations > StarSling](https://sentry.io/orgredirect/organizations/:orgslug/settings/sentry-apps/starsling-dev/)

</Alert>

## Install and Configure

<Alert>

Sentry Owner, Manager, or Admin permissions are required to install this integration.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Starsling**

2. Follow the full [Starsling installation instructions](https://www.starsling.dev/).
