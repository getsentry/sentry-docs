Factory integrates with a users codebase, and pulls in Issues to help automate detecting and fixing issues.

<Alert title="Created by The San Francisco AI Factory">

Built and supported by The San Francisco AI Factory, not Sentry. For help installing or using this integration, contact The San Francisco AI Factory directly.

- **Support:** [support@factory.ai](mailto:support@factory.ai)
- **Documentation:** [Factory Sentry integration docs](https://docs.factory.ai/onboarding/integrating-with-your-engineering-system/sentry)
- **In Sentry:** [Settings > Integrations > Factory](https://sentry.io/orgredirect/organizations/:orgslug/settings/sentry-apps/factory/)

</Alert>

## Install and Configure

<Alert>

Sentry owner, manager, or admin permissions are required to install this integration.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Factory**

2. Follow the full [Factory installation instructions](https://docs.factory.ai/onboarding/integrating-with-your-engineering-system/sentry).
