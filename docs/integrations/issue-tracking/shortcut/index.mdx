Errors, features, and anything else you track in Shortcut can now live side by side. The new Shortcut integration has feature parity with the Shortcut plugin. If you're choosing between the two, we recommend installing the Shortcut integration.

<Alert title="Created by Shortcut Software Company">

Built and supported by Shortcut Software Company, not Sentry. For help installing or using this integration, contact Shortcut Software Company directly.

- **Support:** [Help center](https://www.shortcut.com/help/), [support@shortcut.com](mailto:support@shortcut.com)
- **Documentation:** [Shortcut Sentry integration docs](https://help.shortcut.com/hc/en-us/articles/360026979272-Setting-up-the-Sentry-Integration)
- **In Sentry:** [Settings > Integrations > Shortcut](https://sentry.io/orgredirect/organizations/:orgslug/settings/sentry-apps/shortcut/)

</Alert>

## Install and Configure

<Alert>

Sentry owner, manager, or admin permissions are required to install this integration.

Shortcut **won't** work with self-hosted Sentry.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Shortcut**

![Install Shortcut integration](./img/shortcut.png)

2. Follow the full [Shortcut installation instructions](https://help.shortcut.com/hc/en-us/articles/360026979272-Setting-up-the-Sentry-Integration).
