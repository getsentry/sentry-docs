Teamcamp offers project management, time tracking, messaging, and more.

<Alert title="Created by Teamcamp">

Built and supported by Teamcamp. For help installing or using this integration, contact Teamcamp directly.

- **Support:** [Help center](https://www.teamcamp.app/help), [support@teamcamp.app](mailto:support@teamcamp.app)
- **Documentation:** [Teamcamp Sentry integration docs](https://www.teamcamp.app/help/sentry)
- **In Sentry:** [Settings > Integrations > Teamcamp](https://sentry.io/orgredirect/organizations/:orgslug/settings/sentry-apps/teamcamp/)

</Alert>

## Install and Configure

<Alert>

Sentry owner, manager, or admin permissions are required to install this integration.

Teamcamp **won't** work with self-hosted Sentry.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Teamcamp**

2. Follow the full [Teamcamp installation instructions](https://www.teamcamp.app/help/sentry).
