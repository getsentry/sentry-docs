Linear is an issue tracking tool built for speed, streamlining software projects, tasks, and bug tracking. Effortlessly create new Linear issues from Sentry and link Sentry issues to existing Linear issues.

Linear maintains and supports this integration, which uses the [Sentry Integration Platform](/integrations/integration-platform/). See [Linear's Sentry documentation](https://linear.app/docs/sentry) for setup instructions and supported features.

## Install and Configure

<Alert>

Sentry owner, manager, or admin permissions are required to install this integration.

Linear **won't** work with self-hosted Sentry.

</Alert>

1. Navigate to [**Settings > Integrations**](https://sentry.io/orgredirect/organizations/:orgslug/settings/integrations/) > **Linear**

   ![Install Linear integration](./img/linear-install-pg.png)

2. Follow the full [Linear installation instructions](https://linear.app/docs/sentry).

## Issue Management

Issue tracking allows you to create Linear issues from within Sentry, and link Sentry issues to existing Linear issues. Issue management can be configured in two ways — automatically or manually.

### Automatically

To configure issue management automatically, create an [Alert](/product/monitors-and-alerts/alerts/). When selecting the action, choose "Notify Integration" and then "Linear", or select "Linear" from the action dropdown:

![Create Linear issue as alert action](./img/linear-alert.png)

When the alert runs this action, Sentry sends a request to the Linear integration to create an issue. An alert firing does not confirm that Linear received the request or created an issue. If you don't see a Linear issue, see [Troubleshooting](#troubleshooting).

### Manually

To configure issue management manually, navigate to a specific Sentry issue and find the "Linked Issues" section on the right panel:

![Link Linear issue from Sentry issue](./img/linear-link-issue.png)

Here, you’ll be able to create or link Linear issues.

![Create Linear issue form](./img/linear-create-issue.png)

## Troubleshooting

If no Linear issue appears, check the alert's [triggers, filters, and throttling](/product/monitors-and-alerts/alerts/create-alerts/). Existing Sentry issues can trigger alerts again when these settings allow it. For help with alert execution or request delivery, contact Sentry Support. See [integration support guidance](https://www.sentry.help/en/articles/15423630-getting-help-when-a-sentry-integration-isn-t-working).

### No New or Reopened Linear Issue After Escalation

For an archived Sentry issue that escalates, use **An issue escalates**, not **A resolved issue regresses**.

Check **Linked Issues** on the Sentry issue. If a Linear issue is already linked, including one in the Canceled state, contact Linear support to confirm how the integration handles that link and status.

Published documentation does not specify whether escalation creates another Linear issue or reopens the linked one. Changing the alert's trigger or throttling does not guarantee either outcome.

As a workaround, manually reopen the issue in Linear, or create a new Linear issue with links to the Sentry issue and the previous Linear issue.
