### Tracing

<SplitLayout>
<SplitSection>
<SplitSectionText>

To test your tracing configuration, create a custom transaction and span:

</SplitSectionText>
<SplitSectionCode>

```py
import sentry_sdk

with sentry_sdk.start_transaction(op="task", name="Transaction Name"):
    span = sentry_sdk.start_span(name="Custom Span Name")
    span.finish()

# or, when using stream mode:
# with sentry_sdk.traces.start_span(name="Transaction Name", attributes={"sentry.op": "task"}):
#     with sentry_sdk.traces.start_span(name="Custom Span Name") as span:
#	      ...

```
