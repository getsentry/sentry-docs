<Alert level="warning">

Session Replay masking is best effort. The SDK automatically masks only the components listed in [Supported Components](#supported-components). It may not mask content from third-party libraries, components that draw their own content, or new versions of UI frameworks and libraries that change how they render, even with the default settings.

Before you enable Session Replay in production, test your app with the exact UI frameworks, libraries, and versions it ships with, and mask anything that isn't covered by using the masking options for your SDK. If a supported component isn't masked, open an issue in the SDK's GitHub repository and don't deploy Session Replay to production until it's resolved.

</Alert>
