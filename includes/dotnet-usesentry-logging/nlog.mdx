In an app that calls `UseSentry`, add NLog with `AddNLog` from the `NLog.Extensions.Logging` package, and set `ReplaceLoggerFactory`:

```csharp {filename:Program.cs}
using NLog;
using NLog.Config;
using NLog.Extensions.Logging;
using Sentry.NLog;

var config = new LoggingConfiguration();
config.AddRule(NLog.LogLevel.Info, NLog.LogLevel.Fatal, new SentryTarget());
LogManager.Configuration = config;

builder.Logging.AddNLog(new NLogProviderOptions { ReplaceLoggerFactory = true });
builder.UseSentry(options =>
{
    options.Dsn = "___PUBLIC_DSN___";
});
```

`ReplaceLoggerFactory` replaces the app's `ILogger` factory with NLog's, so each `ILogger` entry reaches Sentry once, through the target. Without it, NLog runs alongside the `ILogger` integration that `UseSentry` adds, and Sentry receives every entry twice. NLog's rules then decide which entries are logged, instead of the `Logging` section of your configuration. The target sends every entry it receives to Sentry as a log, so the rule's minimum level is also the minimum level for logs. In ASP.NET Core, `UseNLog` from the `NLog.Web.AspNetCore` package takes the same option.
