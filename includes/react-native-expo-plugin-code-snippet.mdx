<Alert>

`npx expo install` adds the bare `@sentry/react-native` to the plugins array. Both `@sentry/react-native` and `@sentry/react-native/expo` are valid plugin paths. Expo resolves them the same way.

</Alert>

Add your auth token to a `.env.local` file in the root of your project:

```properties {filename:.env.local}
# DO NOT COMMIT YOUR AUTH TOKEN
SENTRY_AUTH_TOKEN=___ORG_AUTH_TOKEN___
```

<Alert>

Do not commit your auth token. Add `.env.local` to your `.gitignore`.

</Alert>

For EAS Build, store the token as an [EAS environment variable](https://docs.expo.dev/eas/environment-variables/manage/) instead of a `.env.local` file. Set it for each environment you build, such as `production` or `preview`:

```bash
eas env:set --name SENTRY_AUTH_TOKEN --value ___ORG_AUTH_TOKEN___ --environment production --visibility sensitive
```

Use `sensitive` visibility if you also upload source maps from your machine, for example after `eas update`. Values with `secret` visibility never leave Expo servers, so they work for EAS Build but can't be pulled for local uploads.
