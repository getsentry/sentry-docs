## Correlating Logs With Traces

Pass the current `context.Context` when emitting logs so they use the operation's scope and active span. Use `span.Context()` for a child span, `logger.InfoContext(ctx, ...)` with slog, or `logger.WithContext(ctx)` with Logrus.

For the Sentry logger, use `logger.Info().WithCtx(ctx).Emit("message")`. An explicitly bound emission client overrides the construction client; an attached emission scope replaces the construction scope. Loggers and meters created before `sentry.Init` can emit after initialization.
