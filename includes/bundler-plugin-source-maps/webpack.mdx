You don't need to turn on source maps. When `devtool` isn't set, the plugin sets it to `"hidden-source-map"`, uploads the source maps to Sentry, and removes them from the build output. It does this only when it can upload, that is, when it has an auth token, an organization, and a project.

<Alert level="warning">

If you set `devtool` yourself, the plugin uploads these source maps and keeps them in the build output, where they can be public. To remove them after the upload, set [`sourcemaps.delete: true`](/platforms/javascript/sourcemaps/uploading/bundler-plugin-options/#sourcemaps.delete).

</Alert>
