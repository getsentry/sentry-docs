You don't need to turn on source maps. When `sourcemap` isn't set, the plugin sets it to `"external"`, uploads the source maps to Sentry, and deletes them from the build output after the upload. It does this only when it can upload, that is, when it has an auth token, an organization, and a project.

If you set `sourcemap` yourself, the plugin uploads these source maps and keeps them in the build output, where they can be public. To delete them after the upload, set [`sourcemaps.delete: true`](/platforms/javascript/sourcemaps/uploading/bundler-plugin-options/#sourcemaps.delete).
