You don't need to turn on source maps. When `output.sourcemap` isn't set, the plugin turns on hidden source maps, uploads them to Sentry, and removes them from the build output. It does this only when it can upload, that is, when it has an auth token, an organization, and a project.

If you set `output.sourcemap` yourself, the plugin uploads these source maps and keeps them in the build output, where they can be public. To remove them after the upload, set [`sourcemaps.delete: true`](/platforms/javascript/sourcemaps/uploading/bundler-plugin-options/#sourcemaps.delete).
