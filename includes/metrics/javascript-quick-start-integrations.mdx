<PlatformSection supported={["javascript.node", "javascript.express", "javascript.fastify", "javascript.hapi", "javascript.koa", "javascript.nestjs", "javascript.nitro", "javascript.aws-lambda", "javascript.gcp-functions", "javascript.azure-functions", "javascript.firebase", "javascript.astro", "javascript.nuxt", "javascript.react-router", "javascript.tanstackstart-react", "javascript.nextjs", "javascript.remix"]}>

To collect runtime health metrics automatically, add [`Sentry.nodeRuntimeMetricsIntegration()`](/platforms/javascript/guides/node/configuration/integrations/noderuntimemetrics/) to your SDK's `integrations` option. It collects memory usage, CPU utilization, event loop metrics, and process uptime every 30 seconds by default. Requires SDK version `10.46.0` or later.

<PlatformSection supported={["javascript.astro", "javascript.nuxt", "javascript.react-router", "javascript.tanstackstart-react", "javascript.nextjs", "javascript.remix"]}>

Add this integration only to the server SDK configuration when running on Node.js. Do not add it to browser or edge configuration.

</PlatformSection>

</PlatformSection>

<PlatformSection supported={["javascript.bun", "javascript.elysia"]}>

When running on Bun, add [`Sentry.bunRuntimeMetricsIntegration()`](/platforms/javascript/guides/bun/configuration/integrations/bunruntimemetrics/) to your SDK's `integrations` option to collect runtime health metrics automatically. It collects memory usage, CPU utilization, event loop utilization, and process uptime every 30 seconds by default. Requires SDK version `10.47.0` or later.

<PlatformSection supported={["javascript.elysia"]}>

The `@sentry/elysia` SDK exports this integration in version `11.2.0` or later. For Elysia apps running on Node.js, use the manual metric calls below.

</PlatformSection>

</PlatformSection>

<PlatformSection supported={["javascript.deno"]}>

To collect Deno runtime health metrics automatically, add [`Sentry.denoRuntimeMetricsIntegration()`](/platforms/javascript/guides/deno/configuration/integrations/denoruntimemetrics/) to your SDK's `integrations` option. It collects memory usage and process uptime every 30 seconds by default.

</PlatformSection>

<PlatformSection supported={["javascript.hono"]}>

Choose the integration for your Hono runtime and import it from the matching SDK entry point:

- Node.js: [`Sentry.nodeRuntimeMetricsIntegration()`](/platforms/javascript/guides/node/configuration/integrations/noderuntimemetrics/) from `@sentry/hono/node`, added to `Sentry.init` in your instrumentation file
- Bun: [`Sentry.bunRuntimeMetricsIntegration()`](/platforms/javascript/guides/bun/configuration/integrations/bunruntimemetrics/) from `@sentry/hono/bun`, added to the middleware's `integrations` option
- Deno: [`Sentry.denoRuntimeMetricsIntegration()`](/platforms/javascript/guides/deno/configuration/integrations/denoruntimemetrics/) from `@sentry/hono/deno`, added to the middleware's `integrations` option
- Cloudflare Workers: Use the manual metric calls below. Runtime metrics integrations are not available.

</PlatformSection>
