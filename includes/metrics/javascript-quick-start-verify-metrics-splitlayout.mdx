### Application Metrics <FeatureBadge type="new" size="small" />

<PlatformLink to="/metrics/">Application Metrics</PlatformLink> are enabled by
default.

<Include name="metrics/javascript-quick-start-integrations" />

Send test metrics directly to verify your setup without a runtime metrics integration:

```javascript
Sentry.metrics.count("checkout.failed", 1);
Sentry.metrics.gauge("queue.depth", 42);
Sentry.metrics.distribution("api_latency", 187, {
  unit: "millisecond",
});
```
