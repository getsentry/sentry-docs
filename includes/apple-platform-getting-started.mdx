## Install

Sentry captures data by using an SDK within your application's runtime. We recommend installing the SDK with Swift Package Manager (SPM). In Xcode, open **File > Add Packages**, then enter this repository URL:

```
https://github.com/getsentry/sentry-cocoa.git
```

<PlatformSection supported={["apple.ios"]}>

For iOS, you can install and configure the SDK with the [Sentry Wizard](https://github.com/getsentry/sentry-wizard). Run this command from your project directory:

```bash
brew install getsentry/tools/sentry-wizard && sentry-wizard -i ios
```

The wizard patches your project with the SDK configuration and adds the patched files to your version control. To set up the SDK manually, see <PlatformLink to="/manual-setup/">Manual Setup</PlatformLink> or continue below.

<Expandable title="The following tasks will be performed by the Sentry Wizard">

- Install the Sentry SDK with Swift Package Manager
- Update your `AppDelegate` or SwiftUI app initializer with the default Sentry configuration and an example error
- Add an `Upload Debug Symbols` phase to your `xcodebuild` build script
- Create `.sentryclirc` with an auth token for uploading debug symbols (the file is added to `.gitignore`)
- Add a Fastlane lane for uploading debug symbols if you're using Fastlane

</Expandable>

</PlatformSection>

### Initialize the SDK

To capture errors, initialize the SDK as early as possible, such as in your app delegate's `application(_:didFinishLaunchingWithOptions:)` method or your SwiftUI `App` initializer. Session Replay is available on iOS 16+ with Sentry Cocoa SDK 8.31.1+; UI Profiling requires SDK 8.49.0+.

```swift {tabTitle:Swift} {mdExpandTabs}
import Sentry

func application(_ application: UIApplication,
    didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
    SentrySDK.start { options in
        options.dsn = "___PUBLIC_DSN___"
        options.debug = true
        options.sendDefaultPii = true

        // Enable Tracing. Reduce this value in production.
        options.tracesSampleRate = 1.0

        // Enable Profiling.
        options.configureProfiling = {
            $0.lifecycle = .trace
            $0.sessionSampleRate = 1.0
        }

        // Enable Session Replay.
        options.sessionReplay.onErrorSampleRate = 1.0
        options.sessionReplay.sessionSampleRate = 0.1

        // Enable Logs.
        options.enableLogs = true
    }
    return true
}
```

```objc {tabTitle:Objective-C}
@import Sentry;

- (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
    [SentrySDK startWithConfigureOptions:^(SentryOptions *options) {
        options.dsn = @"___PUBLIC_DSN___";
        options.debug = YES;
        options.sendDefaultPii = YES;

        // Enable Tracing. Reduce this value in production.
        options.tracesSampleRate = @1.0;

        // Enable Profiling.
        options.configureProfiling = ^(SentryProfileOptions *profiling) {
            profiling.lifecycle = SentryProfileLifecycleTrace;
            profiling.sessionSampleRate = 1.0;
        };

        // Enable Session Replay.
        options.sessionReplay.onErrorSampleRate = 1.0;
        options.sessionReplay.sessionSampleRate = 0.1;

        // Enable Logs.
        options.enableLogs = YES;
    }];
    return YES;
}
```

```swift {tabTitle:SwiftUI with App conformer}
import Sentry

@main
struct ExampleApp: App {
    init() {
        SentrySDK.start { options in
            options.dsn = "___PUBLIC_DSN___"

            }
            options.sessionReplay.onErrorSampleRate = 1.0
            options.sessionReplay.sessionSampleRate = 0.1
            options.enableLogs = true
        }
    }
}
```

### Initialize the SDK

Initialize the SDK as early as possible when your application starts. The snippet enables Tracing, Profiling, and Logs. UI Profiling requires Sentry Cocoa SDK 8.49.0+. macOS doesn't support Session Replay.

```swift {tabTitle:Swift}
import Sentry

SentrySDK.start { options in
    options.dsn = "___PUBLIC_DSN___"
    options.debug = true
    options.sendDefaultPii = true
    options.enableUncaughtNSExceptionReporting = true

    // Enable Tracing. Reduce this value in production.
    options.tracesSampleRate = 1.0

    // Enable Profiling.
    options.configureProfiling = {
        $0.lifecycle = .trace
        $0.sessionSampleRate = 1.0
    }

    // Enable Logs.
    options.enableLogs = true
}
```

```objc {tabTitle:Objective-C}
@import Sentry;

[SentrySDK startWithConfigureOptions:^(SentryOptions *options) {
    options.dsn = @"___PUBLIC_DSN___";
    options.debug = YES;
    options.sendDefaultPii = YES;
    options.enableUncaughtNSExceptionReporting = YES;
    options.tracesSampleRate = @1.0;
    options.configureProfiling = ^(SentryProfileOptions *profiling) {
        profiling.lifecycle = SentryProfileLifecycleTrace;
        profiling.sessionSampleRate = 1.0;
    };
    options.enableLogs = YES;
}];
```

On macOS, the SDK can't capture uncaught exceptions without additional configuration. The snippets enable `enableUncaughtNSExceptionReporting`. For other options, see <PlatformLink to="/usage/#capturing-uncaught-exceptions">capturing uncaught exceptions</PlatformLink>.

</PlatformSection>

## Send Logs

Logs for Apple platforms require Sentry Cocoa SDK 8.55.0 or later. Starting with version 9.0.0, set `options.enableLogs = true` in the SDK initialization snippet above. For earlier versions, use `options.experimental.enableLogs = true` instead. See <PlatformLink to="/logs/">Set Up Logs</PlatformLink> for all logging methods and options.

```swift {tabTitle:Swift}
SentrySDK.logger.info("User example action completed")

SentrySDK.logger.warn("Slow operation detected", attributes: [
    "operation": "data_fetch",
    "duration": 3500
])
```

```objc {tabTitle:Objective-C}
SentryLogger *logger = SentrySDK.logger;
[logger info:@"User example action completed"];
[logger warn:@"Slow operation detected" attributes:@{
    @"operation": @"data_fetch",
    @"duration": @3500
}];
```

</PlatformSection>

## Send Application Metrics <FeatureBadge type="new" />

Application Metrics are enabled by default. In Sentry Cocoa SDK 9.12.0 and later, use `SentrySDK.metrics` to send counters, gauges, and distributions. Metrics were experimental in versions 9.4.0–9.11.x. The metrics API is currently Swift-only. See <PlatformLink to="/metrics/">Set Up Metrics</PlatformLink> for details.

```swift {tabTitle:Swift}
SentrySDK.metrics.count(key: "checkout.failed", value: 1)

SentrySDK.metrics.gauge(key: "time_since_refresh", value: 4, unit: .hour)

SentrySDK.metrics.distribution(
    key: "api_latency",
    value: 187,
    unit: .millisecond,
    attributes: ["endpoint": "/api/orders"]
)
```

## Verify Your Setup

Capture a test error to confirm that your app is sending events to Sentry. You should see it in your project within a few minutes.

```swift {tabTitle:Swift}
SentrySDK.capture(error: NSError(domain: "SentryTest", code: 1))
```

```objc {tabTitle:Objective-C}
[SentrySDK captureError:[NSError errorWithDomain:@"SentryTest" code:1 userInfo:nil]];
```
