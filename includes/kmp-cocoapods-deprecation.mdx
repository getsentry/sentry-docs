<Alert level="warning" title="CocoaPods is deprecated for Sentry Cocoa">

Sentry no longer publishes the Sentry Cocoa SDK to CocoaPods after [v9.19.1](https://github.com/getsentry/sentry-cocoa/releases/tag/9.19.1), and the CocoaPods trunk becomes read-only on December 2, 2026. Existing Kotlin Multiplatform setups that get Sentry Cocoa through the Kotlin CocoaPods plugin keep working, because older versions stay available on CocoaPods, but they won't receive new Sentry Cocoa releases.

For new projects, install Sentry Cocoa with [Swift Package Manager](/platforms/apple/install/swift-package-manager/) and let the [Sentry Gradle plugin](/platforms/kotlin/guides/kotlin-multiplatform/configuration/gradle/) handle linking. See [how auto-install and linking interact](/platforms/kotlin/guides/kotlin-multiplatform/configuration/gradle/#how-auto-install-and-linking-interact) for which setups are supported.

</Alert>
