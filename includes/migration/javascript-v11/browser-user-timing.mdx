`browserTracingIntegration` no longer captures `performance.mark()` and `performance.measure()` spans by default. The `ignorePerformanceApiSpans` option moved to `userTimingIntegration` as `ignore`.

```js
// Before
Sentry.init({
  integrations: [
    Sentry.browserTracingIntegration({
      ignorePerformanceApiSpans: ["third-party-mark"],
    }),
  ],
});

// After
Sentry.init({
  integrations: [
    Sentry.browserTracingIntegration(),
    Sentry.userTimingIntegration({ ignore: ["third-party-mark"] }),
  ],
});
```
