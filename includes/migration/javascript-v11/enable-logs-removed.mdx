`enableLogs` and `_experiments.enableLogs` were removed. Logs are captured whenever you call `Sentry.logger.*` or add a logging integration such as `consoleLoggingIntegration()`.

Remove the option:

```js
// Before
Sentry.init({ enableLogs: true });

// After
Sentry.init({});
```
