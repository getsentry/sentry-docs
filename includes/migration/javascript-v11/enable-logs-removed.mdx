The `enableLogs` option was removed, including its `_experiments` variant. Logs are captured whenever you use their API (`Sentry.logger.*`) or add a logging integration such as `consoleLoggingIntegration()`.

```js
// Before
Sentry.init({
  enableLogs: true,
});

// After
Sentry.init({});
```
