`withSentryConfig` and the `SentryBuildOptions` type are no longer exported from `@sentry/nextjs`. The no-op passthroughs on the client and edge builds are gone with it.

Import it from the new entry point in `next.config.mjs`:

```js
// Before
import { withSentryConfig } from '@sentry/nextjs';

// After
import { withSentryConfig } from '@sentry/nextjs/config';
```
