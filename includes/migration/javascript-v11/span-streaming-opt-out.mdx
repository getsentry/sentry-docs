`traceLifecycle: 'static'` keeps the previous transaction-based model if you cannot migrate `beforeSendSpan`, `beforeSendTransaction`, or `ignoreTransactions` yet.

```js
Sentry.init({
  traceLifecycle: "static",

  // Wrap `beforeSendSpan` with Sentry.withStaticSpan.
  beforeSendSpan: Sentry.withStaticSpan((span) => {
    span.description = scrub(span.description);
    return span;
  }),
});
```

In Node.js, Bun, Vercel Edge, and Cloudflare you can set `SENTRY_TRACE_LIFECYCLE=static` instead. Transaction mode only exists for backwards compatibility and will be removed in a future major version. Treat it as a temporary measure.
