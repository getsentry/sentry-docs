`sentryReactRouter`, `sentryOnBuildEnd`, `makeConfigInjectorPlugin`, and the `SentryReactRouterBuildOptions` type are no longer exported from the main `@sentry/react-router` entry point.

Import them from the subpath in your build config:

```diff
// vite.config.ts
- import { sentryReactRouter } from '@sentry/react-router';
+ import { sentryReactRouter } from '@sentry/react-router/vite';
```

```diff
// react-router.config.ts
- import { sentryOnBuildEnd } from '@sentry/react-router';
+ import { sentryOnBuildEnd } from '@sentry/react-router/vite';
```
