The Vite plugin exports moved to the `@sentry/react-router/vite` subpath. This affects `sentryReactRouter`, `sentryOnBuildEnd`, `makeConfigInjectorPlugin`, and the `SentryReactRouterBuildOptions` type.

```js {filename:vite.config.ts}
// Before
import { sentryReactRouter } from "@sentry/react-router";

// After
import { sentryReactRouter } from "@sentry/react-router/vite";
```
