The Sentry webpack plugin requires webpack **5.1** or newer. The `@sentry/bundler-plugins/webpack5` entry point was removed. Update imports to `@sentry/bundler-plugins/webpack`:

```js
// Before
import { sentryWebpackPlugin } from "@sentry/bundler-plugins/webpack5";

// After
import { sentryWebpackPlugin } from "@sentry/bundler-plugins/webpack";
```
