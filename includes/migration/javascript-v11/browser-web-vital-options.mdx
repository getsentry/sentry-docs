The `_experiments.enableStandalone*Spans` options were removed. CLS and LCP are no longer configurable, and `browserTracingIntegration` no longer accepts an `_experiments` object at all.

CLS and LCP are recorded as measurements on the pageload span, or as dedicated spans in stream mode.
