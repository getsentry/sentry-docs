`otlpIntegration()` moved from `@sentry/node-core/light/otlp` to every server SDK and was renamed to `openTelemetryIntegration()`. It no longer sets up an exporter, span processor, or tracer provider. The `setupOtlpTracesExporter` and `collectorUrl` options were removed.

Import it from your platform SDK:

```diff
- import { otlpIntegration } from '@sentry/node-core/light/otlp';
+ import { openTelemetryIntegration } from '@sentry/node';

- Sentry.init({ integrations: [otlpIntegration()] });
+ Sentry.init({ integrations: [openTelemetryIntegration()] });
```

Configure your own exporter and leave Sentry tracing off, as shown in [Custom OpenTelemetry setups](#custom-otel-setup). `getOtlpTracesEndpoint()` keeps its name.

If you reference the integration by name, update it:

```diff
- integrations.filter(integration => integration.name !== 'OtlpIntegration')
+ integrations.filter(integration => integration.name !== 'OpenTelemetry')
```
