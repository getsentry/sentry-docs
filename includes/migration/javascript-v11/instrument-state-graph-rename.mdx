`instrumentLangGraph` was renamed to `instrumentStateGraph` because it only instruments the `StateGraph` class.

```js
// Before
import { instrumentLangGraph } from "@sentry/node";

// After
import { instrumentStateGraph } from "@sentry/node";
```
