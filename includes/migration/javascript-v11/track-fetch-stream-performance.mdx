The `trackFetchStreamPerformance` option of `browserTracingIntegration` was removed. Use `fetchStreamPerformanceIntegration()` instead.

```js
// Before
Sentry.init({
  integrations: [
    Sentry.browserTracingIntegration({
      trackFetchStreamPerformance: true,
    }),
  ],
});

// After
Sentry.init({
  integrations: [
    Sentry.browserTracingIntegration(),
    Sentry.fetchStreamPerformanceIntegration(),
  ],
});
```
