The deprecated `sourceMapsUploadOptions` option was removed from `sentryAstro()`. `assets` and `filesToDeleteAfterUpload` moved into `sourcemaps`, and `enabled: false` became `sourcemaps: { disable: true }`.

Move its fields to the top level:

```js
// astro.config.mjs
export default defineConfig({
  integrations: [
    sentry({
      org: 'my-org',
      project: 'my-project',
      authToken: process.env.SENTRY_AUTH_TOKEN,
      sourcemaps: {
        assets: ['./dist/**/*'],
      },
    }),
  ],
});
```
