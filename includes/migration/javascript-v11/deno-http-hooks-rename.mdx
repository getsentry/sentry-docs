The incoming-span hooks on `denoHttpIntegration` were renamed to match `httpIntegration` in the other server SDKs, and their arguments are typed as `HttpIncomingMessage` and `HttpServerResponse` instead of `unknown`.

| Removed option          | Replacement     |
| ----------------------- | --------------- |
| `onIncomingSpanCreated` | `onSpanCreated` |
| `onIncomingSpanEnd`     | `onSpanEnd`     |

```js
// Before
Sentry.denoHttpIntegration({
  onIncomingSpanCreated: (span, req, res) => {
    span.setAttribute('custom', true);
  },
});

// After
Sentry.denoHttpIntegration({
  onSpanCreated: (span, req, res) => {
    span.setAttribute('custom', true);
  },
});
```

The integration also accepts `outgoingRequestHook`, `outgoingResponseHook`, and `outgoingRequestApplyCustomAttributes` now.
