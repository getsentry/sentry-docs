The deprecated server wrappers `wrapServerLoader` and `wrapServerAction` were removed. Loaders and actions are instrumented through the instrumentation API. Export it from your `entry.server.tsx`:

```tsx {filename:entry.server.tsx}
export const instrumentations = [Sentry.createSentryServerInstrumentation()];
```

The deprecated `sentryHandleRequest` export was removed. Use `wrapSentryHandleRequest` instead.
