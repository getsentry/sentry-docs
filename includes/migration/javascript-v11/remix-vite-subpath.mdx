`sentryRemixVitePlugin` moved from the main `@sentry/remix` entry point to `@sentry/remix/vite`.

```js {filename:vite.config.ts}
// Before
import { sentryRemixVitePlugin } from "@sentry/remix";

// After
import { sentryRemixVitePlugin } from "@sentry/remix/vite";
```

The plugin also applies the build-time instrumentation transform. If you added `sentryOrchestrionPlugin()` from `@sentry/server-utils/orchestrion/vite` yourself, remove it. Opt out with `sentryRemixVitePlugin({ buildTimeInstrumentation: false })`.
