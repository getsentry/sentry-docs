title: "The Nuxt server config is bundled, `--import` is no longer needed"
phase: packages
category: behavior
severity: behavior-change
frameworks: [nuxt]
platformCategory: all
order: 87
---

The SDK bundles `sentry.server.config.ts` into the Nitro server build and initializes Sentry when the server starts. Instrumentation happens at build time, so you no longer preload the config file. Remove the `--import` flag from your start commands:

```bash
# Before
node --import ./.output/server/sentry.server.config.mjs .output/server/index.mjs
NODE_OPTIONS='--import ./.nuxt/dev/sentry.server.config.mjs' nuxt dev

# After
node .output/server/index.mjs
nuxt dev
```

Existing start commands continue to work. The SDK still writes a file to the old path, but this file only prints a reminder to remove the flag. If you preload your own file that calls `Sentry.init()`, that call initializes the SDK and the bundled initialization is skipped.

The SDK doesn't initialize while Nitro prerenders pages at build time, so builds no longer send events.
