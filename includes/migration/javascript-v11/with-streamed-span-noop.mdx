`Sentry.withStreamedSpan()` is a no-op and deprecated. It will be removed in v12.

Remove the wrapper:

```js
// Before
beforeSendSpan: Sentry.withStreamedSpan(span => span);

// After
beforeSendSpan: span => span;
```
