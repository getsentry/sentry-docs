React component annotation is configured through a single top-level `reactComponentAnnotation` option that covers webpack and Turbopack:

```js {filename:next.config.mjs}
export default withSentryConfig(nextConfig, {
  reactComponentAnnotation: {
    enabled: true,
    ignoredComponents: ["MyComponent"],
  },
});
```

If you moved to `webpack.reactComponentAnnotation` for v10, move back to the top level. `webpack.reactComponentAnnotation` and `_experimental.turbopackReactComponentAnnotation` still work but are deprecated and will be removed in v12. If both options are set, the bundler-specific option wins for that bundler.

On Turbopack, annotation requires Next.js 16 or higher. The SDK now warns at build time on older versions.
