The SDK now supports Safari 15 and higher. Safari 14 was dropped.

Safari 14 lacks `performance.timeOrigin` and full `visibilitychange` support. The SDK still requires ES2020, so the other minimum browser versions are unchanged:

- Chrome 80
- Edge 80
- Firefox 74
- Opera 67
- Samsung Internet 13.0

iOS Safari also requires version 15. Browser builds that run on Node.js need a [supported Node.js version](#node-version).
