`@sentry/core` exports only isomorphic code now. Browser-only exports moved to `@sentry/core/browser`, and server-only exports moved to `@sentry/core/server`, keeping server code out of browser bundles.

This only affects imports straight from `@sentry/core`. Platform SDKs re-export these APIs as before. Update imports if TypeScript reports `has no exported member`:

```ts
// Before
import { loadModule, trpcMiddleware } from "@sentry/core";
import type { BrowserClientReplayOptions } from "@sentry/core";

// After
import { loadModule, trpcMiddleware } from "@sentry/core/server";
import type { BrowserClientReplayOptions } from "@sentry/core/browser";
```
