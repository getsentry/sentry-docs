The v11 AWS Lambda Layer is published as `SentryNodeServerlessSDKv11`. Version 10 updates continue as `SentryNodeServerlessSDKv10`.

Point your functions at the new layer ARN, which will be listed in the <PlatformLink to="/install/layer/">Lambda layer docs</PlatformLink>. The layer supports the `nodejs20.x`, `nodejs22.x`, and `nodejs24.x` runtimes, so functions on `nodejs18.x` need a newer runtime first.
