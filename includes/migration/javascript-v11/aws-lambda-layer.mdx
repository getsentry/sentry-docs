The layer for v11 is published as `SentryNodeServerlessSDKv11`. Its ARN will be listed in the <PlatformLink to="/install/layer/">Lambda Layer docs</PlatformLink> once it's available.

The layer supports the `nodejs20.x`, `nodejs22.x`, and `nodejs24.x` runtimes. Move functions that still run on `nodejs18.x` to a newer runtime before you upgrade.
