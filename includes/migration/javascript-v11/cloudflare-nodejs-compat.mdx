`@sentry/cloudflare` now requires the `nodejs_compat` compatibility flag instead of `nodejs_als`.

Update your `wrangler.toml` or `wrangler.jsonc`:

```diff
- compatibility_flags = ["nodejs_als"]
+ compatibility_flags = ["nodejs_compat"]
```
