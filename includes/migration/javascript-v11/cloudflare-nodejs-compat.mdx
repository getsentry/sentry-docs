The SDK requires the `nodejs_compat` compatibility flag instead of `nodejs_als`. Update your `wrangler.toml` or `wrangler.jsonc`:

```toml {diff} {filename:wrangler.toml}
- compatibility_flags = ["nodejs_als"]
+ compatibility_flags = ["nodejs_compat"]
```

Workers enable `nodejs_compat` by default from a `compatibility_date` of `2026-08-04`, so you only need the flag on earlier dates.
