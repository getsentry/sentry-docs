On Vercel, `@sentry/nextjs` now defaults `environment` to `VERCEL_TARGET_ENV`, such as `production`, `preview`, or your own environment name. Previously it used `vercel-production` and `vercel-preview`.

Update alert rules, dashboards, and saved searches that use the old names, or set `environment` explicitly to keep them.
