The `include` options of `requestDataIntegration` remain an integration-level override of `dataCollection`. User IP address inference is now controlled by `dataCollection.userInfo`.

An explicit `include: { ... }` value of `false` keeps a category off the event. An explicit `true` attaches it even when `dataCollection` disables the category. Any `allow` or `deny` filtering still applies. If only `include` enables a category, the default denylist filters sensitive values.

To keep user IP inference for the data this integration collects, set `requestDataIntegration({ include: { ip: true } })`. Check your overrides against the [new collection defaults](#data-collection).
