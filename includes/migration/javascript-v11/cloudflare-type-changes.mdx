The `env` types and the generics on `withSentry` and `instrumentDurableObjectWithSentry` were reworked. If you don't pass explicit generic type parameters, nothing changes.

```js {diff}
- export default withSentry<Env>(
+ export default withSentry(
    (env) => ({ dsn: env.SENTRY_DSN }),
    {
      async fetch(request, env, ctx) {},
    } satisfies ExportedHandler<Env>,
  );
```
