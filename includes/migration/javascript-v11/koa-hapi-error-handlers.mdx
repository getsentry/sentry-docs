title: "`setupKoaErrorHandler` and `setupHapiErrorHandler` are deprecated"
phase: cleanup
category: behavior
severity: informational
frameworks: [koa, hapi]
features: []
platformCategory: server
order: 50
---

Koa and Hapi errors are captured automatically when your app starts, so `setupKoaErrorHandler` and `setupHapiErrorHandler` no longer need to be called. Both are deprecated and will be removed in a future major version.

Remove the calls.
