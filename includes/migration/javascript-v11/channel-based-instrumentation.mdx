Channel-based instrumentation, which uses `orchestrion` instead of `import-in-the-middle`, is now the default. It supports instrumentation at run time and build time, enabling tracing on Vercel, Netlify, and Cloudflare, as well as Bun and Deno.

After upgrading, confirm spans still appear for the libraries you care about, especially if you had a custom instrumentation setup or relied on ESM loader hooks.
