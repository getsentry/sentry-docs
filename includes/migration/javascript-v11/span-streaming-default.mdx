Spans are sent in small batches as they finish, instead of being buffered until the root span completes. The 1000-span-per-transaction limit is gone, and individual payload limits are higher. What used to be a transaction is now a service span with its child spans.

No transaction events are produced in stream mode. Review these changes if you use the affected APIs:

- [`beforeSendSpan` receives the streamed span format](#before-send-span-format)
- [`beforeSendTransaction` no longer runs](#before-send-transaction-removed)
- [`ignoreTransactions` is replaced by `ignoreSpans`](#ignore-transactions-removed)
- [Scope tags and extra no longer apply to spans](#scope-attributes)
