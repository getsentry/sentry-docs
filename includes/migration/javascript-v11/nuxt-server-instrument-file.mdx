Support for the `public/instrument.server.[ext]` file was removed.

Move the file to the root of your project, next to `nuxt.config.ts`, and rename it to `sentry.server.config.[ext]`. Its contents do not change:

```
// Before
public/instrument.server.ts

// After
sentry.server.config.ts
```

The SDK then emits `.output/server/sentry.server.config.mjs` for you to preload:

```bash
node --import ./.output/server/sentry.server.config.mjs .output/server/index.mjs
```
