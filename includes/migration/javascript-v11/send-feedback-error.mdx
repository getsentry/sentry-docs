`Sentry.sendFeedback()` now rejects with an `Error` in all cases. Previously it rejected with a plain string on timeouts, 403 responses, and other send failures. The message text is unchanged and still customizable through the `errorMessages` hint.

Read it off `error.message`:

```js
try {
  await Sentry.sendFeedback({ message: 'Hello' });
} catch (error) {
  console.log(error.message);
}
```
