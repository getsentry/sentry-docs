Deploys that the bundler plugins create on Vercel now use `VERCEL_TARGET_ENV` as their environment, instead of `vercel-production` and `vercel-preview`. This matches the new Next.js runtime default.

If your events use a different environment, set `release.deploy.env` to the same value. Set `release.deploy` to `false` to opt out of creating deploys.
