`vercelAIIntegration` now relies on diagnostics channels, which the Vercel Edge runtime does not support. It was removed from `@sentry/vercel-edge`, and `@sentry/nextjs` keeps a no-op export on its Edge build so edge-compiled instrumentation files still resolve. The integration also no longer enhances the native OpenTelemetry spans the `ai` package emits, on any runtime.

Expect no `ai` spans from Edge functions, and possibly fewer agent monitoring details elsewhere. In return the integration works out of the box in many more environments than before.
