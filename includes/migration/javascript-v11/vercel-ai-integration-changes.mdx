`vercelAIIntegration` no longer works on Vercel Edge, which doesn't support diagnostics channels, and it no longer enhances the native OpenTelemetry spans the `ai` package emits. Those spans are captured as they are, so some agent monitoring capabilities are lost.

On Next.js, the `vercelAIIntegration` export stays available as a no-op on Edge builds.
