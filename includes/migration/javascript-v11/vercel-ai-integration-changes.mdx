`vercelAIIntegration` relies on diagnostics channels, which Vercel Edge does not support. The integration also no longer enhances native OpenTelemetry spans emitted by the `ai` package.

On Next.js Edge builds, the export remains available as a no-op. Native OpenTelemetry spans can still be captured as they are, but some agent monitoring capabilities are lost. Check the spans and agent monitoring details you rely on after upgrading.
