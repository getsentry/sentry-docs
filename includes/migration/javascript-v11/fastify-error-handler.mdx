Fastify errors are captured by `fastifyIntegration()` now, so `setupFastifyErrorHandler(app)` is no longer needed. It is deprecated and will be removed in the next major version.

Because the integration owns error capture, `shouldHandleError` moved to `fastifyIntegration()`.

The deprecated `instrumentFastify`, `handleFastifyError`, and `setShouldHandleError` exports were removed.
