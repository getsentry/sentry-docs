The `sourceMapsUploadOptions` option was removed. Move its fields to the top level of the SDK's build options:

```js
// Before
sourceMapsUploadOptions: {
  org: "my-org",
  project: "my-project",
  authToken: process.env.SENTRY_AUTH_TOKEN,
  sourcemaps: { assets: ["./build/**/*"] },
}

// After
org: "my-org",
project: "my-project",
authToken: process.env.SENTRY_AUTH_TOKEN,
sourcemaps: { assets: ["./build/**/*"] },
```

The `enabled` field is gone. Use `sourcemaps: { disable: true }` instead of `enabled: false`.
