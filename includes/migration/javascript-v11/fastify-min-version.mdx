The Fastify integration now supports Fastify 3.21 and higher. Fastify 3.0 through 3.20 are no longer supported.

If your application uses Fastify, including through NestJS's Fastify adapter, upgrade it before upgrading the SDK. Applications that do not use Fastify need no changes.
