title: "Cloudflare rate limiter bindings no longer create spans"
phase: verify
category: behavior
severity: behavior-change
frameworks: [cloudflare]
platformCategory: serverless
order: 125
---

Rate limiter bindings (`env.MY_RATE_LIMITER.limit()`) no longer create a span. Remove any dashboard, alert, or `ignoreSpans` entry that references the `rpc` span with `rpc.service: cloudflare.rate_limit`.
