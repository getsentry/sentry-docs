Update any directly declared Sentry integration packages, such as `sentry_dio` or `sentry_logging`, to the matching v10 release as well. To test the alpha.7 prerelease, use `10.0.0-alpha.7`:

```yaml {filename:pubspec.yaml}
dependencies:
  sentry_flutter: 10.0.0-alpha.7
```

The unreleased changes described in this guide require a later release or a build from the referenced `v10-branch` commit; installing alpha.7 does not include them.

The integration dependency constraints also change:

| Package          | Required Dependency                                     |
| ---------------- | ------------------------------------------------------- |
| `sentry_flutter` | `jni >=1.0.0 <1.1.0` (previously `0.14.2`)              |
| `sentry_dio`     | `dio ^5.8.0` (previously `^5.2.0`)                      |
| `sentry_link`    | `gql_link >=0.5.1 <2.0.0` (previously `>=0.5.0 <2.0.0`) |

Update conflicting direct dependencies or dependency overrides before running `flutter pub get`.
