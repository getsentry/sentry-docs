On iOS and macOS, `captureNativeFailedRequests` now defaults to `false` and no longer accepts `null`. It no longer falls back to `captureFailedRequests`.

To continue capturing failed HTTP requests made by the native SDK's network instrumentation, opt in explicitly:

```dart
options.captureNativeFailedRequests = true;
```

Dart-side failed request capture through `SentryHttpClient` and `sentry_dio` is still controlled independently by `captureFailedRequests`, which defaults to `true`.
