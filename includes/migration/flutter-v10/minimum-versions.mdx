Update your local development environment and CI before upgrading:

| Dependency              | v9 Minimum | v10 Minimum |
| ----------------------- | ---------- | ----------- |
| Dart                    | `3.5.0`    | `3.12.0`    |
| Flutter                 | `3.24.0`   | `3.44.0`    |
| Android API (`minSdk`)  | `21`       | `24`        |
| iOS deployment target   | `12.0`     | `15.0`      |
| macOS deployment target | `10.14`    | `12.0`      |

SDK versions `10.0.0` to `10.3.x` require Android API 26. Starting with `10.4.0`, the minimum is Android API 24, which matches Flutter's default `minSdk`.
