Sentry is an application monitoring platform for errors, tracing, logs, metrics, profiling, Session Replay, and more.

## For AI Agents

- **Setting up Sentry in a project:** Fetch and follow [Agent Guide: Set Up Sentry](/ai/agent-setup/get-started/) before the platform or framework guide. It covers setup through the Sentry CLI, the Sentry MCP server, or neither, from choosing a project to confirming a real error reaches Sentry.
- **Adding a feature to a project that already uses Sentry:** Follow [Agent Guide: Add a Sentry Feature](/ai/agent-setup/instrument/) for tracing, logs, Session Replay, metrics, profiling, crons, uptime, or AI agent monitoring.
